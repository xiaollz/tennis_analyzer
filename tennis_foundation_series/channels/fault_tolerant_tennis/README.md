# Fault Tolerant Tennis

FTT 频道的深度内容证据库。93 条公开视频均有原始视频分析，可用于技术检索、训练建议和 VLM 诊断交叉验证。

## 保留内容

- `foundation/first_principles_knowledge_tree.md`：频道知识框架。
- `foundation/tennis_knowledge_graph_schema.json`：图谱结构。
- `foundation/tennis_knowledge_graph_seed.json`：精选核心节点与关系。
- `raw/video_analyses/`：93 份逐视频原始分析，是最高保真的本地证据。

逐视频结构化关键点已经合并到系列级 `unified/all_knowledge_items.jsonl`，视频元数据在 `unified/all_videos.jsonl`。本频道不再保存重复目录、抓取清单、代理日志和构建产物。

## 使用边界

内容分析不是逐字字幕。引用时保留视频 ID、URL、证据状态和适用条件；无法由画面直接确认的内部发力或因果关系仍需标为假设。
