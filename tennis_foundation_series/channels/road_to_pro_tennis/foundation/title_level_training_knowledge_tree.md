# Road to Pro Tennis：训练教学知识树（标题级证据版）

**源频道：** [Road to Pro Tennis](https://www.youtube.com/@RoadtoPro10is)
**版本：** 0.1，2026-08-15
**范围：** 频道151条可公开枚举视频中，141条被识别为网球训练、表现或竞技发展相关。

> **证据边界。** 本文件是训练内容的**主题地图与后续提取框架**，而不是对视频口述内容的逐条复述。每个节点都由视频标题、URL、时长和主题标签支撑；“可能覆盖的问题”用于检索与人工审阅，**不得**当作频道已明确表述的技术原理或训练处方。

## 1. 树的用途

Road to Pro Tennis 的题材密度集中于正手、发球、反手、网前、脚步、训练设计、心理表现和竞技发展。基于这些公开元数据，知识库应先建立“视频主题 → 待验证教学问题 → 条件/机制/练习槽位 → VLM 观察槽位”的结构。之后只要获得视频字幕、人工笔记或可审计的音画分析，即可把具体主张填入对应槽位，而不会改变索引层。

## 3. 主题→知识单元的标准模板

每个 Road to Pro Tennis 视频的后续内容采集都应生成一个 `TrainingKnowledgeUnit`，而不是仅写摘要。

| 字段 | 含义 | 当前可填状态 |
|---|---|---|
| `video_id` / `source_url` | 公开视频身份与可回链来源 | 已为151条填充 |
| `instruction_scope` | `include_instructional_or_performance` 或排除理由 | 已为151条填充 |
| `domain_tags` | 上述 A–F 节点与细分主题 | 已由标题确定性标注 |
| `teaching_problem` | 视频试图解决的球员问题 | **待字幕/音画证据** |
| `conditions` | 水平、球况、来球、站位、目标、伤病背景 | **待证据** |
| `mechanism_claim` | 身体、球拍、球路、决策或学习机制 | **待证据** |
| `action_cue` | 动作线索与感觉线索 | **待证据** |
| `drill` / `success_criterion` | 练习及通过标准 | **待证据** |
| `vlm_observable` | 可直接观察的关键点、球拍、球路或位置 | 由主题提供槽位，需视频验证 |
| `evidence_type` | `video_explicit` / `visual_inference` / `synthesis` | 当前仅 `metadata_title_only` |

## 4. 与四类应用的最低可用接口

| 应用 | 现在可以安全支持的能力 | 现在不应支持的能力 | 内容补齐后的升级方向 |
|---|---|---|---|
| 知识管理 | 按主题、视频类型、标题、时长和证据状态检索 | 把标题转换成视频内具体教学结论 | 时间码证据、主张冲突与条件化导航 |
| 网球 Agent | 识别问题属于发球/正手/脚步/战术/心理等哪个主题 | 给出“RTP 教练建议你做X”的归因回答 | 条件澄清、证据检索、单变量练习与复测 |
| 教学系统 | 组织课程地图、发现视频资源、建立内容补齐队列 | 自动判定技术是否正确 | 按水平与球况生成阶段化课程 |
| VLM 视频分析 | 为各主题预定义应观察的事件类别 | 从标题反推生物力学诊断 | 事件检测、观察与假设分离、补拍请求 |

## 5. VLM 观察槽位（待视频证据验证）

| 主题 | 建议事件 | 可见变量 | 不可直接从单视频断言的内容 |
|---|---|---|---|
| 发球 | 抛球、奖杯位、拍头低点、接触、落地 | 手足时序、拍头路径、接触点代理 | 精确握力、内部关节力矩、伤病原因 |
| 正手 | 单位转体、下降、接触、随挥、恢复 | 球—躯干距离、站位、拍头/手部相对运动 | 唯一的“正确”随挥或旋转速度 |
| 反手 | 引拍、步入/开放支撑、接触、随挥 | 前脚、骨盆朝向、拍面与击球区代理 | 内部肌肉激活 |
| 网前 | 启动、拦截、截击接触、恢复 | 距网、拍头路径、步数、重心方向代理 | 反应意图和战术沟通 |
| 战术 | 击球前、球路、回合位置、恢复 | 球路、四区站位、攻击/防守相对位置 | 仅凭单分判断的策略优劣 |

## 6. 质量与安全护栏

训练知识库必须先声明证据状态，再展示任何结论。关于疼痛、网球肘或伤病预防的视频，只能建立“相关主题”索引；在没有医学来源和个人评估时，系统不得给出诊断、康复计划或继续/停止训练的医疗判断。

所有需要视频内容证明的节点在本项目中处于 `pending_content_evidence`。当可取得字幕、视频分析或教练人工标注时，应按 `video_id` 追加证据，不覆盖现有标题级数据。
