## 1. Feel-based 教学的核心建模

感觉导向训练不能将“感觉”当作可独立传播的神秘口号。对知识库而言，一个感觉线索必须被建模为：

```text
问题 / 球况
  → 可见动作或可操作对象
  → 感觉线索（意象、外部焦点、节奏或接触反馈）
  → 目标结果（接触、球路、稳定性、恢复或决策）
  → drill 与成功标准
  → 适用条件、常见误解与反证
```

| 感觉线索类型 | 候选标题/播放列表线索 | 正确的数据结构 | 不应做的事 |
|---|---|---|---|
| 意象/隐喻 | throw、imagine、feel like | 将意象绑定到动作阶段、对象和边界 | 把隐喻按字面动作执行 |
| 放松—控制 | relax、tension、effortless、control、rushing | 记录何时放松、何时稳定、如何复测接触 | 将放松误等同于松散或失去结构 |
| 接触反馈 | sweet spot、contact、mishit、touch、feel | 连接触感、声音、拍面/球位代理和出球结果 | 用一次“好手感”替代稳定指标 |
| 外部注意焦点 | ball、target、racket、swing path、throw | 明确注意对象与任务目标 | 让球员过度内省每一个关节 |
| 解释机制 | why、explained、invisible、power、lag、swing path | 分离视频明示、视觉推断和跨视频综合 | 从标题外推完整生物力学结论 |

## 3. 证据化的感觉线索模板

| 字段 | 为什么必要 | 允许的当前状态 |
|---|---|---|
| `problem` | 防止一个 cue 被无条件泛化 | 待视频内容证据。 |
| `context` | 包括技术族、球况、水平、目标与限制 | 标题/播放列表可提供主题级候选。 |
| `cue_text_or_imagery` | 保留原始词汇，而不是概念化改写 | 待视频口述或画面。 |
| `visible_action_proxy` | 使感觉能被教练或VLM复测 | 只能在音画或教练审阅后填充。 |
| `expected_result` | 接触、球路、稳定性、移动或决策变化 | 待视频证据。 |
| `drill_steps` | 起始、动作、反馈与次数 | 待视频证据。 |
| `misuse_or_boundary` | 防止误解“放松/throw/lag”等提示 | 待视频证据或人工审阅。 |
| `evidence` | ID、时间码、类型、置信度、审阅状态 | 元数据条目当前无时间码主张。 |

## 5. Drill 与 cue 的组合模式

| 组合模式 | 适用问题 | 原子组合 | 系统必须追问 |
|---|---|---|---|
| 放松—控制 | 紧张、抢球、触球不稳 | `error_correction` → `relaxation_control_cue` → `drill` → 接触复测 | 哪个阶段紧张？球况与击球目标是什么？ |
| 接触质量 | mishit、甜点击球感不稳定 | `contact_feedback_cue` → 可见球位/拍面代理 → 单变量drill | 是正反手、发球还是截击？来球高度/速度？ |
| 力量感 | 用力但球不走或失控 | `mechanism` → `external_focus_cue` → power/tempo drill | 目标是球速、深度、旋转还是省力？ |
| 球况适应 | 短球、深高球、上网或急球 | 条件 → movement/spacing → 技术cue → recovery | 有多少准备时间？下一拍目标是什么？ |
| 心理—技术整合 | 害怕失误、临场紧张、害怕开放拍面 | 心理条件 → 外部焦点 → 技术原子 → 低压到高压drill | 是否有疼痛、比赛压力或技术风险？ |

## 6. VLM 观察槽位

| 技术域 | 可直接观察的事件 | 能安全报告 | 不能仅凭视频断言 |
|---|---|---|---|
| 正手 | 转体、下降、接触、随挥、恢复 | 站位、球—躯干关系、拍头路径代理、接触与恢复 | 主观“放松程度”、精确关节力矩、唯一正确路径。 |
| 发球 | 准备、抛球、奖杯、拍头低点、接触、落地 | 手足时序、拍头路径代理、接触点与恢复第一步 | 精确握压、旋前速度、疼痛风险。 |
| 单反/反手 | 支撑、引拍、接触、随挥 | 支撑脚、躯干朝向代理、击球区和拍头路径 | 肌肉激活和内部关节载荷。 |
| 截击 | 启动、空间调整、拦截、恢复 | 距网、球拍路径、步数、击球后位置 | 反应意图或战术沟通。 |
| drill | 起始、任务、反馈、重复 | 是否遵守练习约束、可见结果 | 练习是否真正产生长期迁移。 |

## 7. 证据升级原则

当前数据状态为 `metadata_title_and_playlist_only`。当获得视频内容、人工笔记或合规音画分析后，应按 `video_id` 追加原子并提升为 `video_explicit` 或 `visual_inference`；经教练检查后再标记为 `human_reviewed`。任何感觉线索都要保留其原始视频用语、适用条件、反例和复测方法。
