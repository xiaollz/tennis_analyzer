# Feel Tennis Instruction

当前仅保留 Feel Tennis 的感觉导向知识框架。现有视频记录来自标题和官方播放列表，不具备视频内容证据，因此不进入技术诊断。

## 保留内容

- `foundation/feel_based_training_knowledge_tree.md`：感觉、意象、外部焦点、反馈和练习的组织框架。
- `foundation/feel_atomic_training_schema.json`：未来证据化训练原子的结构。
- `foundation/feel_content_enrichment_protocol.md`：补齐视频内容时的证据和质量要求。

视频身份和候选标签统一保存在系列级 `unified/`。在取得时间码和音画内容证据前，只能把这些记录当作待分析资源。
