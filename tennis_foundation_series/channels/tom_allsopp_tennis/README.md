# TPA tennis / Tom Allsopp

TPA 频道的证据化知识库。频道共有 428 条索引记录，其中 124 条有深度视频内容分析，304 条仅有元数据。

## 保留内容

- `foundation/first_principles_knowledge_tree.md`：频道知识框架。
- `foundation/tennis_knowledge_graph_schema.json`：图谱结构。
- `foundation/tennis_knowledge_graph_seed.json`：精选核心节点与关系。
- `raw/video_analyses/`：125 份本地分析文件，其中 124 条进入统一深度证据统计。

统一视频和知识索引位于系列级 `unified/`。只有标记为 `video_content_analysis` 的记录可以影响诊断；其余记录只能用于资源发现。

## 使用边界

不得把标题标签表述为视频教学内容。单机位观察只能支持可见事实和候选机制，不能证明内部肌肉状态、伤病或唯一因果。
