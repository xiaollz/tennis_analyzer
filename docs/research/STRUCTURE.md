## 整理原则

1. **不删除**：所有原文件保留，只移动到对应主题子目录。
2. **来源 vs 主题双轴**：同时按主题（HSA / ESR / Foundation）和来源（FTT / TPA / Bourne）分类，因为有些来源 = 主题（HSA 是项目内发现，与 FTT 等外部来源不同）。
3. **顶层入口最少**：根目录只留 7 个 master 文档作为快速入口，其他全部下沉。
4. **保留 `_meta/` / `_pipeline_state/` / `_synthesis/`**：原有元工作目录不动。
