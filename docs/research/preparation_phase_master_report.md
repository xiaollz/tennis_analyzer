## 1. 准备阶段时间线（精确到 ms）

> **零点**（T=0）= 对手击球前 80ms 起跳分腿步顶点；T=200ms = 落地。
> 时间窗整合自：FTT split-step 文章、Feel Tennis Improve Timing、Tom Allsopp Early Preparation、Tennis Science Ch2 p.40 timing 表、PMC5304278（split-step 80ms）、Landlinger et al. JSSM 2010（trunk peak -57ms）。
> 数据精度：±50ms。中速底线对拉。快球往左推（每个 milestone 提早 100-200ms），慢球可往右推 300-500ms。

| 时刻 | 身体状态 | 关键肌肉 | 唯一 cue |
|---|---|---|---|
| **T = -80 ms** | 对手挥拍中段 / 起跳分腿步开始 | 股四头肌 SSC 储能、踝跖屈肌（小腿三头肌） | 起跳轻、看对手身体（FTT 视觉策略 stage 1） |
| **T = 0 ms** | 对手触球瞬间 / 我在空中分腿步顶点 | 股四头肌等长 + 髋屈肌微张 | "踩在弹簧上" — 不是停在空中 |
| **T = 200 ms** | 双脚落地，宽于肩，已知正/反手 | 股四头肌 SSC 释放（落地反弹），下肢 GRF 1.5–2.0×BW（Tennis Science p.44） | "弹起来"，落地不沉 |
| **T = 300 ms** | Unit Turn 启动 — 右脚先 pivot 带髋 | 右腿臀大肌 + 右腿腘绳 + 腹斜肌（右）开始扭转，**前锯肌已开始招募**（最早，serve 数据 -287ms 启动） | "左肩往前送"（Feel Tennis）/ 不是"右手往后拉" |
| **T = 500 ms** | 双手已开始分开（尚未脱拍）、左手开始把拍颈横过身体 | 左侧菱形肌 + 中下斜方肌后缩肩胛 / 右侧背阔肌等长收缩开始（"胶水"张力）/ 腹斜肌（右）继续拉伸 | "用左手拉拍颈"（FTT / Tom Allsopp）— 双手仍同步 |
| **T = 700 ms** | 髋转完成 ~45-60°、肩转 ~90°、shoulder-hip separation ~25-30° | 臀大肌（右）+ 腘绳（右）拉伸至 SSC 储能；**冈下肌 + 小圆肌 ESR 主动**；**前锯肌 + 下斜方肌 isometric 锁肩胛**；胸大肌**预拉伸但不发力**（"Attached"状态） | "外旋锁门" + "上背绷成槽" |
| **T = 900 ms** | Loaded slot — Pat the Dog / 双外旋完成 | 上述全部肌肉**等长维持**张力；右肘约 45-55° 离体（一拳腋下空间）；右肩在右髋正上方；左手已离拍并指向右侧网柱方向 | "信任刚体，等球" — 进入 Wait 阶段 |

### 时间线注解

- **T=200-700ms 是"Unit Turn"**——四件事（脚 / 髋 / 躯干 / 双手）必须**同步**。任何一个先动 = 破窗。
- **T=900 ms 之后是"Wait"阶段**——快球 wait=0，慢球 wait 可达 500ms+。视觉触发挥拍，不是计时（FTT 书 p.75）。
- **总耗时（split landing → loaded slot）≈ 700 ms**——精英球员可压到 500 ms，业余常见 1200+ ms（晚 = 死）。
- **Landlinger 数据（JSSM 2010）**：精英 trunk 角速度峰值在击球前 -57 ms；推回去 trunk 旋转启动至少要在击球前 300ms+ 完成 → 对应这里的 T=900ms loaded slot。

|---|---|---|---|---|---|---|---|
| 10 | **冈下肌** | Infraspinatus | 肩胛骨外下，肩胛冈下方 | 700 → 900 ms | **肩外旋（ESR）**——把肱骨头转向后下 | **主动**（用户 5/16 关键修正） | 肩后下方"拧"的感觉，**不是**肩顶部 |
| 11 | **小圆肌** | Teres minor | 肩胛骨外缘下段 | 700 → 900 ms | 协同冈下肌外旋 | 主动 | 跟 #10 同区，作为冈下肌的小弟 |

## 3. 三个独立动作系统

> **核心模型**：准备阶段不是一件事，是**三件并行**的事。下肢、躯干、上肢各有自己的肌肉、自己的时机、自己的成功条件。
> 用户 5/16 顿悟："肩外旋 vs 抬胳膊是两件独立的事" — 这是这一节的关键。

### 3.1 下肢系统（base + 旋转引擎）

**职责**：建立轴心 + 提供髋旋转动力 + 储 SSC 弹性能。

**肌肉链**：
- 起：股四头肌 + 小腿三头肌（split step SSC）
- 主：右腿臀大肌（外旋 + 后伸）+ 右腿腘绳肌（拉伸储能）+ 髋屈肌（左侧）
- 稳：右腿股内侧肌、踝周稳定肌

**时机**：
- T = -80 → 200 ms：起跳/落地，SSC 初始化
- T = 200 → 700 ms：右脚 pivot → 髋转 45-60°
- T = 700 → 击球：**髋停在 target 方向**（FTT "stop hip rotation right as they're pointed at the target"），剩下让上身赶上去

**和其他系统的同步**：
- 跟躯干：髋必须**先转或同步**——绝不能肩先转髋停（business of "upper-body-only turn"，30_unit_turn_hip_rotation.md）
- 跟上肢：下肢提供 base + 旋转，上肢被动跟随；下肢蹬转把力**送进**上肢的刚体

**成功条件（自检）**：
- 右臀 + 右大腿后侧拉伸感
- 能抬起左脚不失衡（重心已在右脚）
- 右脚跟踩实（不浮起）

### 3.2 躯干系统（传力通道）

**职责**：胸椎旋转 + 核心刚体 + 肩-髋分离储能。

**肌肉链**：
- 主：腹斜肌（右拉伸）+ 腹横肌（核心加压）+ 多裂肌（脊柱稳定）
- 旋：胸椎旋转肌（深层）
- 后链：竖脊肌（**Tennis Science p.155 提示精英球员普遍弱**——常被忽视）

**时机**：
- T = 300 ms 启动，T = 700 ms 完成 90° 肩转
- 肩-髋 separation = 25-35°（精英；Tennis Science p.35 / Landlinger 27-35°）

**和其他系统的同步**：
- 跟下肢：髋转 45-60°，肩转 90° → 自然 X-factor
- 跟上肢：躯干转动**带着**手臂走（手臂"沿着轴线漂"，不是手臂主动后引）

**成功条件**：
- 右肋外下"拧麻花"
- 头不跟着肩转（眼睛盯球）
- 肩线 ⊥ 球网

### 3.3 上肢系统（锁定刚体）

**职责**：把肱骨**焊**成倾斜刚体 + 设定击球高度 + 双外旋锁定。

> **核心：上肢不发力，上肢做的是"把自己变成一根有角度的杆子"**。

**肌肉链**：
- 锁肩胛（"槽"）：前锯肌 + 下斜方 + 中斜方 + 菱形肌（**isometric**）
- 锁肱骨（"住肩窝"）：背阔肌 + 大圆肌（isometric "胶水"）+ 旋转袖（动态稳定）
- 双外旋（5/14-5/15 突破）：冈下肌 + 小圆肌（**主动 ESR**）
- 设高度：肩胛上回旋力偶（前锯肌下纤维 + 下斜方）→ 不是三角肌

**时机**：
- T = 300 ms 起前锯肌已启动（serve 数据 -287ms）
- T = 500 ms 双手分开但仍同步
- T = 700 ms 双外旋锁定 + 上背绷成槽
- T = 900 ms loaded slot 完成

**和其他系统的同步**：
- 上肢**完全被动跟随**躯干旋转（FTT 书 p.60 "merely a result"）
- 但**等长张力主动维持**——不是"放松软挂"，是"绷成杆子"
- 这两件事不矛盾：**位置被动 + 张力主动**

**成功条件（4 条体感锚）**：
- 腋下能塞下一个拳头（45-55° 夹角，Brian Gordon 标准）
- 右肩胛骨**贴**在背上（不是飘）
- 右肩**沉**（不耸）
- 持拍手腕**完全没感觉**（FTT 书 p.85 "passenger"）

## 4. 主动 vs 被动清单

> 用户 5/6 顿悟："推肘是结果，不是动作" — 这一节是把所有动作切成"主动管 / 被动让"两栏。
> 主动越少越好（FTT 书 p.80 "extraneous movements actively hinder"）。

### 4.1 必须主动的动作（5 件，不能再多）

| # | 动作 | 肌肉 | 为什么 |
|---|---|---|---|
| 1 | **左肩往前** / 用左手拉拍颈 | 左侧胸大肌（轻）+ 左侧前锯肌 | Feel Tennis / FTT / Tom Allsopp 三家共识。把"右臂往后引"的有害本能改成"左肩往前送"——自动产生 unit turn 不需要右臂参与。 |
| 2 | **右脚 pivot + 蹬地（启动 GRF）** | 右腿臀大肌 + 股四头肌 | 旋转引擎的源头。不主动启动 = 整条 kinetic chain 没有输入力。 |
| 3 | **核心收紧**（鼻吸 + 加压） | 腹横肌 + 腹斜肌 + 膈肌 | FTT 书 p.74 "Inhale and Wait"。给上肢提供刚性传力通道。 |
| 4 | **肩胛后缩 + 下沉**（绷成"槽"） | 菱形肌 + 中下斜方肌 + 前锯肌 | 4/30 上身圣经。**唯一**意识能直接管的上肢动作（带"后/下/夹"的 task imagery）。 |
| 5 | **冈下肌主动 ESR**（双外旋锁门） | 冈下肌 + 小圆肌 | 5/14-5/15 双外旋突破。这是 reciprocal inhibition 的入口——主动 ER 抑制 IR，让 Phase 2 的 ISR 释放有空间储能。 |

### 4.2 必须被动的动作（10+ 件）

| # | 动作 | 为什么被动 | 谁做 |
|---|---|---|---|
| B1 | 手臂**向后位移** | "merely a result" — FTT 书 p.60 | 躯干旋转把手臂拖过去 |
| B2 | 拍头**绕到身后** | backswing illusion（Feel Tennis） | 同 B1 |
| B3 | **肘弯曲 90-110°** | 准备位置肘弯是放松状态的自然角度 | 重力 + 握拍微感 |
| B4 | **手腕中立（铰链态）** | FTT 书 p.65-66 — 主动收紧手腕破坏 lag | 放松 |
| B5 | **手腕 lag** | 是前挥中**被动产生**的（FTT 书 p.66）；准备阶段不存在 lag | 物理（前挥时拍头惯性） |
| B6 | **拍面朝下** | FTT 博客 #24 — 准备朝下补偿前挥的自然向上翻 | 握拍 + 重力 |
| B7 | **butt cap 朝向身体** | 手腕放松后的自然几何（FTT 书 p.65） | 放松 |
| B8 | **腋下空间维持**（一拳） | 背阔肌 + 肩胛后缩的几何后果（不是三角肌主动外展） | isometric 张力 |
| B9 | **手抬到肩高** | 肩胛上回旋力偶 + 躯干侧弯的几何结果 | 前锯肌下纤维 + 下斜方（不是三角肌） |
| B10 | **胸大肌微拉伸**（"Attached"状态） | 双外旋 + 上背绷成槽后的下游 | reciprocal inhibition |
| B11 | **腹斜肌储能** | 髋转 + 肩转 separation 的下游 | X-factor 的物理结果 |

### 4.3 绝对禁止主动的动作（5/6 永久禁令）

| # | 错误动作 | 错误原因 | 正确替代 |
|---|---|---|---|
| ⛔ 1 | **推肘 / 胸推肘 / 肘前推 / 送肘** | 激活三角肌前束 → 刚体散架 → 球软。"推肘是结果，不是动作" | "蹬 + 托" / "信任刚体" / **不要管肘** |
| ⛔ 2 | **主动前臂旋前**（5/16 加） | 内上髁炎风险（Tennis Science Ch7 p.142）；前臂是 passenger（FTT 书 p.85） | 前臂**完全没感觉** |
| ⛔ 3 | **三角肌主动抬臂** | 肩胛失稳 → fixed point 缺失 → 胸大肌力分散 → State 2 | 想"肩胛贴胸廓" / "上背绷成槽"（task imagery）|
| ⛔ 4 | **主动延迟肩转 / 主动制造 X-factor** | hip-shoulder separation catastrophe — 实际差只有 25ms，意识来不及（FTT 博客 #21） | "腹部张力"（feel-based） |
| ⛔ 5 | **主动用背"抬"小臂**（5/16 受伤模式）| 背阔肌起点在骨盆-腰椎，止点在肱骨小结节嵴；主动收缩会**拉肱骨**（旋内）不是抬小臂 → 肌腱过载 + 上臂代偿 | 背只做"等长锁定"（胶水），不做"举起"动作 |

| # | 失败模式 | 视觉症状 | 错肌肉（在做事的）| 正确肌肉（应该做的）| 体感自检（10 秒）|
|---|---|---|---|---|---|
| **F1** | **大臂主动后摆 / 上抬** | 右臂先动；肩没转手已经在身后 | 三角肌前束 + 上斜方 + 肱二头 | 前锯肌 + 下斜方 + 菱形肌（让躯干带）| 镜前 unit turn — 是"左肩往前推过来"还是"右臂往后拽"？前者对，后者错 |
| **F2** | **伪 unit turn**（只转上身不转髋）| 肩转 60-90° 但髋几乎没动 | 上斜方 + 三角肌（只有上身参与）| 臀大肌 + 腘绳 + 腹斜肌（下肢-躯干同步）| 转完看右臀有没有压实 + 右大腿后侧有没有拉伸感 — 没有 = 假转 |
| **F3** | **前臂主动旋前**（5/16）| 准备阶段拍面已经盖下来 / 前臂内侧紧 | 旋前圆肌 + 旋前方肌 | 前臂**没有肌肉应该工作** | 摸前臂内侧（肘窝下面）— 应该是软的 |
| **F4** | **用背部"抬"小臂**（5/16 受伤模式）| 拍头被"拽"到肩高，背痛 | 背阔肌做向心收缩（不应该，应该 isometric）| 肩胛上回旋力偶（前锯肌+下斜方）| 用左手摸右肩胛下角 — 转完应该是"贴住"不是"飘起来" |
| **F5** | **过早 ER 抓死** | 引拍顶点之前就把肩外旋拧到底 | 冈下肌过早进入主动收缩 | 冈下肌 isometric → 主动 ER 应在 T=700ms 启动而非 T=500ms | 双手在拍上的时刻（T=500ms）肩**还没**完全外旋；外旋发生在双手分开后 |
| **F6** | **吃肘**（pinched elbow）| 腋下夹角 < 30°，腋窝贴死 | 胸大肌过度收缩（在准备阶段）| 背阔肌 isometric + 前锯肌撑住 | 腋下塞球 drill：球被夹爆 = 吃肘 |
| **F7** | **飞肘**（flying elbow）| 顶点夹角 > 75°，肘被向外拉 | 三角肌中束主动外展 | 背阔肌 isometric 维持躯干-臂角度 | 球在 unit turn 中提早掉 = 飞肘 |
| **F8** | **塌肘**（dropping elbow）| flip 时夹角骤减到 20° | 三角肌松了重力把肘拉下 | 前锯肌 + 背阔肌持续 isometric | 球在 forward swing 早期掉 = 塌肘 |
| **F9** | **耸肩签名**（state 2）| 右肩峰高于左肩 > 2cm | 上斜方代偿 + 三角肌中束 | 下斜方 + 前锯肌（沉肩 + 贴肩胛）| 镜子背对 unit turn — 看右肩胛**下角**有没有翘起来（翼状化 = 失败）|
| **F10** | **Stop-Start Syndrome** | 引拍顶点静止 ≥ 5 帧（60fps）| 大脑切成两段："引完了 → 现在挥" | 顶点是**视觉等待**，不是肌肉死锁 | 顶点时身体应该有"装上的微颤"（quad 弹簧、背阔张力），不是僵 |
| **F11** | **Stop-Start 的反面：过早挥拍** | T=900ms 没到就开始 forward swing | 急 / 紧张 → 跳过 wait | 视觉触发（球到接触区）而非计时 | 自己数节拍 — 60 BPM 4 拍法（E.2 drill）|
| **F12** | **晚 unit turn**（最大杀手）| 球过网了还在转 | 等到看清球速才动 | T=200ms 落地 = turn 启动信号 | "球过网前 unit turn 必须完成"（FTT 书 p.74）— 80% 业余球员失败在这 |

## 6. 整合 cues

> **核心切换原则（5/6 Intuition Paradox）**：
> - **镜前 / 体感唤醒**：用 reasoning cue（找肌肉、找感觉，慢）
> - **球场 / 实战**：用 outcome cue（external focus，快）
> - **混用 = 灾难**：球场上用 reasoning → 500ms 反应窗口来不及，必然 fallback 老动作

### 6.1 镜前训练 cues（reasoning mode）

**整套用于 10 分钟"体感唤醒"，不超过这个时间。**

| 阶段 | cue | 配套动作 |
|---|---|---|
| 起跳 | "踩弹簧" | split step 三跳法（左-右-双） |
| Unit turn 启动 | "**左肩往前送**"（不是"右臂往后拉"）| 慢速 unit turn 30 次，眼盯前方 |
| 髋转 | "**右臀压实，右大腿后侧拉橡皮筋**" | 检查能不能抬左脚不失衡 |
| 双手分 | "**左手拉拍颈横过身体**" | 双手在拍上直到 T=500ms |
| 上背绷槽 | "**肩胛骨中间夹一支铅笔**" / "**肩胛贴胸廓**" | 摸右肩胛下角，确认贴住不飘 |
| 双外旋 | "**外旋锁门**"（冈下肌主动） | 摸肩后下方（不是肩顶部） |
| 维持 | "**蹬 + 托**"（绝不"推肘"）| 信任刚体，等球 |

**镜前自检 5 条**（FTT Build This Foundation 视频形状）：
1. 右肩在右髋正上方（扁担水平）
2. 左手指向右侧网柱方向
3. 能抬起左脚不失衡
4. 右脚尖朝右前方 ~45°，脚跟踩实
5. 右肩胛骨能感到夹紧（不是放松）

### 6.2 球场实战 cue（intuition mode）— **糙男 3 步**

**默认操作框架**——替换之前所有"双外旋 + Wrap + HSA + tilt"4-cue 系统。

| 步 | 动作 | 关键 |
|---|---|---|
| **1. 指高** | 左手指来球**最高点** | 拍头 / 肘还没动 |
| **2. 指肘** | 用**肘**指击球位置 | 不是用手 |
| **3. 出手** | 拍头**经过**胸前那个点 | "经过"不是"到" |

**核心原则（external focus / 外部聚焦）**：
- 想 "**拍头经过哪里**"，不想 "**身体哪个肌肉发力**"
- 想 "**球落哪里**"，不想 "**我做对了吗**"

### 6.3 不同情境的切换

| 情境 | 用哪个 |
|---|---|
| 镜前 shadow / 体感唤醒（10 min） | 6.1 reasoning cues |
| 喂球 / 多球训练 | 6.2 糙男 3 步 |
| 比赛 / 对打 | 6.2 糙男 3 步**只用 1 个**（aim 落点）|
| 失败重置 | 停 → 触诊（左手摸右肩胛骨）→ 镜前空挥 3 次（用 6.1）→ 回 6.2 |
| 同一失败模式 ≥ 3 次 | 才回 reasoning（intuition 卡 local minimum 时）|

## 7. 安全 / 伤病预防

> 来源：Tennis Science Ch7（Ellenbecker / Kibler，最高临床权威）+ Holland Osteopathy + 用户 5/16 受伤模式记录。

### 7.1 内上髁炎（Medial epicondylitis / 高尔夫肘）

**风险触发**：
- 主动前臂旋前**找上旋**（用户 5/16 失败模式 F3）
- western grip + 旋前过度（Tennis Science p.142-143）
- ball behind body in forehand（contact 落在 HSA 关闭区之外）

**警示信号**：
- 肘内侧（小指侧）酸或痛
- 拧毛巾、握拳时疼
- 击球瞬间肘内侧"刺"

**预防**：
- **绝不主动旋前**（前臂 = passenger，FTT 书 p.85）
- 准备阶段前臂内侧应该是软的（自检：摸前臂内侧）
- contact 在身体前方约一拳距离

### 7.2 外上髁炎（Lateral epicondylitis / 网球肘）

**风险触发**（Tennis Science p.142）：
- HSA 失败时前臂代偿主导加速
- weak shoulder muscles
- hit ball behind body
- tight or weak forearm muscles

**警示信号**：
- 肘外侧痛
- 抓握 / 反手时疼
- 慢性"鼓个包"（chronic overload with scar tissue — 不是 inflammation）

**预防**：
- 修上游（HSA / 肩胛 / 蹬转）→ 让肩胛和躯干主导加速 → 前臂不必代偿
- ER@90° 训练（Tennis Science p.147 协议：2-3 sets × 15 reps slow controlled）
- Sleeper stretch + cross-arm stretch（GIRD 解药，p.148）

### 7.3 二头肌肌腱炎 / 肩前痛（错误抬升）

**风险触发**：
- 三角肌前束主动抬臂（state 2 主流失败模式）
- 上斜方代偿 → 撞肩峰
- SLAP / labral 风险（Tennis Science p.141）

**警示信号**：
- 肩前 / 上方痛
- 抬手过头时"卡"
- 慢性肩疲劳

**预防**：
- **绝不三角肌抬臂**——抬到肩高靠肩胛上回旋力偶（前锯肌+下斜方）
- 每天 Wall Slide × 10 + Push-Up Plus × 8-12（前锯肌唤醒）
- Pre-point 30 秒激活：YTW 三连 + 推门感

### 7.4 后链失衡（竖脊肌弱）

**Tennis Science p.155 重要提示**："erector spinae … relatively weak and underdeveloped in elite tennis players" — 因为常规训练只练 abs。

**预防**：
- Bridging extension + Superman + Bird dog（每周 2-3 次）
- 不要只练 plank / sit-up

### 7.5 GIRD（盂肱内旋缺陷）

**Tennis Science p.144**："Elite-level tennis players often have a loss of internal rotation range of motion in the dominant shoulder."

**测量**：goniometer，仰卧 90/90 测 IR 终末角

**预防**：sleeper stretch + cross-arm stretch（每天静态 20-30s × 多次）

## 8. 推荐核心视频和文章

> 按重要性排序，每个一句话说明。

### Tier 1 — 必看（按顺序）

1. **FTT《The Forehand Press Slot》** （博客）— "Hold elbow up using scapula, lats, serratus anterior" 这一句是上肢系统的全部根本。https://faulttoleranttennis.com/the-forehand-press-slot/

2. **FTT《Build This Foundation – The Rest Will Follow》**（YouTube `0m3BMfDDShI`）— "背部胶水"概念 + 拿 2.5 磅哑铃感受背部连接的标准 drill。

3. **FTT 书 p.59-67**（Forehand 准备阶段）— 整本书最致密的 8 页。Unit Turn 定义、手臂"along for the ride"、三个动作（hip turn / hand raise / hand separation）、左手强制整体转身、握拍/手腕放松。

4. **Tennis Science Ch2 (Elliott/Reid/Crespo 2015)**— peer-reviewed 教科书。p.34 SSC 1 秒衰减 50%；p.44 蹬地 GRF 业余 1.7×BW vs 高水平 2.1×BW；p.50 "IR may only occur after impact"。

5. **FTT《The Intuition Paradox》**（博客，2026）— Reasoning vs Intuition 分工。这是为什么"知道但做不到"的根因。https://faulttoleranttennis.com/the-intuition-paradox/

### Tier 2 — 应看

6. **FTT《Scapular Glide on the Tennis Forehand》**（YouTube `6j33LJfl46s`）— 后缩 → 前伸的相位切换。"滑动门"比喻把肩胛骨从抽象变可视。

7. **Tom Allsopp《Early Preparation on the Forehand》**（YouTube `CmXxvX60TOI`）— stop-start syndrome 的最佳示范。区分"早准备"和"早完成"。

8. **Feel Tennis《The Unit Turn In Tennis》**（feeltennis.net/unit-turn）— "左肩往前"的 feel cue。Tomaz 的视觉错觉论是治"backswing illusion"的最佳处方。

9. **Tennis Science Ch7（Ellenbecker / Kibler 2015）**— Kinetic chain 临床版。p.141 SLAP prevention、p.144 GIRD、p.147 ER@90° + Seated row 训练协议。

10. **B 站糙男 RacketBrothers（BV1Hr4y1p7Sx）**— "指高 → 指肘 → 出手" 3 步实战 cue。直觉型教练的极简框架，球场实战默认调用。

### Tier 3 — 有时间再看

11. **FTT《Hip-Shoulder Separation Catastrophe》**（博客）— 25ms 真相。劝退所有"先髋后肩"的有害本能。

12. **Brian Gordon《Four Pillars of ATP Type III Forehand》**（TennisPlayer.net）— 上臂躯干 50° 夹角 + 独立手臂运动定义。

13. **Holland Osteopathy 肩关节生物力学博客**— 学术版肩关节解剖 + 损伤通路。GH 关节接触力 3,573N、肩旋速度 2,500-3,000°/s 等定量数据。

14. **PMC2465270（网球发球肩胛肌肉激活时序）**— 前锯肌 -287ms / 上斜方 -234ms / 下斜方 -120ms。证明"先锁肩胛、后加速肱骨"是物理强制顺序。

15. **庄子逸新浪博客（中文唯一同构者，2014-2016）**— 从拮抗肌角度批判中文术语；中文圈内最早讲到"双外旋锁定"的来源。
