## 一、核心肌群解剖与正手功能

### 1.1 核心肌群组成

书中将核心肌群定义为身体前面、后面和两侧的包裹性肌群，主要包括：

| 肌肉 | 位置 | 功能 | 正手中的角色 |
|------|------|------|------------|
| **腹内斜肌** | 腹外斜肌深层，纤维沿约90度角向腹外斜肌方向移动 | **促进躯干旋转** | **髋→胸传动轴的核心执行者** |
| **腹外斜肌** | 腹部两侧浅层 | **促进躯干旋转** | 与腹内斜肌协同完成旋转 |
| **腹直肌** | 腹部前面，两块垂直条状肌肉（"六块腹肌"） | 躯干屈曲 | 发球触球时收缩；正手中为辅助稳定 |
| **腹横肌** | 最深层，像天然腰带包裹身体 | 稳定骨盆和躯干 | **基础设施**：稳定旋转轴心 |
| **竖脊肌** | 沿脊椎后面，含棘肌、最长肌、髂肋肌 | 身体直立姿势 | 延伸到腰椎、胸椎和颈椎 |
| **多裂肌/腰方肌** | 深层背部肌肉 | 保持脊椎稳定和侧弯 | 深层稳定器 |
| **腰大肌（髂腰肌）** | 由髂肌和腰大肌组成 | 髋关节屈曲 | 负责大腿前弯，蹬地后的回收 |
| **前锯肌** | 胸侧，肩胛骨内侧，八块肌肉 | 肩胛骨向前伸展 | **肩胛骨前伸 = FTT 的"scapular glide"** |

### 1.2 ⭐ "肚脐左方扭转力" = 左侧腹内斜肌

**用户体感映射：**

用户在训练记录中描述的"蹬转→转髋时，肚脐左方一指处有扭转力"，从解剖学角度精确对应**左侧腹内斜肌**：

- **位置**：腹内斜肌在腹外斜肌深层，纤维方向与腹外斜肌呈约90度角
- **功能**：促进躯干旋转——这正是书中的原话
- **为什么是左侧**：右手正手时躯干向左旋转（从准备到击球），左侧腹内斜肌被拉伸后收缩产生旋转扭力
- **腹横肌配合**：最深层的腹横肌像腰带一样稳定骨盆，为腹斜肌的旋转提供稳定锚点

**解剖学验证了用户的体感发现：当动力链正确串通时，腹内斜肌作为"传动轴"被激活，产生可感知的扭转力。**

### 1.3 核心作为"传动轴"的解剖学证据

书中明确指出（p.104）：

> "在动力链中，这些肌肉大多将力量从下半身转移至上半身。"

> "记住，核心肌群作为力量总和的重要组成部分，将最初阶段身体从地面产生的所有力量通过身体的其他部位转移到球拍和球上。"

这**直接验证了 FTT 的"传动轴"概念**：

```
FTT 概念                    解剖学对应
─────────────────────────────────────────
髋→核心传导              腹斜肌（内+外）扭转
核心→胸传导              前锯肌 + 腹斜肌上部纤维
"腹部展开"(Abdominal Uncoil)  腹斜肌从预拉伸→收缩的弹性释放
传动轴稳定                腹横肌 + 多裂肌（深层稳定）
```

## 二、击球与核心肌群运动

### 2.1 击球中核心的工作机制（书中原文，p.104）

书中描述了核心在正手中的**两阶段**工作：

1. **准备发球阶段（向后挥拍）**：核心旋转肌群非常活跃，在此阶段进行**预拉伸**（即 FTT 的 "loading"）
2. **加速阶段（向前挥拍）**：再次拉伸这些肌肉，**释放身体的储存能量**以加速挥拍

> "腹内斜肌、腹外斜肌和腹直肌是主要的驱动肌肉。"

**FTT 映射：**
- "预拉伸" = Unit Turn 中肩线超前于髋线产生的躯干扭转张力（Separation Angle）
- "释放储存能量" = 腹部展开（Abdominal Uncoil），是弹性势能的释放而非主动肌肉收缩
- 这解释了为什么 FTT 说"旋转是短脉冲不是长旋转"——弹性释放天然就是爆发式的

### 2.2 核心在所有击球中的减速作用

书中特别强调（p.106）：

> "核心肌群在稳定身体方面发挥着非常重要的作用，特别是在所有击球（包括发球）的**减速阶段**。"

这对应 FTT 的：
- 随挥不是主动旋转到终点，而是惯性 + **核心肌群主动减速**
- 核心弱 → 减速能力差 → 要么手臂代偿刹车，要么旋转过度（Over-rotation）

## 三、髋→胸力量传输链的解剖学

### 3.1 完整传输路径

综合书中第6章和第7章，力量从地面到球拍的解剖学路径：

```
地面反作用力
  ↓
腓肠肌/比目鱼肌（小腿蹬伸 → 脚踝推力）
  ↓
股四头肌 + 臀大肌（膝盖伸展 + 髋关节伸展）
  ↓
髂腰肌/臀肌群（髋关节旋转）
  ↓
━━━━━━ 核心传动轴 ━━━━━━
  ↓
腹横肌（深层稳定：锁定旋转轴心）
  ↓
腹内斜肌 + 腹外斜肌（躯干旋转的执行者）
  ↓
━━━━━━ 上半身 ━━━━━━
  ↓
前锯肌（肩胛骨前伸 = Scapular Glide）
  ↓
胸大肌（Press = FTT 的"胸肌推压"）
  ↓
背阔肌（手臂-躯干连接 = FTT 的"胶水"）
  ↓
肩旋转袖（SIR = Press Slot）→ 手臂 → 球拍 → 球
```

### 3.2 ⭐ 什么会打断这条链（常见断裂点）

| 断裂位置 | 解剖学原因 | 表现症状 | FTT 对应 |
|---------|---------|---------|---------|
| **髋→核心** | 腹斜肌弱或未激活 | 髋转了但胸没跟上（"力在腰部断掉"） | 用户此前的核心问题 |
| **核心→肩** | 前锯肌弱，肩胛骨不前伸 | 肩胛骨"卡住"，上半身不参与 | FTT "scapular glide" 缺失 |
| **肩→手臂** | 背阔肌不参与，手臂脱离 | 手臂独立甩动，与躯干脱节 | FTT "arm-body disconnect" |
| **腹横肌失稳** | 深层稳定不足 | 旋转时晃动，力量泄漏 | "力量在中间消散" |

### 3.3 用户问题的解剖学解释

用户训练记录中的"力在腰部断掉"现在有了精确解剖学解释：

```
之前（力断裂）：
  蹬地(✅) → 转髋(✅) → [腹斜肌未激活] → 胸不动 → 手臂代偿

之后（力串通）：
  蹬地(✅) → 转髋(✅) → 腹内斜肌扭转(✅ "肚脐左方") → 胸部转动(✅) → 手臂被带走(✅)
```

**腹斜肌就是那个"缺失的中间环节"**。用户感受到它的激活 = 动力链第一次真正完整。

## 四、关于发力顺序：书中观点 vs FTT

### 4.1 书中的描述

书中没有明确说"从下往上"还是"躯干先发令"，但提供了关键线索：

**支持"核心为中枢"的证据：**
- p.102: "核心肌群包含在**每个运动平面**都参与运动的几大肌群"
- p.104: "核心肌群作为力量**总和**的重要组成部分" — 用的是"总和"不是"传递"
- p.104: "这些肌肉大多将力量**从下半身转移至上半身**" — 核心是中转站

**支持"腿部放大"而非"腿部发起"的证据：**
- p.124: "腿部的爆发力用处很大，但是为了能够完成这些动作，肌肉**耐力**也是极其重要的"
- 书中从未说"力量从脚开始"，说的是"地面反作用力需要通过核心传递"
- p.124: "在将力量从地面转移至身体的其他部位时，腿部发挥了重要的作用" — 腿是"转移者"，不是"发起者"

### 4.2 与 FTT 躯干时序的一致性

书中的描述与 FTT 的"躯干发令→腿部放大"模型**高度兼容**：

| FTT 概念 | 书中对应 |
|---------|---------|
| 躯干发令（Command） | 核心旋转肌群在准备阶段预拉伸 → 加速阶段释放 |
| 腿部放大（Multiply） | "带动力链，并将力量从地面转移到身体的其他部位" |
| 力量放大器 | p.121: "强壮有力的腿部是关键，因为它可以从地面获得适宜的力量" |
| 脉冲式爆发 | 核心的"释放储存能量" = 弹性势能爆发（不是持续发力） |

**关键洞察**：书中描述的"预拉伸→释放"机制天然就是脉冲式的，这为 FTT 的"短脉冲不是长旋转"提供了生理学支撑。弹性势能释放不可能是缓慢的——它必然是爆发式的。

### 4.3 没有时序数据

书中未提供肌肉激活的毫秒级时序数据。但从训练顺序看，书的结构是先练核心（第6章）再练腿（第7章），暗示核心的"质量"比腿部"力量"在训练优先级上更高。

## 五、腿部 — 力量放大器的解剖学

### 5.1 腿部肌群解剖

**大腿前侧（伸展/推进）：**
- **股四头肌**：股直肌、股外侧肌、股内侧肌、股中间肌 — 膝盖伸展，正手蹬地的主力
- **髂腰肌**（腰大肌+髂肌）：髋关节屈曲

**大腿后侧（制动/稳定）：**
- **腘绳肌**：股二头肌、半腱肌、半膜肌 — 膝盖弯曲、髋关节伸展
- **臀大肌**：髋关节伸展（蹬直），是全身最大的肌肉之一

**臀部稳定：**
- **臀中肌/臀小肌**：髋关节外展，维持骨盆水平 — 单腿支撑时的稳定器
- **梨状肌/闭孔肌/股方肌**：深层旋转肌，髋关节外旋

**小腿（推进/弹射）：**
- **腓肠肌**：大块纵向纤维肌肉，脚踝跖屈（踮脚/蹬地推进力）
- **比目鱼肌**：腓肠肌深层，耐力型推进
- **腘肌**：微旋转，打开膝关节 — 跑步/急停/变向

### 5.2 ⭐ "腿部是力量放大器而非发起者"的书中证据

书中第7章开篇（p.121）明确定位了腿部的角色：

> "带动力链，并将力量从**地面转移到**身体的其他部位"

关键词是**"转移"（transfer）**，不是"发起"（initiate）。

进一步证据：
- p.124: "显然，腿部的爆发力用处很大，但是为了能够完成这些动作，肌肉**耐力**也是极其重要的" — 强调耐力而非单次爆发
- p.121: "强壮有力且状态良好的腿部还有一个额外的好处，那就是有助于保持身体的**平衡**" — 平衡功能 > 发力功能
- p.124: 低截击需要"反复弯腰"，说明腿的核心功能之一是**姿态维持**

**这与 FTT 完美一致：腿部是放大器（amplifier）和基础设施（foundation），不是发动机（engine）。发动机是躯干旋转意图。**

### 5.3 地面反作用力机制

书中提到的地面反作用力（GRF）链条：

```
脚蹬地 → 地面产生等大反向力 → 力经由：
  腓肠肌+比目鱼肌（踝关节蹬伸）
  → 股四头肌（膝关节蹬伸）
  → 臀大肌（髋关节蹬伸）
  → 进入核心传动轴
```

p.144 特别指出小腿肌肉的角色：
> "在发球预备阶段，地面力量被转移至身体的其他部位，此时腓肠肌和比目鱼肌就开始起作用了。由于这个动作非常有力，实际上许多球员在发球时都双脚离开地面腾空跳起。"

**正手对应**：开放式站位蹬转时，后脚（右脚）的腓肠肌+股四头肌+臀肌协同蹬伸 → 产生向上和向前的地面反作用力 → 被核心"翻译"为旋转力。

## 六、训练动作与正手动力链的对应

### 6.1 核心旋转训练（第6章）

#### （1）俄罗斯式扭转 ⭐⭐⭐（最直接相关）
- **主要肌群**：腹直肌、腹内斜肌、腹外斜肌
- **辅助肌群**：前锯肌、髂肌、腰大肌、腹横肌、多裂肌
- **动作**：坐姿，躯干向左右旋转，持健身实心球触地
- **网球要点**（p.114）："着重训练击打落地球所需的动作，特别是在正手和反手击打落地球的向后挥拍阶段。在一个转体动作路线上，以不同的旋转速度进行"
- **变化动作**：在运动球上进行 → 感觉到腹斜肌收缩 → 增加不稳定面的调动
- **FTT 映射**：直接训练"腹部展开"所需的腹斜肌旋转力量，是最匹配正手的核心训练

#### （2）侧式卷腹 ⭐⭐
- **主要肌群**：腹内斜肌、腹外斜肌、腹直肌
- **辅助肌群**：前锯肌、髂肌、腰大肌、腹横肌
- **动作**：仰卧，做卷腹时转动躯干，右肘移向左膝
- **FTT 映射**：训练交叉模式（对侧连接），正手中髋→对侧肩的斜向力量传导

#### （3）平板支撑 + 侧身平板支撑 ⭐⭐
- **主要肌群**：腹横肌、腹直肌、腹内斜肌、腹外斜肌、多裂肌、竖脊肌
- **网球要点**（p.112）："在击打落地球、发球以及截击球或过顶扣球的与球接触过程中，稳定身体以击离身球和转体的能力可通过平板支撑训练进行改进"
- **侧身平板**（p.112）："大大增强了腹斜肌的肌肉刺激，这对提高转体时身体的稳定性至关重要"
- **FTT 映射**：训练腹横肌的"腰带"功能 — 稳定旋转轴心；侧身平板直接针对旋转稳定

#### （4）触足卷腹 + 转体触足卷腹 ⭐
- **主要肌群**：腹直肌、髂肌、腰大肌
- **辅助肌群**：股直肌、腹横肌、前锯肌、腹外斜肌
- **网球要点**：臀屈肌力量和腘绳肌柔韧性是网球运动中最重要的组成部分
- **转体变化**：用左手触右脚外侧 → 更大程度调用腹斜肌和前锯肌
- **FTT 映射**：训练前锯肌 = 肩胛骨前伸 = Scapular Glide 的肌肉基础

#### （5）屈膝仰卧起 + 反向卷腹
- **主要肌群**：腹直肌（仰卧起）；腹直肌+髂腰肌+腹斜肌（反向卷腹）
- **反向卷腹特点**：抬骨盆而非抬肩膀 → 训练核心下部 + 臀屈肌
- **网球要点**：击落地球和截击时依靠这些肌群让身体处于低重心状态

#### （6）游泳 + 转体游泳 ⭐
- **主要肌群**：竖脊肌、多裂肌、大菱形肌、小菱形肌
- **辅助肌群**：背阔肌、前锯肌
- **转体游泳**：举臂时轻微旋转躯干和上背部 → 调用背阔肌、腹斜肌、前锯肌
- **FTT 映射**：训练背部连接 = FTT 的"背阔肌是胶水"+ 竖脊肌稳定

#### （7）卧雪天使
- **主要肌群**：竖脊肌、多裂肌、大菱形肌、小菱形肌、背阔肌
- **辅助肌群**：后三角肌
- **网球要点**（p.118）："保护背部免受损伤…强化发球和过顶扣球的随球动作中向心收缩的肌肉…上背部保持稳定有时被称为肩胛骨稳定"
- **FTT 映射**：直接训练肩胛骨稳定 + 菱形肌（scapular retraction 的执行者）

#### （8）俯卧两头起 + 超人飞
- **主要肌群**：竖脊肌、多裂肌、大菱形肌、小菱形肌、臀中肌
- **网球要点**（p.120）："由于许多网球击球方法都需要交叉动作，因此具有良好的平衡和上下肢的相反控制非常重要"
- **超人飞**：同时抬大腿和手臂 → 调用腹横肌和臀部稳定肌
- **FTT 映射**：训练对角线力量传导（正手中的对侧连接：右脚→左肩的力线）

### 6.2 腿部训练（第7章）

#### （1）深蹲 ⭐⭐⭐
- **主要肌群**：臀大肌、臀中肌、股外侧肌、股直肌、股内侧肌、股中间肌
- **辅助肌群**：缝匠肌、股薄肌、长收肌、短收肌、大收肌、竖脊肌、多裂肌、腹横肌
- **网球要点**（p.126）："网球运动中的每次击球都需要一个类似于深蹲的姿势…深蹲训练锻炼的肌肉包括臀部肌肉和腿部肌肉，能够提供一个坚实的基础，让球员**将力量从地面转移到躯干和肩部**的肌肉上"
- **FTT 映射**：训练"力量放大器"的基础力量；每次击球前的loaded position就是半蹲
- **变化**：颈前深蹲 → 主要集中锻炼股四头肌

#### （2）罗马尼亚硬拉 ⭐⭐
- **主要肌群**：股二头肌、半腱肌、半膜肌、臀大肌、竖脊肌
- **辅助肌群**：肱二头肌、背阔肌、前臂肌
- **网球要点**（p.128）："对所有的网球击球都有益，尤其对改善正手和反手击打落地球更为重要…不仅有助于增强下背部的肌肉和腘绳肌，也有助于提高它们的灵活性"
- **FTT 映射**：训练后链（posterior chain）— 臀大肌+腘绳肌+竖脊肌 = 蹬地→伸髋的完整链条
- **离心力量**：增强臀部伸肌的离心力量 → 着陆和变向的减速能力

#### （3）弓步下蹲（前弓步、侧弓步、45度弓步、交叉弓步）⭐⭐
- **前弓步主要肌群**：臀大肌、臀中肌、股直肌、股中间肌、股外侧肌
- **侧弓步主要肌群**：长收肌、短收肌、臀中肌、股薄肌、缝匠肌
- **45度弓步主要肌群**：股直肌、臀大肌、股中间肌
- **交叉弓步主要肌群**：股直肌、臀大肌、臀中肌、臀小肌、股中间肌

**网球要点汇总：**
- 前弓步（p.132）：模拟正手与反手截击时身体的姿势
- 侧弓步（p.134）：模拟截击远身球的运动模式，外展肌与内收肌都活跃
- **45度弓步**（p.136）：**"最接近网球截击中所使用的技术"** — 教会球员在触球时将身体重量向前方转移
- 交叉弓步（p.138）：与封闭式站位打落地球的动作类似，模拟单手反手

**FTT 映射**：弓步 = 正手击球时的步法，特别是开放式→半开放式的重心转移训练

#### （4）腘绳肌拉伸（Hamstring Curl）⭐
- **主要肌群**：股二头肌、腘肌、半腱肌、半膜肌、臀大肌、臀中肌
- **辅助肌群**：腓肠肌、比目鱼肌
- **网球要点**（p.130）："改善腿筋和臀部伸肌的强度和稳定性…在开放式站位击打落地球的着陆阶段，需要腿筋和臀部的离心力量"
- **FTT 映射**：着陆后的稳定 = 腿部"制动器"功能

#### （5）跳箱 ⭐⭐⭐（高级爆发力）
- **主要肌群**：臀大肌、臀中肌、股直肌、股外侧肌、股内侧肌、股中间肌
- **辅助肌群**：股二头肌、半腱肌、半膜肌
- **网球要点**（p.140）："重点是训练腿部爆发力运动，在比赛过程中，比如改变方向时，需要经常用到它…在将力量从地面转移至身体的其他部位时，腿部发挥了重要的作用"
- **FTT 映射**：训练"氮气加速"能力 — 躯干启动旋转后，腿部爆发式蹬伸的力量
- **仅限高级球员**：需要先建立腿部力量基础

#### （6）深蹲跳 ⭐⭐
- **主要肌群**：腹直肌、股二头肌、半腱肌、半膜肌、腓肠肌、比目鱼肌
- **辅助肌群**：竖脊肌、臀大肌
- **网球要点**（p.142）："提高腿部肌肉组成部分的力量和速度…在网球赛场上，可以帮助球员在运动时尽可能缩短触地时间，实现更快速地移动和转变方向"
- **FTT 映射**：训练快速蹬伸-落地循环，正手中后脚的快速蹬转

#### （7）提踵（Calf Raise）⭐
- **主要肌群**：腓肠肌、比目鱼肌
- **网球要点**（p.144）："小腿肌肉的任务是使脚部跖屈，这是一个非常重要的运动，因为它可以产生奔跑与跳跃所需的强有力的推动力…腓肠肌作为一大块纵向纤维肌肉，产生了这种推出的力量"
- **FTT 映射**：蹬地的"最后一英寸"推力，虽然不是主要发力源但影响GRF的质量

## 七、伤病预防：核心弱→手臂代偿的解剖学解释

### 7.1 书中的警示

书中多处暗示了核心弱化导致的代偿模式：

p.104:
> "适当的核心肌群准备不可或缺…这将有助于防止受伤并在球场上发挥更好的水平。"

p.112:
> "平板支撑对于**预防核心肌群和臀部肌肉损伤**也非常重要，而这些部位是网球运动员**容易损伤的部位**。"

### 7.2 ⭐ 核心弱→手臂代偿的因果链

结合书中解剖知识和 FTT 理论，构建完整的代偿因果链：

```
核心肌群弱（特别是腹斜肌）
  ↓
髋旋转力量无法传递到肩线
  ↓
肩线旋转不足 → 手臂未被"甩开"
  ↓
大脑检测到"球拍速度不够"
  ↓
自动调用手臂肌肉补偿速度
  ↓
小臂代偿：主动甩腕/scooping/elbow extension
  ↓
长期结果：
  ├─ 网球肘（肱骨外上髁炎）— 前臂伸肌过劳
  ├─ 腕关节损伤 — 手腕过度负荷
  ├─ 肩袖损伤 — 手臂独立发力时旋转袖超负荷
  └─ 动力链效率低 → 力量小、稳定性差、容错性崩溃
```

### 7.3 用户问题的解剖学解释

用户的"小臂代偿"问题（详见 `19_forearm_compensation_analysis.md`）从解剖学角度看：

1. **根因**：腹斜肌（特别是腹内斜肌）未被有效激活 → 核心传动轴断裂
2. **代偿路径**：力从髋到腰就断了 → 大脑命令手臂自行发力
3. **修复关键**：激活腹斜肌（用户已经做到 — "肚脐左方扭转力"）+ 建立手臂-躯干连接（"腋下夹住"）
4. **训练支撑**：俄罗斯式扭转 + 侧式卷腹 = 直接强化传动轴

## 八、训练处方：基于本书的核心+腿部训练计划

### 8.1 针对用户当前阶段的优先级

用户已经突破了"感知到核心"的阶段（肚脐左方扭转力），现在需要：
1. **强化核心旋转力量** → 让传动轴更粗壮可靠
2. **训练腿部爆发力** → 让"氮气加速"更猛
3. **训练核心稳定性** → 让旋转轴心更稳

### 8.2 推荐训练动作（按优先级）

**第一优先级：核心旋转（直接改善正手）**

| 动作 | 组数x次数 | 目标 | 对应正手功能 |
|------|---------|------|------------|

| 侧式卷腹 | 3x15每侧 | 腹斜肌+前锯肌 | 交叉模式力量传导 |
| 侧身平板支撑 | 3x30秒每侧 | 腹斜肌稳定性 | 旋转时的抗侧屈能力 |

**第二优先级：核心稳定（防止力量泄漏）**

| 动作 | 组数x次数 | 目标 | 对应正手功能 |
|------|---------|------|------------|
| 平板支撑 | 3x45秒 | 腹横肌+全核心 | 旋转轴心稳定 |
| 俯卧两头起 | 3x10每侧 | 竖脊肌+对角线 | 后链稳定+对侧连接 |
| 转体触足卷腹 | 3x12每侧 | 腹斜肌+前锯肌 | 肩胛骨前伸力量 |

**第三优先级：腿部力量（放大器升级）**

| 动作 | 组数x次数 | 目标 | 对应正手功能 |
|------|---------|------|------------|
| 深蹲 | 3x12 | 股四头肌+臀肌 | 蹬地力量基础 |

| 侧弓步 | 3x10每侧 | 内收肌+臀中肌 | 横向移动稳定 |
| 提踵 | 3x15 | 腓肠肌+比目鱼肌 | 蹬地最后推力 |

**第四优先级：爆发力（进阶，力量基础建立后）**

| 动作 | 组数x次数 | 目标 | 对应正手功能 |

书中建议（p.104）：
- 核心训练一天训练、一天休息
- 许多训练不需要使用器械，自身体重可充当阻力
- 速度不是重点，应用适当技巧完成
- 注意前面和后面、两侧的**平衡**训练

## 十、总结：三个核心洞察

### 洞察1：腹内斜肌是动力链的"最后一块拼图"

用户的整个学习旅程可以用这本书的解剖学来回顾：
- 先学会了"胸肌 press"（核心→肩的上半段）
- 再学会了"蹬地转髋"（地面→髋的下半段）
- 最后感知到"肚脐左方扭转力"（腹内斜肌）= **中间环节终于接通**
- 解剖学证实：腹内斜肌就是髋旋转→肩旋转的生理中转站

### 洞察2：弹性势能释放机制支持"脉冲式"发力

书中描述的核心工作机制（"预拉伸→释放储存能量"）为 FTT 的"短脉冲不是长旋转"提供了生理学解释：
- 弹性势能的释放天然就是**爆发式**的，不可能缓慢
- 这就是为什么"想着转一整圈"反而没力量——你把弹性释放变成了主动肌肉收缩
- 正确做法：制造预拉伸（Unit Turn 的 Separation Angle）→ 让它**自己弹回来**

### 洞察3：训练核心 > 训练腿部 > 训练手臂

从这本书的角度，网球力量训练的优先级应该是：
1. **核心旋转力量**（腹斜肌）— 传动轴的"粗度"决定了能传递多少力
2. **核心稳定性**（腹横肌）— 轴心的"刚度"决定了传递效率
3. **腿部力量**（股四头肌+臀肌）— 放大器的"倍率"
4. **手臂**？书中第6章和第7章都没提到手臂需要主动训练来增强击球力量——因为手臂是传递者，不是发动机

这与 FTT 的核心哲学完全一致：**正手的力量来源于旋转，不是来源于手臂。**
