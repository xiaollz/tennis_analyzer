# Scapular ESR Cocking Spring Model

> 写作日期：2026-05-28
> 触发：用户提出“肩胛骨后缩 + 肩外旋像手枪上膛，压缩弹簧后释放”的体感模型。
> 状态：个人机制整合节点。它连接 FTT Scapular Glide / Build This Foundation、Bourne ESR、Tennis Science / Kibler 肩胛漏斗、5/8 ESR 根因和 5/3 HSA 框架。

---

## 0. 一句话结论

用户的体感方向是对的：

**准备阶段的核心不是把右大臂单独拉到后面，而是肩胛骨后缩/稳定 + 肱骨 ESR 共同把右大臂锁进胸背结构。这个状态像“上膛”：后侧肩胛-旋袖系统建立张力，IR 群被预拉伸并被 ESR 抑制；释放时，躯干旋转 + HSA + ISR + 肩胛前伸把能量沿着手臂和球拍传出去。**

更短的操作语言：

> 肩胛后缩稳住发射台，ESR 拧上弹簧；前挥时身体转开，胸背释放，拍头自然甩出。

### 2026-08-23 顺序校正：不是三个串行步骤

对用户而言，`ESR 第一帧启动` 仍是最高优先的个人防错入口：它能先抑制 IR 抢跑和右臂主动后拉。但这不表示真实动作要做成“先完全 ESR并停住，再单独 retraction，最后主动 elbow extension”。更准确的肩胛-肱骨协同是：

```text
Unit Turn + 左手组织球拍
  -> ESR 立即开始，建立肱骨朝向
  -> 轻度肩胛后缩 / 贴胸廓 / 上回旋与 ESR 重叠，维持高度和离身宽度
  -> 肘关节夹角按风格和来球需要部分打开
  -> 有支撑地进入转换，前挥中肩胛逐渐前伸
```

三个术语必须解耦：

- `ESR`：肱骨绕自身长轴外旋；肘可相对肩保持安静，但会随胸廓和肩胛在空间中移动。ESR 本身不等于抬肘。
- `Scapular retraction`：肩胛骨沿胸廓向脊柱方向适度滑动并提供稳定；它不负责把球拍大幅拉向后场，也不能最大幅度夹死。
- `Elbow extension`：肘关节夹角变大。它与 retraction 不是同一个动作，也不存在必须绑定的先后关系。

FTT 书允许两种正手风格：引拍期间较早、部分打开肘角的 Federer 型，以及保持更多屈肘、由前挥动量继续打开的 Nadal 型。共同边界是不能在前挥前把肘锁死。对用户当前曲臂模型，默认保留舒适屈肘，只允许肘角在引拍末段到前挥中自然、部分打开；若主动伸肘导致手向后跑、肩胛支架消失或转换停顿，就取消该动作。

## 1. 这到底是不是“压缩弹簧再释放”？

是，但要精确一点：这不是单一弹簧，而是一个 **scapula-humerus spring system**。

### 1.1 上膛阶段

```
右脚轴 + Unit Turn
  -> 躯干转开
  -> 肩胛骨后缩 / 下沉 / 贴胸廓
  -> 肱骨 ESR
  -> 胸大肌、肩胛下肌、背阔肌等 IR 群被预拉伸
  -> 冈下肌 / 小圆肌激活，IR 抢跑被反射抑制
```

这个阶段的“爽感”来自几个东西叠加：
- 肩胛骨像滑动门一样向后收，背部有被拉紧/夹住的感觉；
- 肱骨外旋让肩后侧和旋袖有“拧紧”感；
- 胸前侧被轻微拉开，但不应该主动发力；
- 整条右大臂不再是自由摆锤，而像被胸背结构托住。

### 1.2 释放阶段

```
前挥视觉信号
  -> 躯干短脉冲旋转
  -> 保持肩胛发射台，不让右大臂脱离
  -> HSA 窗口出现，胸-肱角闭合
  -> ISR / pronation / racket flip 作为下游释放
  -> 肩胛前伸包裹胸廓，完成缓冲
```

这里的“伸展出去”不是主动把肩膀或肘往前捅，而是能量被释放到末端。肩胛骨在随挥中前伸，像把胸廓包住；拍头和前臂的翻转是释放结果，不是主动小臂动作。

## 2. 参与肌肉地图

### 2.1 肩胛骨层：发射台

| 肌肉 | 主要作用 | 正手中的角色 |
|---|---|---|
| 菱形肌 | 后缩肩胛骨 | 上膛时把肩胛向脊柱方向收住 |
| 中斜方肌 | 后缩肩胛骨 | 与菱形肌一起建立背部“夹住”感 |
| 下斜方肌 | 下沉、后倾、稳定肩胛 | 防止耸肩，给肱骨外旋留下空间 |
| 前锯肌 | 肩胛贴胸廓、前伸、上回旋 | 让肩胛骨不翼状化；释放和随挥时包裹胸廓 |
| 背阔肌 | 胶水、连接大臂与躯干 | FTT “back is the glue”的核心体感之一 |

关键：肩胛骨不是死锁不动。健康模式是 **准备期后缩/稳定，释放期受控前伸**。错误模式是准备期就漂、耸、翼状化。

### 2.2 肱骨/旋袖层：ESR 锁门

| 肌肉 | 主要作用 | 正手中的角色 |
|---|---|---|
| 冈下肌 | 肩外旋主力 | ESR 的首要肌肉，肩后下方“拧”的感觉 |
| 小圆肌 | 肩外旋协同 | 与冈下肌一起维持外旋锁 |
| 冈上肌 | 盂肱关节稳定 + 外展平台 | 不是主要发力源，但提供稳定 |
| 肩胛下肌 | IR 主力之一 | 准备阶段被 ESR 预拉伸/抑制，释放期参与 ISR 链 |

ESR 对用户的第一作用不是“更有力”，而是 **抑制 IR 抢跑**。这点沿用 5/8 ESR 根因文档：先当刹车，再当蓄力。

### 2.3 胸-肱层：HSA 释放窗口

| 肌肉 | 主要作用 | 正手中的角色 |
|---|---|---|
| 胸大肌 | 水平肩内收 / IR | 接近击球窗口时闭合胸-肱角，进入 HSA 释放 |
| 三角肌前束 | 肩屈 / IR 协同 | 容易抢跑；主动顶肩、推肘时通常是它在接管 |
| 肱二头肌 / 前臂屈肌 | 远端补偿 | 如果大臂脱离身体，小臂上端/捞球会出现 |

胸大肌的健康参与必须建立在肩胛稳定上。肩胛飘时，“用胸”会变成肩/大臂整体前扑；肩胛稳时，胸肌才有 fixed point 把大臂带过球。

## 3. 和已有知识库的对齐

### 3.1 FTT

| FTT 概念 | 本模型对应 |
|---|---|
| Build This Foundation | 背部肌肉是胶水；右大臂不独立悬挂 |
| Scapular Glide | 后缩建立发射台，前伸完成释放/缓冲 |
| Place, Pull Forward | 上膛完成后不再二次往后拉，只从结构中向前 |
| Press Slot | 肩胛稳定 + ESR 后，HSA 有发力窗口 |
| No Backswing | “往后”来自身体转动和肩胛/肱骨结构，不是右大臂独立后拉 |

### 3.2 Bourne / One Minute Tennis

| Bourne 概念 | 本模型对应 |
|---|---|
| Hiding the Elbow | ESR 的 external-focus 表达 |
| Showing the Shoulder | ISR/释放后的外部标记 |
| Hold onto the Ball | 左手和拍喉的触觉锚，强制 unit turn 与右臂被动 |
| Power Point | 用触觉替代抽象身体 cue，减少球场上右手接管 |
| No wrist snap | 末端释放不是主动腕鞭 |

### 3.3 Tennis Science / Kibler

Tennis Science 对本模型的支撑点：
- kinetic chain 不是局部发力，肩是腿/躯干到拍臂的能量漏斗；
- 肩胛控制、rotator cuff balance、scapular stabilizer 是健康和发力的共同基础；
- weak shoulder / poor scapular control 会让前臂和肘部代偿；
- ER@90、seated row、sleeper / cross-arm stretch 是肩胛-旋袖健康训练的基本处方。

### 3.4 ESR / HSA 项目体系

```
右脚轴
  -> Unit Turn
  -> 肩胛后缩/稳定 + ESR 上膛
  -> IR 抢跑被抑制
  -> HSA 释放窗口
  -> ISR / pronation / racket release
```

这说明：ESR、肩胛槽、HSA 不是三个独立 cue，而是一个相位链。

### 3.5 高位准备补全：上回旋支撑不等于后缩夹死（2026-08-11）

Ascended Athletics `E6EllpflfuQ` 补上了本模型此前偏重“后缩 + ESR”、但没有讲清的准备高度问题。高位准备首先来自**胸廓保持高且宽**，肩胛骨上回旋作为辅助支撑，使手臂像被托住而不是向肋骨内塌。可用手位范围约为胸骨/胸口下缘到嘴鼻高度，拍头高于手，肘与肋骨保留舒适空间。

```text
胸廓高且宽（主支架）
  + 肩胛上回旋（辅助支撑）
  -> 手/肘结构悬浮在合理高位
  -> 前挥开始后拍头获得动态 drop 空间
  -> 减少整臂先掉低、小臂再向上救球
```

这和后缩/ESR 上膛不是两个互斥动作，而是肩胛骨在胸廓上的动态协作：上回旋负责架起准备空间，受控的后缩/稳定与肱骨 ESR 建立张力，释放时再前伸包裹胸廓。不能把“背托住”执行成夹紧肩胛骨不动。

永久边界：

- 不是单靠肩胛骨把手硬举高；盂肱关节、三角肌和旋袖仍正常协同。
- 不耸肩，右肩不能向耳朵靠近；上斜方肌抢做会制造颈肩紧张。
- 不是越高越好；过高会增加路径和张力。Sinner 的手位相对低，但肘和手臂仍宽且有支撑。
- “需要极强肩胛力量、容错更低”没有视频依据；合理高位反而有助于节奏与重复性。

专项来源：`docs/research/coaches/ascended_athletics/E6EllpflfuQ.md`。

### 3.6 High Set 到稳定槽：下降不等于塌陷（2026-08-13）

FTT `wzLMv4ASg9s` 进一步说明，高位 loop 后手臂允许向后、向下进入一个背部稳定的 slot。此时中/下斜方肌、背阔肌和菱形肌提供以等长为主的 `back stability`；主观上支撑可保留至触球，随挥时再释放。

```text
正确：高而宽地准备 -> 背部基座仍在 -> 手臂向后下方落入稳定槽 -> 向外释放
错误：高位准备 -> 背部支撑消失 -> 手/肘/拍整体塌低 -> 小臂向上救球
```

因此，VLM 和人工复核不能再把“手位下降”单独判错；必须同时观察肩是否耸起、手肘结构是否失控、前挥是否先向外行进，以及触球前是否出现急剧反向上抬。High Set 的肩胛上回旋支撑与 FTT 的 `in and down` 稳定描述的是相邻阶段，不应被合并成一个冻结姿势。

专项来源：`docs/research/ftt/video_analyses/wzLMv4ASg9s.md`。

## 4. 用户当前问题的解释

用户近期视频和体感中的问题：

> 右大臂会独立往高、往后；击球时小臂斜向上补偿；镜前能做，球场看到球就回到右手发力。

在本模型里，根因链是：

```
看到球 -> 大脑进入“击打”任务
  -> 右侧易激活肌抢跑（三角肌前束 / 二头 / 前臂）
  -> 肩胛后缩 + ESR 上膛没有保持
  -> 右大臂相对躯干独立后拉/上抬
  -> 蹬转力传不到大臂
  -> 拍头 drop 后身体带不过去
  -> 小臂斜向上捞/补 through
```

所以“小臂上端”不是根因；它是肩胛-ESR 上膛失败后的末端救球动作。

## 5. 正确体感 vs 危险误读

| 正确 | 错误 |
|---|---|
| 肩胛后缩/贴胸廓，像发射台 | 右肩主动往后夹死 |
| ESR 是肱骨自转，拍头朝天/手背方向变化 | 用小臂翻拍或手腕扭拍 |
| 大臂跟胸背成为一个 unit | 大臂夹死贴身、不留肘部空间 |
| 释放时身体带大臂，拍头落后 | 肩膀往前捅、主动顶球 |
| 前臂/腕是末端被动释放 | 主动 wrist snap、主动小臂上端 |
| 爽感来自张力建立 + 自动释放 | 用力憋紧、肌肉僵死 |

## 6. 训练与自检

### 6.1 10 秒自检

1. 站到正手准备位。
2. 右手模拟架拍，左手摸右肩胛下角/内侧缘。
3. 做慢速 Unit Turn + 轻 ESR。
4. 检查：
   - 肩胛是否贴着肋骨向后滑，而不是耸肩；
   - 肩后下方是否有轻微“拧紧”感；
   - 右大臂是否仍和胸背同步，没有自己往后找球；
   - 小臂/手腕是否没有主动做事。

### 6.2 家练顺序

| 顺序 | Drill | 目标 |
|---|---|---|
| 1 | Wall slide / push-up plus | 唤醒前锯肌 + 下斜方稳定 |
| 2 | ER@90 弹力带 | 建立冈下肌/小圆肌 ESR 锁 |
| 3 | 轻哑铃或拍子高位 hold-up | 感受背部胶水托住大臂 |
| 4 | 双手扶拍 unit turn | 把肩胛/ESR 上膛合进整体转 |
| 5 | Topspin Pro / 发球机低速 | 只验证右大臂是否仍跟胸背走 |

### 6.3 球场 cue

球场上不要想肌肉列表。只保留一个短 cue：

> 背后上膛，肩头带大臂过球。

如果这个 cue 让你主动顶肩，立刻改成：

> 背贴住，球进路径。

## 7. VLM 观察点

后续视频诊断应单独观察：

1. Unit Turn 完成时右肩是否耸高，还是肩胛稳定贴胸廓；
2. 右大臂是否相对躯干独立后拉/上抬；
3. 前挥启动时大臂是否跟胸背一起移动，还是右手/小臂先动；
4. 拍头 drop 是否发生在身体启动后，而不是手动预先摆低；
5. 接触前后小臂是否出现主动上端/翻腕救球；
6. 随挥中肩胛是否受控前伸包裹胸廓，而不是肩膀顶出去。

---

## 8. 结论

这个模型补齐了“为什么左手辅助不够”的上游解释：

左手可以帮助启动 unit turn，但真正阻止右大臂乱跑的是 **肩胛骨稳定 + ESR 锁门**。如果肩胛发射台没稳、ESR 没在第一帧上膛，右大臂仍会在看到球时接管；如果肩胛和 ESR 到位，右大臂会被胸背结构带着走，好的 lag 才会留给拍头，而不是发生在大臂和身体之间。
