## 1. FTT 独特术语与概念（视频里反复出现的）

| 术语 | 含义（FTT 用法） | 来源视频 |
|---|---|---|
| **Press Slot** | 触球前手部到达的"压迫槽位"。所有职业正手无论引拍风格不同，进入击球区瞬间到达**同一个**位置。 | `wVa4XQPcaqs`, 综合 |
| **Place, Pull Forward** | 取代"Backswing"的口令：把手"放置"到位 → 直接"向前拉"。否定"先往后再往前"的二段式心理表象。 | `0m3BMfDDShI` |
| **Hold it Up** | 准备结束时拍头要"撑住"，禁止主动向后/向下翻滚——任何后翻都应是动力学副产品。 | `0m3BMfDDShI` |
| **Unit Turn / Unit Swing** | 身体作为一个整体转，左右手必须同步；不是"先转身再挥臂"。 | `0m3BMfDDShI` |
| **Build This Foundation** | "最简有效正手"——地基 = 一种连接状态，不是动作细节。 | `0m3BMfDDShI` |
| **Scapular Glide** | 肩胛骨在肋骨上"滑动门"式：后收+外旋 → 前推+内旋。**前提是肘部空间存在**。 | `6j33LJfl46s`（13）+ 综合 |
| **Press Wall Test** | 静态推墙验证准备结构是否能传力——Johnny 把抽象 slot 物理化的标志性方法。 | `wVa4XQPcaqs` |
| **Innervation / Pivot Point** | 准备阶段对球拍的"神经支配"：用手指（尤其是食指指节背、小指掌根）建立触觉映射，挥拍从"神经接通球拍"开始。这是用户问的 **grip "micro-zone bonding"** 的 FTT 原版表达。 | `pWzyP-xfLfU` |
| **Flush Roll Back** | 引拍切换到前挥的瞬间，拍面相对一个垂直平面"平整"地后滚，而非翻转/开面。 | `wd4YRQW3TOc` |
| **Multi-Split-Step** | 球机/无对手节奏时，用连续多次小分腿垫步保持神经兴奋。 | `BbGzWTp5pCM` |
| **Triple Bend** | 准备时踝/膝/髋同时弯曲——FTT 把"动力链加载"的视觉判据简化成这一条。 | `FOmz8Wjv3DQ` |
| **Landing in Motion** | 分腿垫步落地必须直接转化为向球的第一步，禁止"先落定再启动"。 | `FOmz8Wjv3DQ` |
| **Apparatus（装置）** | 肩-臂-拍在跑动中保持为一个刚性整体"挂"在背上，不随移动晃动。 | 综合（Khachanov 视频） |
| **Arm in Ready State** | 移动中手臂保持准备结构，绝不用手臂摆动来平衡——平衡交给腿和核心。 | `42BfbKsTGb4` |
| **X Stretch** | 准备完成时左肩↔右髋的对角线拉长，作为肩髋分离的"可视证据"。 | `wFIrPMutzRo` |

## 2. 视觉诊断标准（FTT 在视频里说"我看的是这些"）

FTT 教练在画面上看 Unit Turn / 准备的判据，按优先级：

1. **背部胶水状态（Lats Glue）**：球衣背部是否出现肩胛骨工作的褶皱；非持拍侧肩胛骨是否先于手臂启动。
2. **腋下空间（Elbow Space）**：肘部是否离开躯干、腋下保持稳定的"窗口"。该空间在整段简单挥拍中**几乎不变**。
3. **Triple Bend**：踝、膝、髋都有明显角度（不是只蹲膝、不是只折髋）。
4. **Stance Width > 肩宽**：宽站姿——他们专门在 Nadal 视频里强调这条作为练习/比赛差距的根因。
5. **拍头"撑住"**：准备结束的瞬间，拍头不主动向下或向后翻滚。
6. **拍面 Flush（平整）**：引拍末端拍面不开放、不极端关闭，处在"镜子面"角度。
7. **左右手同步性**：双手是否在 Unit Turn 中作为一对同时开始、同时停止。
8. **手部到 Press Slot 的距离一致性**：无论上一拍多狼狈，准备结束时手到达的"虚拟槽位"相对躯干位置应稳定。
9. **眼/球凝视**："冷静凝视"森林而非叶子——准备阶段眼睛锁向球而非脚下。

## 3. 推荐拍摄角度（FTT 频道里反复用的）

FTT 没有专门一期"how to film yourself"，但他们自己的演示固定使用三种角度，可视为隐含的拍摄推荐：

| 角度 | 用途 | FTT 观察的内容 |
|---|---|---|
| **正侧面（base-line side, 90°）** | 分析 Unit Turn 完整度、肩髋分离、Place/Pull、肘部空间 | 肩线 vs 髋线分离角；肘是否离体；拍头是否 Hold up |
| **正后方（球员背后，沿击球方向）** | 分析肩胛骨滑动、左手位置、X 拉伸 | 球衣背褶；Off-shoulder blade 启动信号；左肩是否过中线 |
| **斜前方 45°（fence corner）** | 分析握拍/手指支配、拍面角度、Flush Roll Back | 拍面镜像；Press Slot 到达；手指对柄底盖的支撑 |
| 60 fps 慢速 | 所有逐帧分析的标配（user 偏好已确认）| 用 `,` `.` 键逐帧数从拍头释放到触球的帧数（应≈3 帧） |

> 关键：FTT 反对单纯正面对镜头——正面看不到肩髋分离也看不到 slot。

## 4. 常见错误及 FTT 的术语化解释

| FTT 称呼 | 视觉表现 | FTT 给的因果链 |
|---|---|---|
| **"Backswinging"** | 球员主动把拍往后挥 | 心理表象错→拍头不必要后翻→挥拍路径过长→比赛时间压力下崩溃 |
| **拍头 Drops too early** | 准备结束就主动垂拍头 | Hold up 失效→需要更长前挥距离→Press Slot 错位 |
| **Open face on roll back** | 引拍末端拍面开放 | 触发"捞球"代偿（DC02），上旋窗口变窄 |
| **Elbow Collapse** | 肘塌进躯干 | 锁死肩胛骨滑动空间→必须由小臂代偿（C25） |
| **"Soft arm"（软臂）** | 背部不发力支撑 | 拍面角度漂移→击球稳定性塌方 |
| **Narrow stance** | 站姿窄于肩 | 重心垂直起伏→拍头轨迹不稳→网/出 |
| **Loose grip seam** | 准备时手指与拍柄之间有间隙 | 神经支配未建立→所有后续动力链是"盲发力" |
| **No Multi-Split-Step on ball machine** | 球机训练时只跳一次 | 缺少对手节奏→神经兴奋下降→比赛"找不到节奏" |
| **Arm used for balance** | 跑动中持拍臂前后摆动 | 手臂离开"准备状态"→无法保持 Apparatus 刚性 |
| **Land then start** | 分腿落地后才启动 | 错过 Landing in Motion 窗口→第一步迟 1 拍 |

## 5. 节奏和时机（FTT 视频里反复讲的几条规则）

1. **分腿垫步定时**：在对手击球的瞬间处于跳起最高点，而不是落地点。
2. **Landing in Motion**：落地必须已经在向球移动的过程中，不能"先稳后冲"。
3. **Time Window Overlap**：躯干启动旋转时，小臂仍处在向后翻转中——这一段重叠是"动态拉伸"窗口；停顿即丢失弹性。
4. **拍头"挂"在背上要早**：跑动击球时球拍必须**提前**挂上背部 Apparatus，不要等靠近球才准备。
5. **准备完成 ≠ 静止**：准备完成的标志是"Place 已完成 + 神经支配建立 + Hold up"，不是身体停下来。
6. **释放窗口**：拍头超越手部 → 触球，60 fps 下应≈3 帧；≥5 帧 = 释放过早 → 触发腕部代偿。
7. **加速不改变基础**：比赛节奏加快只允许"加大转体意图"，禁止改造引拍结构。

## 6. 与 FTT 书内容的对比 —— 视频独有的部分

下列内容在 FTT 书里**没有**或只是文字提及、视频才提供视觉/动作判据：

| 视频独有 | 为什么书里没有 |
|---|---|
| **球衣背部褶皱**作为肩胛骨滑动的可视证据 | 书里只描述"glide"，没有教你看哪 |
| **Press Wall Test**（推墙验证 slot） | 是动态实操，文字描述不出反作用力体感 |
| **Flush Roll Back vs 翻面引拍**的拍面对比 | 必须看连续帧才能区别 |
| **Place / Pull Forward 心理口令** vs "Backswing" | 是口令更替，视频用并排示范才有效 |
| **Multi-Split-Step**（球机训练） | 书侧重比赛情境；视频补了无对手训练场景 |
| **Triple Bend** 作为踝/膝/髋的统一视觉判据 | 书分散讨论各关节，视频做了合并 |
| **Landing in Motion** 的分腿垫步落地→第一步连续性 | 必须看动作 |
| **Innervation / Pivot Point**（手指握拍微区) | 这是 FTT 视频时代才提出的术语，对应用户说的"micro-zone bonding"——书里只讲东方/半西方握拍，不讲手指神经映射 |
| **X Stretch** 的对角拉伸视觉化 | 视频用慢动作直接画线 |
| **Apparatus（装置）刚性** 在跑动中的保持 | 书里没有这个比喻 |
| **Arm in Ready State**（移动中不要用手平衡） | 比较反直觉，必须看示范 |

## 8. 给 VLM 的可执行检查清单（从 FTT 频道独家提取）

准备阶段（Preparation / Unit Turn）VLM 应输出的 9 个二值/分级判据：

1. `back_glue_active`：非持拍侧肩胛骨是否先于手臂启动？
2. `elbow_space_stable`：腋下窗口是否存在并保持稳定？
3. `triple_bend_present`：踝/膝/髋是否同时弯曲？
4. `stance_wider_than_shoulders`：站姿宽度 > 肩宽？
5. `racket_head_held_up`：准备末端拍头是否未主动后翻/下垂？
6. `face_flush_at_rollback`：引拍末端拍面是否处于"镜子面"（非开/非过闭）？
7. `hands_synchronized`：双手是否同时开始、同时停止 Unit Turn？
8. `split_step_landing_in_motion`：分腿落地是否直接接第一步，无静止帧？
9. `grip_innervated`：准备阶段是否能看到手指对柄的微调（非死握、非松垮）？

每条不达标对应 FTT 的标准口令（见 §7），可直接由报告生成器调用。
