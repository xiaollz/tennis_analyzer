## 新 VLM 问题（6 个）

加在 prompt 末尾的 `EXTRA OBSERVATIONS` 段：

- **Q33** 击球瞬间脊柱与地面夹角 → side bending
- **Q34** 等球阶段脚是否持续小跳 → slow motion practice
- **Q35** split airborne 阶段躯干/视线已转 → late recognition
- **Q36** 握拍特写：底部三指 vs 虎口 V 字 → pivot at butt cap
- **Q37** 拍头方向 vs 来球方向（拦截 vs 追） → chasing
- **Q38** 引拍速度 vs 来球速度匹配 → takeback mismatch

每个 Q 在 `Q_DIRECT_MAPPING` 都接到了上面的概念上，并配了 drill / muscle cue。

## 10 个新视觉洞察（来自看视频的两个 agent）

把"教练讲的东西"和"VLM 真正能看到的东西"对齐后留下的 10 条：

1. 左肩位移 / 右臂位移 < 0.3 = 手臂主导引拍 (Tomaz #1) → Q23 已覆盖
2. prep_complete → forward_swing_start 之间无角速度低谷 = 没有"等" → Q26
3. 拍头向量 vs 来球向量夹角 < 90° = 追球 → **Q37 (新)**
4. 手腕 1–2 帧脉冲式上升 = slap (Tomaz #3) → 暂未独立成 Q（用 Q9 推断）
5. 髋 < 肩 < 肘 < 腕 峰值时序 = 真正的分段鞭打 (Tomaz #8) → Q17 已部分覆盖
6. 低角度握拍特写：底部三指紧握 = 支点在底盖 (FTT pivot) → **Q36 (新)**
7. 30 帧无脚部位移 = slow motion practice → **Q34 (新)**
8. split 落地前躯干和视线已转向 (Federer footwork) → **Q35 (新)**
9. 击球时脊柱-地面 ≥ 85° = 无侧弯 → **Q33 (新)**
10. 引拍速度 / 来球速度 > 2.0 = 早完成 → **Q38 (新)**

## 你下次训练应该做什么（2 件事，就够了）

**1. 把"等球时脚不停"加到自检清单里。**
你之前一直在攻克"摆锤时机 + 肘在前"，但 wave 2 揭示了一个上游：
你练习时如果脚是粘地的，所有时机问题都会被放大。
下次训练，每次接球前刻意做 2–3 次小垫步（不是大跳，是几乎看不见的离地 2–3 cm），
配合用力呼气。这一条看似无关，其实是 FTT Multi-Split-Step 的核心。

**2. 录一段握拍特写（10 秒就够）。**
按新的"可选机位：握拍特写"录一段——手机贴近拍柄 30 cm，60 fps，
做几次 shadow swing。让 VLM 看一眼你的虎口 V 字够不够紧、底部三指有没有死握。
如果发现是 butt-cap pivot，那么之前所有"lag 出不来"的努力其实在治错了根——
这是 FTT Johnny 视频里最大的发现，物理上你的握拍结构决定了 lag 能不能产生。

其它什么都不用变。等脚伤好。
