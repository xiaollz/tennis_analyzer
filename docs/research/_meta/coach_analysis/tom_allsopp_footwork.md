## 1. Split Step 时机与触发

**已确认（来自 TPA 体系总论）：**
- Tom 强调 split step 是"主动准备"而非装饰动作；它的目的是把球员从静止状态转入"可向任意方向爆发"的弹簧加载状态。
- 触发时机点：**对手球拍接触球的瞬间**（contact moment），不是球离拍后才跳。这是 TPA 反复强调的核心节拍点。
- Split step 不是高跳，而是一次"小幅卸力下沉"——双脚几乎同时离地很短一瞬，落地时膝盖弯曲，体重压在前脚掌。

**教学口诀（TPA 风格）：**
- "Land as they hit"（对方击球瞬间你落地）
- "Small, low, loaded"（小、低、加载好）

**⚠ 推断（基于其 ATP/WTA 文章逻辑）：**
- 防守 split step（深底线）落地稍宽、稍低，为侧向滑步做准备。
- 进攻 split step（上升期）落地更窄，重心略前倾，便于向前压上。

## 2. 第一步（pivot）的方向和大小

**TPA 方法论核心：**
- 正手第一步 = **右脚（右手球员）外侧脚的 pivot 转动**，与上半身 unit turn 同时发生，而不是先动手臂再动脚。
- Tom 在 ATP/WTA 文章中区分：ATP 风格更强调右脚先 pivot + 髋部分离；WTA 风格右脚 pivot 较小、更多依赖肩转。
- pivot 的角度："让脚尖指向边线方向"，约 **45°–90°** 旋转开。
- 第一步大小由来球决定：近球——pivot 后只需小调步；远球——pivot 直接转化为 crossover 或 side shuffle 的发力步。

**可观察诊断点（VLM 应捕捉）：**
- 右脚 pivot 是否与肩转**同步**发生（同帧或差 1–2 帧）。
- pivot 时右脚后跟是否离地（脚掌为支点旋转）。
- pivot 后的第一步方向是否朝击球点而非朝球当前位置。

## 3. 半开放式站位的步伐模式

**已确认要点：**
- 半开放站位（semi-open）：双脚连线与底线约成 **45°**，右脚（持拍侧脚）在后并外旋。
- Tom 把它定位为"中性站位与开放站位之间的默认 fallback"——能兼顾旋转发力（rotation）与重心转移（weight transfer）。
- 进入路径：split step 落地 → 右脚 pivot 外旋 → 左脚自然形成 45° 站姿，**无需"额外补一步"**。补步往往是预判迟钝的代偿。

**⚠ 推断（基于 TPA "less steps is more time" 哲学）：**
- 优秀球员从 ready position 到 semi-open 通常只用 1–2 步（pivot + 调位）。
- 业余球员常见 3–5 步碎步，是 split step 时机晚 + 第一步方向错的复合结果。

## 4. 常见步伐错误及诊断标志

Tom 的诊断风格是"找根因而非纠表象"。从公开内容可归纳：

| 错误现象 | 视觉信号 | TPA 归因 |
|---------|---------|---------|
| Split step 太晚 | 对方球已过网仍在下沉 / 落地后身体还在后坐 | 看球节拍未建立，注意力在球而非对手动作 |
| Split step 太高 | 双脚明显腾空、落地有"砸"感 | 误以为 split = jump，丢失反应窗口 |
| 无 pivot 直接侧滑 | 右脚不旋转，整个人横向滑出 | unit turn 与下肢脱节，导致挥拍只剩手臂 |
| 碎步过多 | 进入击球区前 4+ 次小调步 | 第一步方向错，需要二次校正 |
| 击球后无 recovery | 击球完原地停留 / 朝错方向回 | 缺少"recovery 是下一拍 split step 的开始"的概念 |
| 站位过开（脚跟向网） | 右脚尖朝向网而非边线 | pivot 不足，髋无法蓄力 |

## 5. 拍摄角度建议

Tom 在其 video analysis 服务中推荐的角度（来自 tpatennis.com 视频分析服务页面与博客图示）：

- **正后方低机位（baseline rear, ~hip height）**：观察 split step 时机、第一步方向、recovery 路径——**这是步伐分析的首选角度**。
- **侧面 90° 中机位**：观察 pivot 时右脚后跟是否离地、髋肩分离、重心转移。
- **斜后 45°（broadcast angle）**：综合用，但容易掩盖第一步真实方向。
- 不推荐：正前方/俯视——会丢失下肢深度信息。
- 帧率要求：步伐分析至少 60fps，否则 split step 落地与对手击球的时间差无法精确对齐。

## 6. 教学练习

从博客/播客可提取或合理推断的练习（具体名字以视频为准）：

1. **Mirror Split Step**：一人模拟挥拍，另一人在"接触瞬间"完成 split step 落地。训练触发时机。
2. **Two-Step Volley**（已确认博客名）：split + step-in 双步。虽然是截击练习，但 Tom 用它建立"先 split 再 step"的肌肉顺序，可迁移到底线。
3. **Pivot & Hold**：教练抛球前喊"now"，球员立刻 pivot + unit turn 并保持 1 秒，再正常击球。隔离第一步动作。
4. **Recovery Split Drill**：每次击球后必须完成一次小 split 才能等下一球，强化"recovery 是下次反应的起点"。
5. **Shadow Footwork to Cones**：在三个落点放锥桶，用 split → pivot → 正手步伐序列模拟，无球。

> 命名为推断；TPA 视频中实际命名可能不同，需观看复核。
