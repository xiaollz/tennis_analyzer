**转换阶段保持率**——动态肩胛支架 + 手拍接口，能否在转换和触球区一起保住。  
已经不是「能不能做出」，而是「准备稍晚 / 支撑一松时会不会回到整臂塌低 + 小臂急升」。

下次只验证这两件事；**不增加**：主动降拍、主动旋后、主动伸肘、主动推肘。
