## 1. 这条视频实际教什么（以抽帧人工复核为准）

**练法**：髋关节旋转隔离练习。

- **设置**：后脚放在 15–20 cm 的踏板上，只用前脚掌踩、脚跟悬空；前脚全脚掌踩地，作为“重心脚”；前后宽弓步，前膝弯曲。
- **动作**：先转髋（引拍），停顿，再转回来击球。带练时教练在近处低手抛球。
- **约束**：
  - 支撑腿的膝和脚尖不翻、不晃；
  - 肩和髋不向侧面晃；
  - 腿不能蹬直，“腿完全垂直，旋转就不存在”；
  - 发力不能向上；
  - 重心在中立位偏外侧，“55% 或 60%”，这是体感比喻；
  - 支撑脚不能离地。
- **失效信号**（带练段）：人离球太远，上半身就会歪；脚松掉、腿发抖、上半身偏离；疲劳时更明显。
- **边界**（教练原话）：“这个为什么叫隔离项，是我并没有去做一个完整的动作”；职业球员是“击球结束之后，这条腿才跟过来”。

## 3. 冲突与边界

1. **FTT《How the Feet Liberate the Hips》**：“双脚都牢牢固定在地面上时，完全的髋部旋转是不可能的”，而且会给膝和踝带来扭转负荷（`docs/research/ftt/06_ftt_blog_movement.md:180-182`）。这和灵熙的练法并不直接矛盾：灵熙只要求前脚在击球前不离地，后腿在击球后“跟过来”。但“膝和脚尖不翻”只能作为练习约束。**完整挥拍时，击球后要让髋和脚被带着转完。**
2. **FTT《Hip-Shoulder Separation Catastrophe》**：刻意去“感受先髋后躯干”会被拉长成可以感知的延迟，反而破坏挥拍（`docs/research/ftt/04_ftt_blog_forehand_1.md:635-650`）。灵熙练法里的“停顿”正是人为拉长的延迟，所以**只能当场外校准练习，不能把“转髋、停顿、再打”带进实打节奏**。
3. **刘教练有两条讲“向上蹬伸”**（统一知识库条目，`all_knowledge_items.jsonl` 第 10180、10187 行）：讲的是职业慢动作里重心的整体上提。灵熙反对的是**击球时身体向上窜、力量散向上方**。两者的区别在于力量方向是否离开了击球方向，不能简化成“永远不准向上”。
4. **单机位、单条视频**：无法判断具体是哪块肌肉在发力，也无法验证 55%–60%。Gemini 对演示段脚位的描述有错，已经用抽帧纠正。
5. **身体风险**：弓步加后脚垫高，膝和髋的负荷高于平地挥拍。膝内侧、髋前侧或跟腱疼痛就停止练习（参照 7/14 刻意拧脚后跟腱疼的教训，`docs/record/learning.md:10262-10270`）。

## 4. 与用户当前问题的关系

- **相关**：用户反复出现上半身后倒、转过头、提前恢复、蹲腿往上顶。这个练法把“前腿承接和制动 + 不上窜 + 躯干中立”变成了看得见的约束，和 FTT 的 Step In 锚点、刘教练的前腿制动讲的是同一方向。
- **不要混淆**：7/17 的“坐进右臀”讲的是准备期**后腿**的装载；这个练法练的是**前腿**这个支撑轴上的旋转和稳定。两者是同一条动力链的两端，互不替代。
- **使用方式**：家里或场边的慢速校准练习，每次 2–3 组，每组 5–8 次，与 TopSpin Pro、影子挥拍配合。上场后只保留一个外部结果：**“击球后前脚还踩着，头不往上窜，球往前深走”**，不再想髋。

## 5. 补充：FTT《How the Feet Liberate the Hips》与相关视频（2026-09-23）

用户看完本视频后判断这是自己的命门：“膝盖也在转向，脚也在动，就是没有把力量传递上去，导致手发力”。已记入 `docs/record/learning.md` 9/23 ⭐ 条目。

**FTT 文章要点**：双脚钉死时完全转髋不可能，硬转会让膝和踝承受扭力；脚部分离地是转髋的结果。四种模式：非持拍脚抬起（相持球）；双脚跟抬起一起转（进攻、低慢球）；持拍脚蹬起后甩（费德勒 hop step，不是有意识地跳）；双脚离地（跑动中或全力击球）。与灵熙的关系：灵熙约束击球前的支撑腿，FTT 描述击球后脚被带走，两者是同一件事的两个时间段。
