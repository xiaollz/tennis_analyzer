## Integration With Current User Root Cause

### 1. Elbow Shape Is The Takeback Gate

The short takeback video (`Je358uLhJNg`) is the cleanest match for the user's current bottleneck. Its useful project translation:

```text
肘部形状先定住
  -> 肘与身体保留空间
  -> 拍面角度不先乱变
  -> 身体单位把肘轴带到右侧
```

This refines the 6/20 Intuitive Tennis entry: "elbow as center" is not just a geometry metaphor. It has a concrete shape requirement: elbow slightly bent, slightly away from ribs, not collapsing below the hand.

### 2. Back Support Is The Muscle Ground For Elbow Axis

Web Tennis Classic does not always use the same FTT words, but the mechanics match the user's 6/20 breakthrough:

```text
肘轴能稳定
  because 背部/肩胛/核心托住右臂框架
```

If back support is absent, the user sees the exact failure pattern already captured by the pipeline:

```text
dropped elbow
  -> racket head collapse
  -> V-shaped scooping
  -> no slap
```

### 3. Closed-ish Racket Face Helps Preserve Structure

The visual template repeatedly shows a more closed racket face during takeback / drop, not an upright face that falls straight down. Project translation:

```text
拍面微闭 / 朝地
  -> reduces upright-lowering collapse
  -> helps forearm/racket stay in the elbow-axis frame
  -> gives slap room on the right side
```

Boundary: this is not an instruction to actively press the racket face down with the wrist. Contact face should still return to near vertical or slightly closed.

### 4. Follow-through Is An Outlet, Not A Separate Arm Trick

The follow-through videos use Japanese cues such as pinky-up / wiper. They are useful only after the upstream frame is stable:

```text
背托肘 + 右侧窗口 stable
  -> pinky-up / wiper can express release
```

If practiced too early, pinky-up becomes wrist manipulation and can recreate the user's old brush / scoop pattern.

## Recommended Training Use

### Field Cue

Use one compact cue only:

```text
肘形状定住，背托住，在右侧释放。
```

Shorter on-court version:

```text
肘架住，右侧打。
```

### Ball-Machine Block

- 3 blocks x 10 balls.
- Lowest speed / solo forehand context.
- Block goal: keep elbow shape through unit turn and contact on the right side.
- Video check after each block:
  - elbow stays away from ribs during takeback;
  - forearm does not collapse below the hand before forward swing;
  - racket face is closed-ish in drop, not upright-falling;
  - contact/release occurs before the torso over-rotates left.

### Home Drill

Use the 2 kg medicine ball only if headache symptoms are absent.

```text
K-shape hold 20-30s
  -> slow unit turn with ball at chest/right side x 8
  -> stop at right-side contact window x 5
  -> 5 slow shadow swings with racket
```

Purpose: body unit and back support, not power.

## Risk Boundaries

- Do not turn elbow-axis language into active elbow pushing.
- Do not actively press the racket face down with the wrist.
- Do not copy a large WTA-style backswing if it reintroduces right-arm independent pulling.
- Do not isolate pinky-up / wiper before elbow axis and back support are stable.
- Do not chase a deep racket drop first; direct slap/supination remains the current priority.
