## Core Claim

Tom's central point is:

```text
Slot is not a static position you place before the swing.
Slot is entered dynamically when the forward swing begins and the racket head lags/drops because of inertia.
```

The "slap" image is meant to create a fast, loose, whip-like release **from the high-side structure into and through the slot**. It is not a wrist flick and not an active elbow cue.

### 2026-06-12 Correction — Slap Does Not Wait For Drop

The earlier phrasing risked making the user wait for the racket head to drop before releasing. That is not the important point of this video.

Correct causality:

```text
High-side unit structure + body-chain start + loose arm slap
-> racket head dynamically lags/drops into slot
-> supination/flip appears as a byproduct
-> release through the ball
```

Wrong causality:

```text
Wait until racket head is already dropped
-> then start slap
```

The value of Tom's "slap" cue is precisely that it prevents the player from over-managing the drop. Ryan does not need to place the racket into a perfect low slot first. He can feel a high, rough, direct slap; the racket drop and supination happen during the entry into slot because the racket head lags behind the body/arm structure.

### 2026-06-12 Addendum — 6:30-7:30 Progression

Gemini rechecked the 6:30-7:30 segment. The progression is:

```text
Stage 1 for Ryan / user now:
  high setup -> direct slap from the top -> learn supination / flip / release

Stage 2 after slap is comfortable:
  smooth the motion -> allow a slightly lower Djokovic-like racket drop -> slap/release from that more advanced slot
```

This means Tom is not denying that a lower racket drop exists in a mature forehand. He is prioritizing the missing skill. Ryan's immediate problem is not "insufficiently beautiful racket drop"; it is that he cannot yet release/supinate without getting stuck or actively dragging the racket. Therefore the crude high slap is a learning scaffold.

Important boundary:

```text
Do not chase Djokovic's smooth low drop before the slap/release pathway exists.
```

The coach also warns against an overly floppy wrist. The wrist/hand should be secure enough to control the racket, while the forearm/racket can still flip naturally. This matches the user's recent V-shape / firm-but-not-death-grip finding.

The key correction is:

```text
Do not pre-drop / pre-place pat-the-dog.
Keep the racket higher and on the hitting-side structure.
Start the chain and slap from the high-side structure.
Let the racket head dynamically drop / lag into slot as a byproduct.
Do not wait for a static drop before releasing.
```

Gemini's raw analysis used phrases like "throw the elbow forward." In this project, that must be handled carefully.

### Unsafe interpretation

The latter risks triggering the user's known right-arm takeover pattern and conflicts with the permanent "推肘 is result, not action" rule.

## Main Pitfalls

1. **Turning slap into wrist flick**
   - Wrong: active wrist snap.
   - Right: loose racket head lag and release.

2. **Turning elbow lead into active elbow cue**
   - Wrong: think "move elbow forward."
   - Right: maintain body-arm structure; elbow lead appears as a result.

3. **Pre-dropping the racket**
   - Wrong: place pat-the-dog before the swing.
   - Right: drop appears after forward swing starts/slap begins.

4. **Waiting for the drop before slap**
   - Wrong: pause or mentally wait until the racket is low, then slap.
   - Right: slap from the high-side structure; drop/supination appears during entry into slot.

5. **Letting left hand leave early**
   - Wrong: free the right arm too soon.
   - Right: left hand holds the structure until the chain start makes the drop happen.
