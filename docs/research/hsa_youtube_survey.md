# HSA (Horizontal Shoulder Adduction) YouTube 综合调研

> 目的：把 FTT 之外、网上能找到的"教 HSA / 显式 HSA / 训练 HSA"的视频系统过一遍，按价值排序，给出可直接观看的优先序列。
>
> 撰写日期：2026-05-03。
> HSA 定义（本调研用）：肩关节在水平面上的内收（pec major 主导），即胸大肌把上臂从外展位向身体中线方向"合拢"——网球前挥末段把肘从体侧拉到身前的核心驱动。
> 既不是 ESR/ISR（那是矢状轴上的旋转），也不是前臂旋前（那是肘以下的事），更不是单纯转髋转肩（trunk rotation 是上游）。

---

## 0. 核心结论（先看这一段）

1. **真正系统讲 HSA 的频道，目前只有 FTT 一家**。其它频道讲的都是 HSA 的"周边变量"——shoulder rotation、chest engagement、pec activation、press、pull across、rotation-to-arm 传递等。把这些拼起来才能围出一张完整的 HSA 教学拼图。
2. **危险信号**：很多频道把 windshield wiper 当成"动力源"教，把 forearm pronation 说成发力机制。这是错的。前臂旋前是被动现象，能量在它发生之前 90% 已经由 pec major（HSA）+ ISR 释放完毕。看到"靠手腕翻转 / 靠前臂旋前发力"直接降级。
3. **一个隐藏共识**：所有教"effortless power"的高手——Tomaz、Salzenstein、Top Tennis Training、Macci——都在不同时期描述过同一件事：**rotation 把上臂带起来 → 上臂被动外展外旋（lag）→ pec 受拉爆发性收缩（HSA）→ ISR 自然跟出 → 前臂旋前作为减速**。差别只是各家用的语言不同。
4. **Tier S（必看，FTT 之外）**：Brian Gordon × Macci 的 Type 3 系列 + Holland Osteopathy 的 shoulder biomechanics 文章 + 任意一支 Sinner / Alcaraz 240fps 慢动作（用来观察而不是听讲）。
5. **最高效观看顺序**：FTT 两支 HSA 视频 → Brian Gordon Type 3 → Sinner 240fps → Alcaraz 240fps → 任一胸推/press 概念视频做术语桥接。10 支以内拿到 90% 价值。

要点提取（来自 Brookbush + Kenhub + StatPearls 的综合）：
- pec major 三个分区：clavicular（上）、sternocostal（中）、abdominal（下）。三部分都收敛到肱骨大结节。
- 主功能：horizontal adduction（**水平内收 = HSA**），辅功能：肩屈、肩伸（不同分区方向相反）、肩内旋。
- 网球前挥的 pec 收缩 = 上+中分区主导，**先离心拉长（lag/ESR 阶段）**，**再向心爆发（HSA 阶段）**。这就是为什么"先松后紧"的体感是对的。
- 一句话引用："the primary shoulder horizontal adductor."（pec major 的功能定义）

## 附录：术语对照表（看视频时识别 HSA 的关键词）

| 视频里听到这些 | 大概率在讲 HSA 或其上下游 |
|---|---|
| chest drive / use your chest / pec drive / press / press slot | 直接 = HSA |
| horizontal adduction / horizontal flexion | 解剖准确名 = HSA |
| arm comes in / elbow drives across | 描述 HSA 的运动学画面 |
| independent arm contribution / late acceleration | Gordon Type 3 的 HSA 名 |
| pull across body / cross-body finish | HSA + ISR 的合成结果 |
| lag and snap / whip | 笼统词，HSA 通常被打包在 snap 阶段 |
| windshield wiper | 接触后的画面，**HSA 已发生**；不要把它当作主动动作训练 |
| ESR → ISR | HSA 的前后近邻；ESR 是 HSA 的拉长，ISR 与 HSA 几乎同时 |
| forearm pronation | 减速阶段，**不是动力源** |
| rotation / shoulder turn | trunk 转动，是 HSA 的上游而不是 HSA 本身 |

看视频时用这张表过滤，能在 30 秒内判断这支视频是真在讲 HSA，还是在讲它的近邻。
