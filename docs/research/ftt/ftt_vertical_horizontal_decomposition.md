## §0 一句话总结

> **FTT 把整套挥拍简化成两个分量**：vertical（垂直，钟摆下落到球之下）+ horizontal（水平，into-out 旋转加速）。**业余通病 = 跳过垂直直接水平 = IR 抢跑**。**修正 = "Be patient" 等垂直先建立，再水平释放**。

这是用户 5/8 ESR 根因诊断（"ESR 抑制 IR 抢跑 = 刹车机制"）的**外部聚焦语言版**——同一物理事实的两种描述：
- 解剖语言（项目内部）：ESR 启动 → IR 群被反射抑制 → 拍头自然下垂 → HSA 释放
- 二维语言（FTT 外部聚焦）：等垂直分量建立（拍头降到球下）→ 水平分量释放（into-out 旋转）

## §2 两个分量的精确定义

### §2.1 垂直分量（Vertical Component）

**FTT 视频定义**：球拍像**钟摆下落**到球下方，由**重力**驱动（不是手臂主动下压）。

**项目术语对应**：
- = ESR 的视觉表现（拍头朝天 → 朝下的摆动）
- = scapular slot 进入后大臂被托起 → 拍头自然下垂的轨迹
- = lag / racket drop / dynamic position（FTT 用语）的物理本体
- = Brian Gordon Type 3 的 backswing depth

**关键**：是**重力 + 身体旋转惯性**做的，不是"主动下压拍头"做的。
- ❌ 用小臂主动 pat-the-dog 把拍头压下去（项目早期 V-scooping 根因）
- ✅ ESR 启动 + 槽进入 + 身体准备转动 → 拍头自动下垂

### §2.2 水平分量（Horizontal Component）

**FTT 视频定义**：**Into-out rotational** —— 从内向外的旋转加速，"把从后向前的力量加载到手中"。

**项目术语对应**：
- = HSA（Horizontal Shoulder Adduction，胸-肱角主动闭合）
- = chest fire / 胸推肘（已被 HSA 覆盖）
- = "撕"字 / ISR 释放（Phase 2 末端）
- = into-out rotational power

**关键**：水平分量在垂直分量**到位之后**才允许介入。提前介入 = 用户 30 年根因。

## §3 业余通病：跳过垂直直接水平

### §3.1 视频里的描述（[00:41]）

> "If I load the hand up here, the racket's max velocity is going to be **down into the ground**..."
>
> 在高位就让手发力 → 球拍最大速度朝地面 → 必须用手腕在末端挑球。

### §3.2 跟项目体系的精确映射

| FTT 二维语言 | 项目内部语言 | 用户体感（5/8 实测） |
|---|---|---|
| 在高位让手发力 | IR 抢跑（胸大肌 + 肩胛下肌 + 三角肌前束 + 背阔肌 提前激活）| "感觉只是手腕在动" |
| 球拍最大速度朝地面 | 大臂飘 + 拍头朝下提前刺出 | 球软、节奏断 |
| 末端用手腕挑球 | 食指收紧 + 前臂屈肌补偿 | 内上髁炎信号（5/16 受伤模式）|
| 跳过垂直直接水平 | ESR 偷懒 = ESR 没在 Unit Turn 第一帧启动 | "镜前完美球场消失" |

### §3.3 为什么"过早发力 = 只有手腕动"（用户原话）

物理上讲：
1. 球拍最大角速度发生在垂直分量末端（拍头从最低点向上拐）
2. 如果水平加速过早叠加（球拍还在高位），合速度方向 = 朝下 + 朝前的合矢
3. 这个合矢不在球的飞行平面上 → 击不出球
4. 大脑 emergency override：在最后 50ms 用前臂屈肌 + 手腕做一次抢救性挑球
5. **结果**：身体的旋转能量没传到球上，全部能量都集中在前臂手腕这一段——所以"感觉只是手腕在动"

**这是 IR 抢跑的另一种描述**——FTT 用 outcome 语言（"max velocity goes to the ground"），项目用解剖语言（"IR 群提前激活"）。**同一回事**。

## §4 "Be Patient" 跟 ESR 根因的双胞胎关系

| FTT 用语 | 项目用语 |
|---|---|
| "Be patient" | "ESR 在 Unit Turn 第一帧启动" |
| 等待垂直分量建立 | ESR 抑制 IR 群（Sherrington 反射抑制） |
| 等钟摆下落到球下 | 等 scapular slot 进入 + 拍头自然下垂 |
| 然后水平释放 | 然后 HSA + tilt 释放 |

**两者的诊断价值不同**：

- **ESR 根因**（项目内部）：精确告诉你**做什么**（主动启动 ESR）+ **为什么**（反射抑制 + 蓄力）
- **Be patient + 二维分解**（FTT 外部）：精确告诉你**等什么**（等垂直分量到位）+ **错在哪**（高位发力）

→ **两个一起用最强**：内部跟自己解释机制（ESR 启动），外部对自己下命令（"耐心等垂直"）。

## §5 FTT 视频里的 3 个训练 drill（reasoning reference）

> ⚠️ **遵守 Intuition-First 协议**：以下 drill **不进训练 list**。仅作为诊断辅助 + 概念桥。如要做，按 §6 的整合判断。

### §5.1 Two-Finger Swing（[02:26]）

**做法**：仅用拇指 + 食指捏拍挥动。

**作用**：
- 强迫身体不与球拍惯性对抗
- 感受拍柄从掌心脱出的 lag
- **本质**：让用户意识到"水平分量是被动加速，不是手主动拉"

**跟项目对应**：
- = JUL Drill 5（球拍悬挂感）的姊妹版
- = Hypothenar Eminence 挂重的极限版（只剩两根指头）
- ⚠️ **用户 5/8 状态**：肘伤未愈，**禁持拍**——不能立刻做

### §5.2 Catching Drill（[12:38]）

**做法**：抛球，用球拍弦面把球"接住"。

**作用**：
- 训练晚加速感（late acceleration）
- 防止过早发力把球打飞
- **本质**：垂直分量到位才允许水平加速的肌肉记忆

**跟项目对应**：
- = "晚加速 + 上对角线"的 outcome drill
- 是 Intuition-First 协议下少见的"有 outcome 的 drill"——**球能不能接住**就是 outcome 信号

### §5.3 Shoulder Slant / Tilt（[08:45]）

**做法**：肩斜转（非持拍肩高于持拍肩），不水平转。

**作用**：
- 自然产生向上分量
- 模仿 Alcaraz 的肩 tilt

**跟项目对应**：
- = HSA Phase 2 末端的 tilt（用户 5/15 大悟模型 Phase 2 已包含）
- = JUL Three-Layer Classification 里的"肩躯倾斜"

## §7 教练（Claude）使用本文档的协议

回答用户问题时：

1. 用户描述"过早发力 / 只手腕动 / 球软 / 大臂飘"
   - **第一句仍按 ESR 根因协议**："ESR 在 Unit Turn 第一帧启动了吗？"
   - **第二句可补 FTT 二维语言**："换 FTT 的话——你刚才那球，**垂直分量**建立了吗？拍头降到球下了吗？"
   - 给用户两套语言（内部解剖 + 外部聚焦），让 ta 选用得顺的

2. 用户主动问"什么是 FTT 说的水平/垂直分量"
   - 引用本文档 §1（视频时间戳）+ §2（精确定义）
   - **必须**指出这就是 ESR 根因 + HSA 的双胞胎概念

3. **禁止**：
   - 把"练 vertical component"作为新训练协议加进 5/8 实践指引（违反 Intuition-First）
   - 把 two-finger / catching drill 推荐给用户（用户肘伤未愈 + 协议禁新 cue）
