## 核心颠覆：发力不是"从下往上"，是"躯干指挥，腿部放大"

### 传统错误模型

```
蹬地 → 转髋 → 转腰 → 转肩 → 手臂
（从下往上的阶梯式顺序）
```

### FTT 正确模型

```
躯干（肩线）发出旋转意图（Command）
  → 腿部/臀部在旋转中途爆发式响应（Multiply）
  → 力量通过手臂传导到球拍
```

**关键区别：旋转的"命令"来自上部躯干，下肢是接到命令后的强力响应者，不是发起者。**

---

## 为什么"先蹬转再躯干转"是错的

1. **物理学 vs 生物力学意图**：力确实来自地面（物理事实），但**生物力学的意图（Intent）不能从地面开始**
2. 如果先蹬地：动作变得"线性向上"而非"旋转爆发"
3. 导致躯干落后，动作脱节，产生"笨拙、缓慢"的感觉
4. 失去击球需要的"鞭打感（Whip）"

---

## 腿部 = 力量放大器（Force Multiplier）

### 氮气加速比喻
- 躯干 = 转向系统 + 初级引擎（决定方向和起始速度）
- 腿部 = **氮气加速（Nitrous）**
- 氮气不能在静止时启动 → 车必须先跑起来（躯干先启动旋转）
- 然后注入氮气（腿部蹬伸）→ 产生巨大爆发力
- **没有躯干引导，腿部力量无处可去；没有腿部放大，躯干旋转太弱**

### 跳水踏板比喻
- 你得先跳上去（躯干启动）
- 踏板才会把你弹高（腿部放大）

## 正确的心理模型：脉冲，不是长旋转

| | 错误模型 | 正确模型 |
|---|---------|---------|
| **旋转范围** | 从 0° 到 180°（长旋转） | 极短的爆发式**脉冲（Pulse）** |
| **旋转终点** | 随挥终点 | **击球瞬间（Press Slot）** |
| **大脑想的** | "我要转一整圈" | "我要在击球瞬间产生一个爆炸" |
| **随挥** | 主动转到终点 | 惯性的自然结果 |
| **类比** | 花滑自旋（持续旋转） | 网球鞭打（爆发式脉冲） |

## 发力时序（正确版）

```
1. 躯干发令：肩线率先产生旋转趋势（微小但明确）
2. 拉伸链条：躯干旋转拉伸身体链条，手部进入空间
3. 腿部爆发：臀部/腿部在旋转中途猛然发力（放大器启动）
4. 穿过击球：在 Press Slot 位置完成全部发力
5. 自然随挥：惯性带着身体和球拍到随挥终点
```

**感知提示：** 臀部不是在做旋转运动，而是在**"蹬直"的瞬间产生侧向冲力**，完美融入由肩膀开启的旋转。

## 对用户的直接影响

### 之前的错误心理模型
用户之前的口令是 `蹬→肚子→胸→出去`（从下往上的阶梯式）。这导致：
- 先想着蹬地 → 腿先发力 → 躯干落后 → 手臂更落后 → 代偿
- 感觉"胸 press 时手臂还在后面"就是这个模型造成的

### 修正后的心理模型
- 不要从脚开始想——从**躯干旋转意图**开始
- 躯干发令 → 腿部自动响应放大 → 力量穿过胸和手臂
- 口令从 `蹬→肚子→胸→出去` 改为 **`躯干发令，腿部放大`**
- 或更简单：**`转！`**（一个意图，不是四步）

### 关于 Over-rotation 的新理解
- 过度转体的根因：心理模型是"长旋转"（从 0° 到 180°）
- 修正：旋转是一个**短脉冲**，终点是击球瞬间，不是随挥终点
- 大脑想的应该是"在击球点爆炸"，不是"转一圈"
