## §1 哲学框架（FTT 立场 + 用户特殊性）

### 1.1 FTT 的官方立场

FTT 的 dynamic position 哲学**反对把 ESR 作为主动 cue**。原文逻辑：

> 准备阶段所有的位置（拍头朝天、双外旋、肘抬起、左手平衡）都是**Unit Turn 的副产品**，不是单独训练的对象。一个一个去 cue 这些位置，就是 reasoning overload，球场 500ms 反应窗口装不下。FTT 推荐的 cue 是 outcome 级别（"throw the racket out toward the target"、"rotate earlier"），让所有 dynamic position 自动出现。

这个立场**对 FTT 自己的学员是对的**——他们 80% 是基础打野选手，没有 30 年 IR 抢跑的肌肉回路。

### 1.2 用户特殊性（为什么不能直接套 FTT cue）

用户的现状跟 FTT 假设的"普通学员"在三个维度上不同：

| 维度 | FTT 默认学员 | 用户实际 |
|---|---|---|
| 动作回路年龄 | 1-3 年（可塑性高）| 30 年（深度固化）|
| 主导发力肌 | 中性 | **内旋肌系统主导**（胸大肌前束 + 三角肌前束 + 二头肌）|
| 卡点性质 | 缺位置 | **错位置**（IR 抢跑导致 ESR 永远不到位）|
| 现有 cue 输入 | 0 | **过载**（HSA / Wrap / press slot / 撕 / chest fire 等 12+ 个概念）|

直接套 FTT outcome cue（"throw the racket out"）→ intuition fallback 老回路 → IR 仍然先动 → ESR 永远建立不起来。

### 1.3 解决方案：阶段性 cue（active → passive）

把 ESR 当作"过渡性教学拐杖"使用：

```
Phase 0-1：active ESR（治疗期）
  ├─ 用 reasoning 强行打断 IR 抢跑
  ├─ 镜前 + 慢速喂球，意识全程参与
  └─ 目标：建立"先 ESR 后 IR"的新肌肉回路

Phase 2：active → passive 过渡
  ├─ 球场实战，意识只 set goal（aim）
  ├─ ESR 已经是次主导反应
  └─ 目标：把 active cue 强度降到 30%

Phase 3：passive ESR（FTT 哲学）
  ├─ 切换到 outcome cue（"throw the racket"）
  ├─ ESR 自然发生
  └─ 不再想 ESR 这个词
```

这跟 FTT 哲学**不冲突**——FTT 不要求"永远不主动想任何 dynamic position"，FTT 要求"成熟阶段不主动想"。用户现在不在成熟阶段。

### 1.4 一句话原则

> **Reason 用来打断 IR 抢跑（修肌肉回路），Intuition 用来执行成熟动作（球场实战）。两个角色不混用。**

## §2 阶段化训练计划

### Phase 0：肘恢复期（5/8 → 5/14, 1 周）

**核心目标**：48h 严格不持拍 + 第 3 天起做无负重 ESR 唤醒 + 上肢张力链重建。

**为什么这周不能跳过**：内上髁炎本身就是"IR 代偿 + 腕旋前过载"的临床信号（Tennis Science Ch7 p.142, Kibler）。在肘没恢复前练 ESR 会立即激发腕旋前代偿 → 病情恶化 + 错误回路再加深。

#### Day 1-2（5/8-5/9）：完全休息

- 持拍：禁止
- 镜前空挥：禁止
- 上肢力量训练：禁止
- 允许：冰敷（每次 15 min，每天 3 次）+ 下肢训练 + 核心训练 + 看视频复盘

#### Day 3-7（5/10-5/14）：无负重唤醒

每天 30 min，分 3 个 block：

**Block A — 镜前 ESR 体感唤醒（10 min）**

无球拍 / 无哑铃。站墙前，做以下动作：

1. **L 字试验**（3 min）：
   - 大臂贴肋骨（armpit pencil 固定），前臂屈肘 90°
   - 慢速做"开门"（外旋）→ "关门"（内旋）
   - 每开一次停 2 秒在外旋顶点
   - 体感锚：肩胛骨外侧深处（冈下肌位置）"麻 + 紧"
   - 50 次

2. **Hypothenar Eminence 校准**（4 min）：
   - 用 SW（Semi-Western）握拍法在空气中握拳
   - 注意：第 5 掌骨小鱼际（hypothenar eminence）正对自己
   - 慢速做"双外旋"动作（肩 ER + 前臂位置稳定）
   - 检查肘心：**完全不能有任何牵拉感**——有就立即停
   - 30 次

3. **Off-arm Pull 同步**（3 min）：
   - 左手做"拉拍颈横过身体"动作
   - 同步右手做 ESR
   - 体感：左手拉一寸，右肩胛骨深处紧一寸
   - 20 次

**Block B — 上肢张力链 isometric（10 min, TRX）**

1. **TRX Y-pull**（3 min）：
   - 双手抓 TRX 把手向斜上方 Y 字拉开
   - 每次拉到位停 3 秒，肩胛下沉 + 后缩
   - 8 次 × 3 组
   - 训练目标：下斜方 + 菱形肌 isometric 控制
   - 肘心痛立即停

2. **TRX 单臂 ER@90°**（4 min）：
   - 右手抓 TRX 在体侧，大臂水平 90°，前臂垂直
   - 做小幅 ESR（外旋 30° → 回中位）
   - 8 次 × 3 组（右手）
   - **关键**：负重不能让肘心痛——找到不痛的最大角度

3. **肋木架 scapular slot 找位**（3 min）：
   - 双手抓肋木架，做"挂着"动作（肩胛下沉）
   - 不做引体向上，只找"肩胛骨卡进槽"的位置感
   - 每次 hold 10 秒
   - 6 次 × 2 组

**Block C — 下肢蹬转（10 min）**

下肢系统不参与肘伤恢复，全力做：

1. **右脚为轴蹬转影子**（5 min）：徒手原地蹬转 50 次
2. **TRX 单腿弓步**（5 min）：左右各 10 × 3 组

#### Phase 0 出口标准

进入 Phase 1 前必须满足：
- 肘心按压无痛
- TRX 单臂 ER@90° 8×3 组无痛
- 镜前 L 字试验 50 次无任何代偿（无前臂晃动 / 无肩耸起）

未满足 → Phase 0 延长至满足为止。**绝不带伤进入 Phase 1**。

### Phase 1：体感固化期（5/15 → 5/28, 2 周）

**核心目标**：在镜前 + 慢速喂球建立"ESR 第一帧启动"的肌肉回路，通过率达 70%+。

**当前阶段允许的 reasoning 强度**：100%（治疗期，意识全程参与）。

#### 每天 60 min 训练结构

**Block A — 镜前空挥（20 min）**

1. **空挥 ESR 启动监测**（15 min）：
   - 持球拍（VCORE 98），慢速做完整挥拍 50 次
   - 录像 60fps
   - 自我口令："**外旋。第一帧。**"
   - 每挥完一次问自己：ESR 是不是 Unit Turn 第一帧？
   - 通过率手动记录（推荐用 Notes 记 30 次/30 次）

2. **失败回查**（5 min）：
   - 失败的挥拍立即停下来分析
   - 最常见失败：**肘先离体 → ESR 跟着才出现**（IR 抢跑模式）
   - 修正方式：再做 5 次只有 ESR 没有挥拍的"半动作"，把肌肉感强化

**Block B — 慢速喂球（30 min）**

需要一个固定喂球员（陪练或发球机）：

| 阶段 | 球速 | 球数 | 落点 |
|---|---|---|---|
| Day 1-3 | 50 mph | 50 球 | 固定 1 个落点（深中路偏正手）|
| Day 4-7 | 55 mph | 60 球 | 固定 2 个落点交替 |
| Day 8-14 | 60 mph | 80 球 | 3 个落点随机 |

每球后**只问一件事**：肘心 / 二头肌 / 前臂内侧——有没有酸痛？有 → 立即停，回 Block A 调整。

**Block C — 视频自检（10 min）**

录所有 Block B 的击球，回放 60fps 慢动作：
- 看 §4 的 5 帧检查表
- 通过率 < 70% → 第二天回 Block A 增加镜前次数
- 通过率 ≥ 70% × 3 天 → 进入 Phase 2

#### Phase 1 出口标准（4 项必须全部满足）

1. 镜前空挥 ESR 第一帧启动通过率 ≥ 80%（连续 3 天）
2. 慢速喂球 ESR 通过率 ≥ 70%（视频核对）
3. 肘心 + 二头肌 + 前臂内侧零酸痛（连续 5 天）
4. 体感主导酸位 = 胸大肌 + 肩胛下角（不再是二头肌）

---

### Phase 2：实战迁移期（5/29 → 6/30, 1 个月）

**核心目标**：把 Phase 1 的"reasoning 控制 ESR"迁移到"球场速度下 intuition 自动 ESR"。

**当前阶段允许的 reasoning 强度**：30%（仅在每球间隙，挥拍中不参与）。

#### 关键转折：训练心智模式切换

Phase 1 → Phase 2 最难的不是动作，是**心智模式切换**：
- Phase 1 心智：每挥一次都问"ESR 做对了吗"
- Phase 2 心智：每挥一次只问"球落在哪里 / 想要它落在哪里"

如果继续 Phase 1 心智上球场 → reasoning overload → 球场速度下崩盘（用户 5/15-5/16 的精确机制）。

#### 每周训练结构（4 次/周）

**Week 1（5/29-6/4）— 中速喂球过渡**

- 喂球速度 65 mph
- 100 球/次
- 球数分配：
  - 前 30 球：仍允许内心默念"外旋第一帧"（reasoning 拐杖期）
  - 后 70 球：完全 outcome only（"球去那个角落"）

**Week 2（6/5-6/11）— 中速喂球纯 outcome**

- 喂球速度 70 mph
- 120 球/次
- 100% outcome only（不再默念 ESR）
- 训练后录像回看 Block C，统计 ESR 通过率

**Week 3（6/12-6/18）— 轻量真人对打**

- 找水平相当或略低的对手
- 对打 30 min（不计分，纯拉锯）
- 每球唯一目标：**让球过网 + 落在对方场地深半场**
- 完全不想 ESR / IR / HSA 任何概念

**Week 4（6/19-6/30）— 实战检验**

- 每周 2 次完整训练课（含计分对打）
- 每周 1 次 75 mph 喂球录像（视频 ESR 通过率监测）
- 通过率必须 ≥ 75%

#### Phase 2 出口标准

1. 真人对打 30 min × 4 次，零代偿酸痛
2. 75 mph 喂球录像 ESR 通过率 ≥ 80%
3. 主观感觉：挥拍前**没主动想 ESR**，但视频里 ESR 仍然出现
4. 球质稳定（深球 ≥ 70%、不挂网 ≥ 90%）

---

### Phase 3：成熟期（7/1+, 长期）

**核心目标**：完全切换到 FTT outcome cue，ESR 这个词从训练中消失。

#### Phase 3 训练规则

- **唯一 cue**：糙男 3 步（指高 → 指肘 → 出手）+ FTT "rotate earlier"
- **完全禁用**：ESR / IR / HSA / 撕 / wrap / press slot 等任何 reasoning 概念
- **唯一允许 reasoning 介入的场景**：
  - 同一失败模式连续 ≥ 3 次出现
  - 球质连续 1 周倒退（视频对比）
  - 受伤复发

#### Phase 3 跟以往的区别

ESR 没消失——ESR 仍然在每一次挥拍里发生。区别是：
- **Phase 1**：ESR 由 reasoning 触发（"外旋。"）
- **Phase 3**：ESR 由 Unit Turn 触发（脚一蹬，背一绷，ESR 物理上自动发生）

这就是 FTT 的 dynamic position 哲学——**位置是动作的副产品，不是动作的目的**。

## §3 实战 checklist（FTT 风格 ≤ 5 项）

> **核心原则**：**球场上和镜前的 checklist 不是同一个**。混用会导致 reasoning overload。

### 3.1 球场实战 / 比赛 / 真人对打时

**唯一要想的事（Phase 2 起）**：

```
1. 球去哪了？想让它去哪？
2. 拍头经过胸前那个点没？
```

就这 2 件事。**完全不想 ESR / IR / HSA / 任何技术概念**。

挥拍中如果脑子里冒出"我 ESR 做对了吗"——立即压下去，把注意力拉回"球去哪"。

### 3.2 镜前 / 慢速喂球训练时（Phase 0-1 期）

允许使用 reasoning checklist（**5 项以下，按重要性排**）：

```
1. 肘心痛吗？（绝对优先：痛立即停）
2. ESR 是不是 Unit Turn 第一帧？
3. 左手 off-arm pull 同步吗？
4. 肩胛槽进了吗？（HSA 准备）
5. 蹬转的"压"和"飘"配上了吗？
```

**只在镜前用，球场上不用**。

### 3.3 中间过渡情境（Phase 2 早期）

allowed checklist（≤ 3 项）：

```
1. 球去哪了？（outcome 优先）
2. 蹬转启动了吗？
3. 拍头经过胸前点没？
```

## §4 视觉自检（60fps 慢动作 5 帧法）

**关键认知**：60fps 下每帧 = 16.7ms。ESR 启动要发生在 Unit Turn 第一帧 = T=300ms 后的第 1-2 帧内。

### 5 帧精确检查表

| 帧 | 时刻 | 视觉特征（通过）| 视觉特征（失败）|
|---|---|---|---|
| **T0 — Ready position** | 分腿步落地，T=200ms | 拍头中性、肘弯曲 ~110°、双手握拍 | 肘已朝后 / 单手握拍 / 拍头垂下 |
| **T1 — Unit Turn 第一帧 + 1**（关键！）| 右脚 pivot 启动后第 1-2 帧 = T=320ms | **拍面**已轻微外翻，握拍小鱼际开始指向地面斜下方；**右肘**仍在体侧（armpit pencil 还夹着） | 右肘已离体 / 拍面仍朝前 = ESR 没启动 |
| **T2 — Unit Turn 中段** | T=500ms | 拍头开始朝天斜上方，肩转约 60°；左手已开始横拉 | 拍头朝后水平 = ESR 不够深 |
| **T3 — Loaded slot** | T=900ms，Pat the Dog 完成 | 拍头几乎朝天，肘约 45-55° 离体（一拳腋下空间），左手已离拍指向网柱 | 肘已挂在体后或太靠前 / 拍头水平 / 左手已下垂 |
| **T4 — 接触瞬间** | T≈1300ms | 拍面朝前接触球；接触前 16ms 内 IR 才开始（被动）| 接触前 50ms+ IR 已经发生 = IR 抢跑 |

### ESR 通过 / 失败信号（看 T1 那一帧）

**通过信号**（视频里能直接看到）：
1. 拍面 logo 已经从"朝前"变成"朝侧斜下"
2. 握拍小鱼际（hypothenar eminence）转向斜地面
3. 右肘**仍贴在体侧**没离开
4. 右肩胛骨明显往脊柱方向收（衣服皱褶能看出）

**失败信号**（任何一个出现 = 失败）：
1. 右肘已经离开体侧 ≥ 5cm
2. 拍面 logo 仍然朝前（没外翻）
3. 拍头已经下垂（说明前臂已松，IR 在准备启动）
4. 左手仍贴在右手上（off-arm 没启动）

### 录像设备要求

- iPhone 慢动作 240fps 拍摄（向下采样到 60fps 慢放）
- 拍摄角度：**正侧位**（90° 站位侧面），距离 3-4m
- 高度：肩高水平（不要低拍仰拍）
- 光线：球场训练时面向阳光（避免逆光）

## §5 体感自检（一句话肌肉酸位法）

> **用法**：球场上**每球后只问一件事**——这个体感系统要能在 1 秒内自检完，否则就是 reasoning overload。

### 5.1 核心问题

**"刚才那球击完，最酸的是哪里？"**

### 5.2 三选一答案表

| 酸位 | 含义 | 行动 |
|---|---|---|
| **胸大肌中段**（锁骨下 5cm 区）| ESR 健康，HSA 正常 SSC 释放 | 继续打，不用调整 |
| **肩胛下角附近**（背部偏右下） | ESR 主动维持中（治疗期正常）| 治疗期可接受；Phase 3 出现 = 提示 reasoning 未完全切换 |
| **二头肌 / 前臂内侧 / 肘心**（肘附近）| **ESR 偷懒 + 内旋肌代偿**（IR 抢跑）| **立刻停**，回镜前体感唤醒，下次球质降一档 |

### 5.3 为什么这套体感能替代 5 项 checklist

这个系统利用了**肌肉酸位 = 主导发力肌**的生理事实：
- 胸大肌酸 → 说明 HSA 主导发力 → ESR 自动健康（HSA 必须先 ESR 拉满才有效）
- 肩胛下角酸 → 说明肩袖外旋肌主动维持 → 治疗期意识参与的正常代价
- 二头肌酸 → 说明前臂屈肘代偿了 → 说明 IR 比 ESR 先发动 = 失败

**用户每球只需问一个 yes/no/which 问题，1 秒决断**。这是 outcome-first 协议在体感层面的实现。

### 5.4 特别警告

如果出现**肘心痛 + 前臂内侧紧**组合 → **立即停训，冰敷**，不要"再练一拍试试"。这是内上髁炎复发的早期信号，再练 1 球可能炎症升级到需要 2 周休养。

## §6 球场检验程序（Phase 1 + Phase 2 量化版）

### 6.1 Phase 1 喂球进度表（5/15 起）

| 日期 | 球速 | 球数 | 落点 | 通过率目标（视频核对）| 失败处理 |
|---|---|---|---|---|---|
| Day 1（5/15）| 50 mph | 50 | 1 个固定点（深中路偏正手）| 60% | 通过率 < 60% → 回 Block A 加 30 min 镜前 |
| Day 2（5/16）| 50 mph | 50 | 同上 | 65% | 同上 |
| Day 3（5/17）| 55 mph | 60 | 2 个交替点 | 65% | 同上 |
| Day 5（5/19）| 55 mph | 70 | 同上 | 70% | 同上 |
| Day 7（5/21）| 60 mph | 80 | 3 个随机点 | 70% | 通过率 < 70% → 退回 Day 3 |
| Day 10（5/24）| 60 mph | 100 | 同上 | 75% | 同上 |
| Day 14（5/28）| 60 mph | 100 | 同上 | 80% | 通过率 ≥ 80% → 进 Phase 2 |

### 6.2 Phase 2 实战进度表（5/29 起）

| 周 | 内容 | 球数 | KPI | 失败处理 |
|---|---|---|---|---|
| Week 1（5/29-6/4）| 65 mph 中速喂球 | 100 球/次 × 4 次 | ESR 通过率 ≥ 75% / 球质深球 ≥ 60% | 通过率 < 75% → 退回 Phase 1 Day 14 |
| Week 2（6/5-6/11）| 70 mph 喂球，纯 outcome | 120 球/次 × 4 次 | ESR 通过率 ≥ 75% / 深球 ≥ 65% | 同上 |
| Week 3（6/12-6/18）| 真人对打（轻量）| 30 min × 4 次 | 零代偿酸痛 / 失误率不超过常态 | 出现肘心酸 → 退到 Week 1 |
| Week 4（6/19-6/30）| 真人对打（计分）| 1 set × 8 次 | 通过率 ≥ 80% / 球质稳定 | 通过率 < 80% → 重做 Week 3 |

### 6.3 失败处理通用规则

**球质连续 3 次训练倒退**（深球率 / 失误率 / ESR 通过率任一）→ 退回上一阶段，重做最后一周。

**肘心痛复发** → 立刻停 + 冰敷 + 回 Phase 0。不要"忍一下"。内上髁炎一旦升级到肌腱撕裂级别，恢复期 8-12 周。

**心理过载**（训练中焦虑、失误后愤怒、连续 5 球失败）→ 完全退到 outcome 模式：剩余球只想"让球过网"，其它一切 cue 暂停。这跟 Phase 3 不是同一回事——这是应急模式。

## §7 转向 FTT passive ESR 的 4 个 trigger

> **决策规则**：以下 4 项满足 ≥ 3 项 → 切换到 FTT cue（"throw the racket out"），完全停掉 active ESR。

### Trigger 1：球场 ESR 通过率 ≥ 80%（变量喂球）

**测量方式**：60mph 随机落点喂球 100 球，60fps 录像，§4 的 5 帧表逐球核对。
- 80/100 球达到 T1 帧 ESR 通过 → Trigger 1 ✓
- 测量频率：Phase 2 Week 4 起每周 1 次

### Trigger 2：不再有内旋肌酸 / 二头肌酸代偿信号

**测量方式**：每次训练后 24h 内做体感自检。
- 连续 4 周 / 16 次训练后零二头肌酸 + 零前臂内侧酸 + 零肘心痛 → Trigger 2 ✓
- 仅胸大肌酸 + 偶尔肩胛下角酸 = 健康范围

### Trigger 3：镜前不需要意识也能保持 loaded slot

**测量方式**：镜前空挥 30 次，**不允许默念任何 cue**（包括"外旋"），每次挥到 T3 帧检查 loaded slot 形态。
- 27/30 次（90%+）loaded slot 形态正确 → Trigger 3 ✓

### Trigger 4：球质稳定 4 周（无球软 / 无失控）

**测量方式**：连续 4 周训练录像，由 Claude 教练或专业教练打分。
- 深球率 ≥ 70%
- 球速带 ≥ 平均水平
- 失误率不增加
- 4 周无明显倒退 → Trigger 4 ✓

### 切换协议（满足 ≥ 3 项后）

满足切换条件后做以下三件事：

1. **第一周**：训练前 5 min 做"卸载仪式"——
   - 镜前空挥 10 次，告诉自己"从今天起 ESR 这个词不再用"
   - 把 §3.1 球场 checklist 写在手机便签首屏

2. **第 1-2 周**：唯一 cue 切换为糙男 3 步：
   - 指高（左手指来球最高点）
   - 指肘（肘指击球点）
   - 出手（拍头经过胸前点）

3. **每周末**：录像 1 次，自检 §4 的 5 帧表
   - ESR 仍然出现 → 继续 Phase 3
   - ESR 退化（T1 帧失败率 > 30%）→ 1 周内回 Phase 2 Week 4 巩固

### 重要提醒：不要急着切换

**宁可在 Phase 2 多停留 4 周也不要早 1 周进 Phase 3**。早切换的后果：30 年的 IR 抢跑回路在 80% 通过率水平上仍然能反弹回来。给新回路足够的稳态时间（4 周 trigger 4 是"最低"门槛，不是"理想"门槛）。

## §8 安全 + 失败应急

### 8.1 立即停训信号（任何一个出现 = 当场停）

| 信号 | 含义 | 处理 |
|---|---|---|
| 肘心痛 / 前臂内侧紧 | 内上髁炎复发 | 当场停 + 冰敷 15 min × 3 次/天 + 退回 Phase 0 |
| 肩前侧深处刺痛 | 肩袖损伤风险（ESR 主动过载）| 当场停 + 48h 不持拍 + 检查 ESR 是否过深（≥ 90° ER）|
| 腕心牵拉痛 | 腕旋前代偿 | 当场停 + 检查握拍是否变 Eastern（应保持 SW）|
| 头晕 / 心率异常 | 整体过载 | 立即停训 + 当天不再训练 |

### 8.2 球质连续倒退（3 次训练）

判定标准（任一）：
- 深球率连续 3 次 < 60%（之前稳定 ≥ 70%）
- 失误率连续 3 次 > 30%（之前稳定 ≤ 20%）
- 视频 ESR 通过率连续 3 次 < 之前平均 - 10%

处理流程：
1. 当天训练立即降到上一阶段球速
2. 第二天做 30 min Phase 1 Block A（镜前体感唤醒）
3. 第三天回退一周（Phase 2 Week 3 → Week 2）
4. 仍未恢复 → 全面回 Phase 1 Day 7

### 8.3 心理过载应急

**触发场景**：
- 训练中持续焦虑、心跳过快
- 连续 5 球以上失败 + 失误后愤怒
- 球场反复出现"想 ESR 但反而做不出"的卡住状态

**应急协议**（剩余训练时间）：
1. 立即放下所有技术 cue（包括 ESR / 糙男 3 步）
2. 唯一目标：让球过网 + 落在对方场地内（不论深浅）
3. 击球时只允许有 1 个念头：球往哪里去
4. 训练结束不复盘技术，只复盘心情
5. 第二天回到当前阶段正常训练

**这个应急协议跟 Phase 3 哲学相似但不同**：
- Phase 3 = 成熟 outcome only（intuition 已经接管 ESR）
- 应急 = 暂时 outcome only（intuition 没接管，只是 reasoning 被关掉避免恶化）
- 两者外在动作可能像，内在状态完全不同

### 8.4 治疗期结束信号（确认进 Phase 3 后）

**进 Phase 3 之后 4 周内必须确认的"已治愈"信号**：
1. 30 天没主动想过"ESR"这个词
2. 训练后 24h 内主导酸位是胸大肌中段
3. 球质（深球率 / 失误率）跟 Phase 2 Week 4 持平或更好

**任一未达成** → 不算治愈，回 Phase 2 巩固。

## §9 跟项目其它体系的关系

### 9.1 跟 HSA 的关系

ESR 是 HSA 的**前置条件**（HSA 在 ESR 拉满后释放才有 SSC 弹性）。但 ESR 不是 HSA 的全部——HSA 还需要 scapular slot + chest fire。

**Phase 1-2 期 cue 优先级**：ESR > scapular slot > chest fire。
**Phase 3 期**：全部 collapse 进 outcome cue（"throw the racket"）。

### 9.2 跟 Foundation Layer F1-F7 的关系

F7（HSA 检测）依赖 F5+F6（scapular slot + chest fire）。ESR 不在 F7 检测范围内（F7 只检测 HSA 本体）。

**未来工程化方向**：在 `evaluation/foundation_layer.py` 加 F8 = ESR 检测（基于 §4 的 T1 帧拍面外翻角检测）。**本文档不做这件事，留给后续 phase**。

### 9.3 跟糙男 3 步的关系

糙男 3 步是 Phase 3 的官方 cue。Phase 0-2 用 ESR 主导（reasoning），Phase 3 用糙男 3 步主导（intuition）。**不是替代关系，是阶段性切换**。

### 9.4 跟 Intuition Paradox 的关系

本协议是 Intuition Paradox 哲学的**特例化**——FTT 默认假设学员可以直接进入 outcome only 阶段，本协议承认用户因 30 年 IR 抢跑必须先用 4-8 周 reasoning（Phase 0-2）打断旧回路。**这不是违背 Intuition Paradox**，而是把 Intuition Paradox 的"成熟阶段"明确为 Phase 3 的目标。
