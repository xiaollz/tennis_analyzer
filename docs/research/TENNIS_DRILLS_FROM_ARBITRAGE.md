## 🤚 关于非持拍手（3 条）

### 1. 左手 = 锚点（不是被拉走的物体）

| 项 | 内容 |
|---|---|
| **网球术语** | Off-Arm Anchor / 非持拍手锚定 |
| **触发** | 用户报 "左手飞了"、"Unit Turn 没旋转中心"、"动作散" |
| **已有项目 drill** | Tomaz Drill #3 "Half-Half" 正手（左手带拍向后）+ 4/9 用户自验"想左手忘右手"|
| **新 drill 候选**（YouTube 搜）| "tennis off-arm hold position" / "non-dominant hand anchor" |
| **球场自检** | Unit Turn 终点左手应感觉**"重"**（铅块），不是"漂浮"。重 = 锚定。 |

### 2. 左手伸直 = 杠杆臂

| 项 | 内容 |
|---|---|
| **网球术语** | Lead Arm Extension / 非持拍手伸展（项目已用） |
| **触发** | 用户报 "左手不知道放哪"、"挥拍没力" |
| **已有项目 drill** | Hansen Fitness 拉伸视频（trigger 视频） |
| **新 drill 候选** | "tennis straight lead arm drill" / 录像自检肘弯度 |
| **球场自检** | 左手指尖指向**后挡网或更远** = 真伸直；指向自己右肩 = 还弯着 |

### 3. 想左手忘右手 = 注意力对侧转移

| 项 | 内容 |
|---|---|
| **网球术语** | Off-Arm Pull（项目 5/9 整合）|
| **触发** | 用户报"球软"、"只手腕动"、"手臂主导" |
| **已有项目 drill** | Tomaz 8 drills（0-E 到 3-C），项目顶层 drill 协议已含 |
| **新 drill 候选** | 不需要新 drill — 项目已完备 |
| **球场自检** | "你那球注意力在左手还是右手？"（5/9 强制问句）|

## 🔄 关于背 / 上背（3 条）

### 4. 转身的发动机是上背（胸椎）不是腰

| 项 | 内容 |
|---|---|
| **网球术语** | Thoracic Rotation（胸椎旋转）vs Lumbar Rotation（腰椎旋转） |
| **触发** | 用户报"腰疼"、"转身没力"、"转身僵" |
| **已有项目 drill** | 项目 4/30 槽圣经 + 胸椎 mobility 资料 |
| **新 drill 候选** | **Medicine Ball Wall Throw**（已搜到，跨胸壁砸药球）+ "tennis thoracic rotation drill" YouTube |
| **球场自检** | Unit Turn 时感觉**两肩胛之间 + 上背中段扭** = 对（胸椎工作）；感觉**腰扭** = 错（腰椎代偿）|

### 5. 背阔肌是"绳索"，不是"发力肌"

| 项 | 内容 |
|---|---|
| **网球术语** | Lat as Connection / 背阔肌连接（不是 lat power）|
| **触发** | 用户报"用背发力但越用越僵"、"手臂跟身体脱节" |
| **已有项目 drill** | FTT Press Slot 概念 + Hansen 背阔拉伸 |
| **新 drill 候选** | "tennis lat engagement drill" / FTT Power Checklist 第 5 步 |
| **球场自检** | 击球后背阔的酸是**"被拉伸的酸"**（绳索被拉过） = 对；**"发力的酸"**（肌肉用力）= 错 |

### 6. 肩转 = 上身扭簧（你已实战验证）

| 项 | 内容 |
|---|---|
| **网球术语** | Hip-Shoulder Separation / X-Factor（项目已有，5/8 量化）|
| **触发** | 用户报"上身硬棒、转身没力"、"球软" |
| **已有项目 drill** | 你 5/11 已实战找到——左手按住左髋 + 做 Unit Turn + 轻微 ESR |
| **新 drill 候选** | 不需要新 drill — 你已找到 |
| **球场自检** | Unit Turn 后**胸右侧 + 上背中间被拉紧** = 对；没紧 = 又变硬棒 |

## 💪 关于胸 / 肋笼（2 条）

### 7. 肋笼扩张 vs 胸肌硬

| 项 | 内容 |
|---|---|
| **网球术语** | Rib Cage Expansion（肋笼扩张）vs Pectoral Tension（胸肌张力） |
| **触发** | 用户报"胸前紧但球不重"、"上胸紧撑找不准" |
| **已有项目 drill** | 项目 KB 未深入讲，**这是新维度** |
| **新 drill 候选** | "tennis breathing rib cage forehand" / TPI 深呼吸肋笼 mobility（已搜过但需翻译网球版）|
| **球场自检** | Unit Turn 准备时**深吸一口气 + 轻微 ESR** → 感觉**整个胸腔被撑开**（不只是胸肌硬）|

### 8. 躯干撞向被动手臂 = HSA 本质

| 项 | 内容 |
|---|---|
| **网球术语** | HSA（Horizontal Shoulder Adduction，项目 5/3 命名） |
| **触发** | 用户报"主动用胸发力但球软"、"想推球但越想越散" |
| **已有项目 drill** | 5/11 你已悟到——"左手把躯干拉过去撞到右手臂" |
| **新 drill 候选** | 不需要新 drill — 你 5/11 已找到 |
| **球场自检** | 感觉**左手拉躯干 → 躯干自然撞到右手臂** = 对；感觉"主动用胸推手臂" = 错 |

## ✋ 关于手臂释放（2 条）

### 9. 手腕 3 段释放

| 项 | 内容 |
|---|---|
| **网球术语** | ISR (Internal Shoulder Rotation) + Wrist Pronation Sequence |
| **触发** | 用户报"球软只手腕动"、"想做撕做不对" |
| **已有项目 drill** | 项目 KB 讲了 ISR "撕"但没拆 3 段 |
| **新 drill 候选** | **必搜**："tennis wrist sequence drill" / "tennis pronation drill" |
| **球场自检** | 身体做 ①屈腕②尺偏，手腕只做 ③Twist = 对；3 段全用手腕 = 错（球软）|

### 10. Lag = 主动不打开（不是用力做）

| 项 | 内容 |
|---|---|
| **网球术语** | Wrist Lag（项目已用）|
| **触发** | 用户报"找不到 lag"、"主动延迟手腕但球软" |
| **已有项目 drill** | 项目 4/27 "重大突破日" + 你 5/11 体感"等球拍落到一定位置"|
| **新 drill 候选** | 不需要新 drill — 你已找到 |
| **球场自检** | 下挥前 1/3 **手腕完全不主动做任何事** = 对（lag 自然出现）|

## 🎯 关于诊断方法（2 条）

### 11. Push vs Pull 二分

| 项 | 内容 |
|---|---|
| **网球术语** | Pulled Stroke vs Pushed Stroke |
| **触发** | 任何"球软"投诉 — **第一诊断棱镜** |
| **已有项目 drill** | 没有 drill — 这是**诊断方法**不是训练动作 |
| **新 drill 候选** | 不是 drill — 是**球场自检问题** |
| **球场自检** | 击球瞬间**问自己**："是我推 racket 过去，还是 racket 被身体拽过去？" |

### 12. Bernstein 铁匠 — 心智解放

| 项 | 内容 |
|---|---|
| **网球术语** | Variability is Healthy（变异性是健康的）|
| **触发** | 用户报"我做不到 Sinner 那种"、"动作每次都不一样" |
| **已有项目 drill** | 没有 drill — 这是**心智协议** |
| **新 drill 候选** | 不需要 drill |
| **球场自检** | 看自己录像时**关注拍头到位 + 击球点**，**不关注**手臂角度像不像 Sinner |
