## 三个永久自检（每球都问）

每次挥拍之前先过这三关，过不了直接停手：

1. **ESR 第一帧启动了吗？** — Unit Turn 起步那瞬间肩有没有外旋（直觉上是"拍头朝天"那个感觉）
2. **注意力在左手还是右手？** — 想右手 = 错；想左手 = 对
3. **左侧紧撑 + 右手放松了吗？** — 上背上胸有张力，右手臂松到像跟身体不连

任何一条做不到，球软是必然结果。讲再多 drill 都没用。

## 阶段 0 · 体感建立（不持拍 / 单手 / 慢动作）

刚开始练、找感觉、镜前热身。**不打球**。

### 0-A · 手按胸肌横拉
**视频**：[FTT — Am8j1Zw5KrE](https://www.youtube.com/watch?v=Am8j1Zw5KrE)
左手摸住右胸（胸大肌），慢慢做正手横拉动作。手底下能感觉到胸肌缩短。
**对症**：胸不会发力 / 不知道 HSA 是什么感觉。

### 0-B · 探针 Drill
**视频**：[FTT — Am8j1Zw5KrE](https://www.youtube.com/watch?v=Am8j1Zw5KrE)
不挥拍，把拍头当探针，慢慢去碰"击球该在的那个点"。重复找位置。
**对症**：击球点漂、不知道球该在身体前面哪里。
**装备增强版**（5/12 用户验证）：用**带线网球挂门框**当 3D 锚点。慢挥让拍头**经过**那个挂球位置，验证击球点。发力撞架子 = 你的轨迹本来就偏。详见 [equipment.md · 带线网球](../record/equipment.md#带线网球--锚点训练球)

### 0-C · 反向工程握拍
**视频**：[FTT — 5KdScDKxVSI](https://www.youtube.com/watch?v=5KdScDKxVSI)
先做对挥拍动作，再反推握拍。不要教科书定义，让正确动作选握拍。
**对症**：握拍死板、动作做不出来。

### 0-D · 二头肌 SSC 体感
**视频**：[Gordon USPTA 完整版 — n4Cq4VaiFTw](https://www.youtube.com/watch?v=n4Cq4VaiFTw)
肘弯成 90 度，让二头肌先被拉长一下再收缩。感受"先拉后弹"。
**对症**：不理解 SSC 弹簧机制、动作发僵。

### 0-E · Tomaz 侧向"8"字
**视频**：[Feel Tennis — 0a7s64RgJOs](https://www.youtube.com/watch?v=0a7s64RgJOs)
两手前伸，画水平 8 字。重点是肩膀带着画，不是手画。
**对症**：左右手不协调、Unit Turn 散。

### 0-F · 双手挤压球拍
**视频**：[Feel Tennis — 0a7s64RgJOs](https://www.youtube.com/watch?v=0a7s64RgJOs)
双手对着捏住拍颈，往中间挤。感受上背一片肉绷起来。
**对症**：上背没张力 / 左侧软。

### 0-G · 合掌推挤转动
**视频**：[Feel Tennis — 0a7s64RgJOs](https://www.youtube.com/watch?v=0a7s64RgJOs)
双手合十掌心相对，互推同时上身慢慢转向右后方。
**对症**:上身扭簧建不起来。

### 0-H · 重球扔球
**视频**：[Feel Tennis — oPc8OJkG-zw](https://www.youtube.com/watch?v=oPc8OJkG-zw)
拿个药球（4-6 斤），左手挂在右肩前，整个身体转动把球扔出去。手只是终点不是动力。
**对症**：手臂主导挥拍 / 找不到"身体扔球"的感觉。

## 阶段 1 · 持拍慢动作（静态 / 半场 / 喂球 0-30%）

体感找到了，开始拿拍子但**慢**。

### 1-A · 静态无转体击球
**视频**：[FTT — 5KdScDKxVSI](https://www.youtube.com/watch?v=5KdScDKxVSI)
站定不转身，只做 HSA 闭合击球。隔离测试 HSA 单独够不够发力。
**对症**：搞不清是身体转还是 HSA 出力。

### 1-B · 慢速横拉影子挥
**视频**：FTT — hqganBxzQNM（需自搜 "FTT slow shadow swing"）
没有球，对着空气慢动作完整挥拍。每个阶段卡 1 秒。
**对症**：动作各段拼不起来 / 时序乱。

### 1-C · 半场短挥
**视频**：[TTT Simon — xf93E0Ja0Lk](https://www.youtube.com/watch?v=xf93E0Ja0Lk)
站在半场，挥幅缩小，强迫只用 HSA + 蹬转，不用大臂。
**对症**：动作一大就靠肩屈代偿 / 找不到 HSA 出力点。

### 1-D · Tomaz Half-Half
**视频**：[Feel Tennis — 0a7s64RgJOs](https://www.youtube.com/watch?v=0a7s64RgJOs)
非持拍手（左手）扶着拍颈，左手主导往后带，到位再松开。
**对症**：右手主导 backswing / 左手不知道放哪。

### 1-E · Body-Led（身体带动）
**视频**：[Feel Tennis — oPc8OJkG-zw](https://www.youtube.com/watch?v=oPc8OJkG-zw)
有人辅助按住你的手腕，你转身体把拍子带出去。手是死的。
**对症**：手臂在主动挥 / 身体不参与。

## 阶段 2 · 力量传递（药球 / 弹力带 / 弹弓）

体感和慢动作都过了，开始练**力的传递路径**。

### 2-A · 药球侧砸墙
**视频**：参考 [Kovacs Academy 药球文章](https://kovacsacademy.com/2020/04/16/medicine-ball-wall-drills/)
站墙侧面，双手抱药球做正手挥的动作把球砸墙上。重点是从地面发动。
**对症**：发力链断在某处、上下不连。

### 2-B · 药球斜砍 Wood Chopper
**视频**：搜 YouTube "wood chopper medicine ball tennis"
药球从右上往左下斜着砍。对角能量链。
**对症**：核心不参与、躯干扭力不够。

### 2-C · 弹弓加速
**视频**：[Gordon USPTA 完整版 — n4Cq4VaiFTw](https://www.youtube.com/watch?v=n4Cq4VaiFTw)
身体先转再急刹车，让手臂被甩出去。模拟 trunk slowdown → arm acceleration。
**对症**：转身平稳没有"弹"出去的感觉。

### 2-D · Kinetic Loading
**视频**：[Macci — zac_u3TxxDo](https://www.youtube.com/watch?v=zac_u3TxxDo)
重心后倾加载到右脚后跟，再蹬地起来挥拍。从脚开始的整条链。
**对症**：动作从腰开始（应该从脚）。

### 2-E · Landmine Twist
**视频**：搜 YouTube "landmine twist"
杠铃一端固定在地面，双手握另一端做躯干扭转。
**对症**：核心力量不够、躯干扭转无力。

### 2-F · Dynamic Slot 演示
**视频**：[Gordon USPTA 完整版 — n4Cq4VaiFTw](https://www.youtube.com/watch?v=n4Cq4VaiFTw)
看 Gordon 现场演示 flip（拍头被动加速翻转）的样子。
**对症**：以为 lag 是主动做的 / 想"翻拍头"。

### 2-G · Weighted Ball 持拍版
**视频**：[Feel Tennis — 0a7s64RgJOs](https://www.youtube.com/watch?v=0a7s64RgJOs)
拿球拍，但前面再绑个小重物。慢挥找"左侧拉、右侧被拽"的感觉。
**对症**：右手又主动了 / 左侧失去主导。

### 2-H · WearBands 弹力带反馈
**视频**：[Feel Tennis — 0a7s64RgJOs](https://www.youtube.com/watch?v=0a7s64RgJOs)
非持拍手套弹力带（连到柱子），挥拍时弹力带会"提醒"左手有没有保持张力。
**对症**：左手挥到一半就塌了。

## 阶段 3 · 整合（完整挥拍 / 喂球 50-70%）

前面都过了，开始完整挥。

### 3-A · Shadow Swing 含 Drop
**视频**：[Macci — zac_u3TxxDo](https://www.youtube.com/watch?v=zac_u3TxxDo)
完整影子挥，重点感觉拍头从高位自然 drop 下来。
**对症**：拍头不会 drop、引拍位置不对。

### 3-B · Flip Drill
**视频**：[Macci — zac_u3TxxDo](https://www.youtube.com/watch?v=zac_u3TxxDo)
专门练拍头的"被动翻转"。手腕完全松，让身体把拍头甩过来。
**对症**：找不到 lag、想用手腕做 lag。

### 3-C · Off-Arm Pull 整合
**视频**：[Tomaz Part 1 — gyZxjDlmp2I](https://www.youtube.com/watch?v=gyZxjDlmp2I) + Feel Tennis 系列
完整挥拍时**只想左手做什么**。右手忘掉。
**对症**：右手老想主动、球软。

### 3-D · 慢速完整挥（带哑铃）
**视频**：搜 "weighted forehand swing slow"（FTT 协议）
持 1-2 公斤哑铃做完整正手挥，5+5+5 三组。
**对症**：动作整合后还是发软、各段不连。

### 3-E · Fence Push 推围栏
**视频**：无视频（Bourne *Power Solution* p136-137 书里图示）
面向围栏站，模拟挥拍但最后让拍头"推"过围栏。强迫拍头加速时机对。
**对症**：拍头加速太早 / 太晚。

### 3-F · 高拍头启动
**视频**：[TTT Simon — 5_vJU8XJOTs](https://www.youtube.com/watch?v=5_vJU8XJOTs)
准备和引拍时，拍头始终高于手柄。左手扶着拍颈控位置。
**对症**：拍头一开始就低 / 右手紧张。

### 3-G · Coil-Uncoil 放松验证
**视频**：[TTT Simon — 5_vJU8XJOTs](https://www.youtube.com/watch?v=5_vJU8XJOTs)
重点不在挥，重点在击球前那一刻右手前臂是不是**完全松**。松了 lag 自然出现。
**对症**：强行做 lag / 手腕主动延迟。

## 阶段 4 · 实战（喂球机 / 比赛）

### 4-A · 发球机分速段
不同球速（30/50/70 km/h）各练一组。慢速找体感、快速验证。
**对症**：慢速行快速崩、镜前完美球场失败。

### 4-B · 变方向喂球
左右穿梭喂球，看 HSA 在不同站位是否一致。
**对症**：正位行偏位崩。

### 4-C · 比赛模拟 + 自检视频
带相机打练习赛，每局后回看 30 秒。让录像替代感觉做仲裁。
**对症**：感觉良好但实际动作走样。

### 4-D · 被动状态下的 HSA
专门让球落到尴尬位置（远、近、深、浅），看动作还在不在。
**对症**：主动球行被动球散。

## 解剖术语对照（常被混淆，必须分清）

| 术语 | 是什么 | **不是什么** |
|---|---|---|
| **ESR**（External Shoulder Rotation）| 肩关节外旋，肱骨绕自己长轴往外转 | 不是抬肩、不是翻手腕、不是肩胛后缩 |
| **ISR**（Internal Shoulder Rotation）| 肩关节内旋，肱骨绕自己长轴往内转 | 不是前臂旋前、不是手腕屈 |
| **Pronation**（前臂旋前）| 桡骨绕尺骨转，手掌朝上→朝下 | **不是**肩内旋（不同关节） |
| **Supination**（前臂旋后）| 桡骨绕尺骨转，手掌朝下→朝上 | 不是肩外旋 |
| **HSA**（Horizontal Shoulder Adduction）| 水平面上肩内收，胸-肱角闭合 | 不是 ISR，不是前臂动作 |
| **真正的 ESR 主力肌**| 冈下肌 + 小圆肌 | **不是**背阔肌（背阔反而是内旋） |
| **真正的 HSA 主力肌**| 胸大肌（主驱动）+ 肩胛下肌 + 大圆肌 | **不是**三角肌前束（前束激活 = 球软信号）|

**常见搞混**：
- "撕"动作 = ISR（肩内旋）+ Pronation（前臂旋前），**两个独立关节**的动作合在一起。教练说"press"包含这两层。
- 用"背"做 ESR = **错**。背阔肌主动收会把肱骨拉向内旋（IR 方向），看起来肩抬起来了实际是 ESR 没真做。5/16 内上髁炎根因。
