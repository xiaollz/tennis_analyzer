## 跨书核心 takeaway

### 共同点（3 本书都覆盖）
1. **Elbow first not racket first**（Forehand / Power 直接 / Backhand 隐含）
2. **Pronation 是被动结果**（明确反对 "wrist snap"）
3. **External focus cue 取代 internal focus 解剖**（Wulf 范式实践）

1. **ESR 独立成章** p47-50（强化 5/8 ESR 根因）

3. **双 kinetic chain（body + arm）** p77-84（验证 4/27 两系统并行）
4. **Fence Push drill** p136-137（唯一可执行新 drill）
