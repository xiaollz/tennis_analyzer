## Core Correction

The user had been trying to solve the forehand by finding or waiting for the racket drop. TPA and FTT together suggest a different training priority:

```text
First build the ability to slap / flip / release through supination.
Then gradually smooth the motion and allow a deeper Djokovic-like drop / pat-the-dog shape.
```

This does **not** mean mature forehands have no racket drop. It means the user's current bottleneck is not the visual shape of the drop. The bottleneck is the missing release mechanism.

---

## TPA: Slap Into Slot

TPA's learner case is direct:

```text
Ryan gets stuck when he tries to place the racket into lag/drop.
Tom first gives him a crude high slap to create supination / flip / release.
Only after that becomes comfortable should the motion be smoothed and the racket allowed to lower more like Djokovic.
```

### Correct progression

```text
Stage 1 now:
  high setup -> direct slap -> learn supination / flip / release

Stage 2 later:
  smooth the motion -> allow a slightly lower racket drop -> slap/release from the more advanced slot
```

### Wrong progression

```text
try to pre-place pat-the-dog / low slot
-> wait for the drop
-> pull the lagged racket forward with hand/forearm
```

This wrong progression is very close to the user's recent failure pattern: the racket appears to drop, but the arm has not released; the player then drags the racket forward and finishes with brushing/fussing rather than a true slap-through.

## FTT: Throw Down To Hit Up

FTT's biomechanical framing explains why the TPA drill works.

The arm/hand/elbow path can feel level or even high-to-low, while the racket head still travels low-to-high because the forearm/racket system rolls:

```text
arm/hand path: overhand / throw-down / level-through
racket head path: drops below the hand, then rises through the ball
mechanism: supination -> release/roll -> pronation, with racket inertia
```

FTT separates two things that the user had been mixing:

| Item | What the player should feel/train first | What appears visually later |
|---|---|---|
| Arm path | Overhand / throw-down / slap-through | Hand may look level or slightly descending |
| Racket path | A consequence of release | Racket drops below hand and comes up through contact |
| Topspin source | Forearm/racket roll plus racket-head path | Not active hand lifting |
| Drop/pat-the-dog | Not a static pose to find | A passing shape inside a dynamic release |

This is why "throw down to hit up" and "slap into slot" are the same family: both move attention away from active low-to-high lifting and toward release of a connected, higher arm structure.

---

## Unified Causality

```text
High-side structure / overhand frame
  -> direct slap / throw-down intention
  -> forearm supination / flip appears
  -> racket head drops dynamically into slot
  -> release continues through the ball
  -> pat-the-dog / lower drop can be added later as a smoother, more advanced shape
```

The critical inversion:

```text
Drop is not the prerequisite for slap.
Slap/release is the learning doorway that lets drop happen correctly.
```

## Why The User Could Not Feel Chest-Driven Contact

The 2026-06-12 FTT recheck supports the user's new explanation:

```text
static low racket drop / manual pat-the-dog
  -> chain stalls at the low point
  -> left-side abdominal pull / clear does not happen
  -> chest-back support disappears
  -> body rotation cannot pull the racket
  -> arm/forearm/wrist must compensate
```

In FTT language, this is the underhand trap: when the elbow drops and the racket is actively lowered, rotation no longer transfers into the racket. In the healthy overhand/slap model, the elbow stays supported outside/up, the scap-lat/rotator-cuff system holds the upper arm, the left side clears, and chest rotation can create the dynamic lag/drop.

Therefore, the user's missing "chest forward" feeling was not a separate chest problem. It was downstream of a broken support structure and wrong drop priority.

## Training Rule

This is a drill progression, not a permanent in-swing thought.

### Current priority

```text
高位一掌，拍头自掉。
```

or slightly longer:

```text
先高位 slap，练出 supination/release；熟了再加更低、更顺的 drop。
```

### Avoid for now

```text
先等拍头降完，再挥。
```

### Future progression

Once the slap/release pathway is reliable on video:

```text
high slap scaffold
-> smoother drop
-> lower pat-the-dog / Djokovic-like slot
-> still release-based, not hand-dragged
```

---

## Boundaries

1. Do not turn this into active wrist flicking.
2. Do not turn TPA's elbow language into active "推肘". Elbow-forward is an observable result of connected structure and chain start.
3. Do not keep a totally floppy wrist. The hand must hold the racket securely enough for V-shape control; the forearm/racket can still flip.
4. Do not make "supination" a court thought on every ball. Use it as a short-term drill to build the missing release pathway.
5. Do not call this a personal root-cause bible until the next court video confirms reduced hand-pull, reduced forearm lift, and dynamic drop.
