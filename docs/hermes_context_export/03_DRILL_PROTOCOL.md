# 03 · Drill 协议（训练时给具体动作）

> **Hermes 训练时第二常用文件**。用户问"怎么练 / 给我个 drill" → 立即从这里拿。**禁止讲道理，直接给 drill**。

---

## 🎯 给 drill 的 4 条规则（不准违反）

1. **一次最多给 3 个 drill**（违反 = Intuition Paradox 协议堆 cue）
2. **必须按用户当前 Stage** 给（A/B/C，见下）
3. **必须直接从总表拉编号**（0-H / 1-D / 2-G 等），不创造新 drill
4. **第一句 = drill 编号 + 名字 + 立即做的体感锚**

---

## 📊 用户当前 Stage（5/10）

```
Stage A → B 过渡

✅ Stage A 完成: 不持拍体感建立（0-E/0-F/0-G/0-H 体感已到位）
🔄 Stage B 进行: 持拍整合（1-D/1-E）
⏳ Stage C 待开始: 实战调用（2-G/2-H/3-C）
```

→ Hermes 默认从 Stage A/B drill 选择。Stage C 仅在用户明确说"我能持拍负重"时给。

### 阶段 4：实战调用

| # | Drill | 一句话做法 |

## 🎯 当前 5/10 主线训练（Unit Turn 顶髋诊断）

用户 5/10 撞到的问题——**4/27 圣经的体感失败信号**。

### Sit Test（5/10 当前必做体感校准）

**做法**：
1. 站立，模拟 Unit Turn 准备位
2. 闭眼做 Unit Turn
3. 自检：右髋是 **向下沉（屈髋 / Sit）** 还是 **向外侧顶（abduction / Push）**？
4. 体感锚点：
   - ✅ 对：**右大腿后侧 + 臀部**承重
   - ❌ 错：**右髋外侧**紧张

**Gregg [03:07] 视觉 cue**："像有人冲过来你想挡住"——这是屈髋后坐的体感。

## ⛔ Drill 禁忌

1. **不要给 10 个 drill 让用户自选**——只给 3 个
2. **不要发明新 drill**——只用总表里的
3. **不要堆 cue 进 drill**——drill 本身就是体感入口，不需要再附 5 个口令
4. **不要假设用户在球场上**——大部分 drill 是镜前/家里可做
5. **不要混合 Stage**——一次训练只走一个 Stage
