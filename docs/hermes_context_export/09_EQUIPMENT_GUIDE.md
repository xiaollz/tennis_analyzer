## 🎾 穿线服务（用户在中国市场）

### 用户当地两个选项

| 选项 | 工费 | 描述 |
|---|---|---|
| ¥30 / 次 | 普通店，穿的次数多 | 用户当前推荐 |
| ¥60 / 次 | "国际认证 + 得过奖" | 不推荐溢价 |

线材：用户**自带线**，不含工费里。

### 5/8 实证结论：选 ¥30

按用户当前阶段：
1. **技术变量太大**（5/2-5/10 一周内 cue 全在变）—— 装备差距被技术变化淹没
2. **训练强度低**（发球机最低速）—— 高端穿线优势用不到
3. **线衰减慢**（低速冲击小）—— 不需顶级保线寿
4. **省下的钱（¥30/次 × 6 次/年 = ¥180/年）拿去测不同线材** ROI 更高

### 真要去 ¥60，先确认

下次去 ¥60 那家**问"什么认证"**：
- MRT (USRSA Master Racquet Technician) → 真金，是良心价
- CRT (USRSA Certified) → 中等
- ERSA / ITF tour stringer → 中等偏上
- 国内自定义协会 → 营销溢价

**关键提醒**：用户报"没感觉出来 60 比 30 好"是**没盲测过**——不是"没差距"。当前阶段（3 个月球龄 + 技术不稳）感知不出 ¥60 价值是正常的。

### 何时该回 ¥60（3 触发条件）

到一条再考虑：
1. **6-12 个月后技术稳定** + 实战频率每周 3+
2. 想用 hybrid 穿线（主聚酯 + 副多丝/羊肠）
3. 球拍升级到比赛级（单拍 ¥1500+）

到时做 A/B 盲测验证。
