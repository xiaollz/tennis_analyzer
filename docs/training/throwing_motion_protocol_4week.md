# 投手式被动臂 4 周训练协议

> **入口体感（4/30 用户原话）**：像棒球/垒球投手——左手托右手到引拍位 + 右手完全被动 + 身体极度蜷曲 + 胸推背撑前推。
>
> **诊断**：用户已掌握所有解剖件（右脚为轴 / 肩胛槽 / 大臂住肩窝 / 胸推肘），但默认大脑路径仍是"大臂主动甩"（State B）。投手类比绕过解剖语言，用一个**全身已会的动作模板**强行触发被动臂模式（State A）。
>
> **本协议不替代** `arm_body_connection_protocol_6week.md`——它是后者的并行支线，专攻"切换扳机"。两套可以同周做，**早晚分开**。
>
> **核心隐喻**：投手不"挥"球，投手"释放"球。手臂不是工具，是被身体甩出去的鞭梢。

---

## §0 协议总览

**4 周路径**：

| Phase | 周 | 场景 | 工具 | 一句话目标 |
|---|---|---|---|---|
| **P1 投球脱敏** | W1 | 场下 | 毛巾 / 棒球 / 网球 | 让身体先记住"被动臂"是什么 |
| **P2 球拍 setup** | W2 | 场下空挥 | 球拍 | 把投球 setup 嫁接到拍上 |
| **P3 挂球 + 慢喂** | W3 | 场上静态 | 球 + 拍 | 静态条件下用投球感击球 |
| **P4 实战压力** | W4 | 对拉 / 训练赛 | 全部 | 压力下不丢投球感 |

**升级原则**：硬性 criteria，不是周数。任一不满足 → 当周延长。

**与 6 周协议的关系**：
- 6 周协议练**肌肉**（前锯肌 / 下斜方肌神经通路）
- 本协议练**模板**（用投球这个全身已会的动作，触发同样的肌群）
- 6 周协议是"从下往上"激活，本协议是"从上往下"借用

**剂量天花板**：每天 ≤ 30 分钟。投球动作肩关节负担大，不堆量。

## §1 Phase 1 · 场下投球脱敏（Week 1，无球拍）

**目标**：让大脑先体验"右臂完全被动"是什么神经感觉，把"主动挥小臂"的默认值松开一次。

### Drill 1.1 · 扔毛巾（Towel Throw）

- **步骤**：
  1. 一条中等浴巾，对折再对折成长条。右手抓巾的一端
  2. 投手 setup：左脚在前侧身，左手前指、右手提巾到耳后（**像投棒球的引拍位**）
  3. 重心右脚 → 髋启动 → 胸打开 → **靠胸的前推把毛巾"甩"出去**，手臂全程不主动加速
  4. 毛巾落地的一端越靠前 = 鞭打越好
- **频率**：每天 20 次 × 2 组（早 / 晚分开）
- **时长**：8 分钟
- **做对的体感**：
  - 毛巾末端"啪"一声脆响（小臂被抽出去的)
  - 手臂结束位在身体左前方（不是右前方）
  - 大臂内侧贴胸，不是外展
- **失败模式**：
  - 毛巾闷响 / 没有甩鞭声 = 主动用大臂砸（错）
  - 毛巾落在右侧 = 没等胸打开就甩了（错）
  - 肩前侧酸 = 三角肌前束抢跑（错）
- **升级标准**：连续 10 次都有清晰的鞭响 → 进 1.2

### Drill 1.2 · 轻球抛投（橡胶球 / 棒球）

- **步骤**：
  1. 找一面墙，距离 5 米，手里一颗轻球（棒球 / 橡胶球，**不要网球**——网球太轻反而诱发主动挥）
  2. **关键**：左手把球放进右手掌心 + 把右手抬到投球引拍位（**强迫左手主动、右手被动**的肌肉记忆）
  3. 极度蜷曲：左肩朝墙、右肩朝后、胸闭合像"压扁的弹簧"
  4. 髋先启动 → 胸展开 → 球被甩出
  5. **右手在整个过程像被借走了一样**
- **频率**：每天 15 次 × 2 组
- **时长**：6 分钟
- **做对的体感**：
  - 蜷曲到末端时，**胸大肌外侧明显被拉伸**（这是 4/30 上午"胸推肘"的真实张力）
  - 球出手后，右手大拇指指向左膝（说明完整 pronation 发生）
- **失败模式**：
  - 球出手后右手指还指向右前方 = 没 release，主动臂模式
  - 蜷曲不够、胸没张力 = 直接进入挥臂
  - 球速忽快忽慢 = 主动臂在补偿（被动臂的速度应该非常一致）
- **升级标准**：10 次里 ≥ 8 次胸大肌有明确拉伸感 + 大拇指收尾指向左膝

### Drill 1.3 · 对墙短抛（连续节奏）

- **步骤**：
  1. 距墙 3 米，**站定不动脚**（隔离上身）
  2. 球弹回 → 单手接 → 立即用左手"重置"到引拍位 → 再投
  3. 节奏：每 4 秒一次
- **频率**：每天 30 球 × 1 组
- **时长**：4 分钟
- **做对的体感**：节奏稳定、肩不酸、左手在做"管家"工作
- **失败模式**：
  - 球越投越偏 = 想发力了
  - 肩前侧酸 = 三角肌抢跑，立即停
- **升级标准**：30 球能稳定节奏 + 肩不酸 → P1 通过

### Phase 1 通过 criteria（全满足才进 P2）

- [ ] 1.1 毛巾连续 10 次脆响
- [ ] 1.2 胸大肌拉伸感 ≥ 80%
- [ ] 1.3 30 球连续 + 肩不酸
- [ ] 自检：闭眼回想"右臂被借走"的感觉，能立刻调出来

## §2 Phase 2 · 球拍上的投球 setup（Week 2，场下空挥）

**目标**：把 P1 学到的"左手管家 + 右手被动 + 极度蜷曲"嫁接到球拍上。**这是最容易丢失的转换**——拍一上手，主动挥的本能立刻回来。

### Drill 2.1 · 双手托拍 wind-up

- **步骤**：
  1. 双手扶拍 ready position，**左手是主动方**——左手把整支拍**托**到引拍末端（不是扶着跟去）
  2. 在托的过程中，右手**完全不参与**，像挂在拍柄上
  3. 到位后冻结 3 秒，**自检右大臂前侧三角肌——如果硬 = 错**
  4. 用右手的"被动"完成击球轨迹，左手在前挥时往身体左后拉离
- **频率**：每天 30 次 × 2 组
- **时长**：8 分钟
- **做对的体感**：
  - 引拍末端，握拍手重量像挂在肩窝里（不是端着）
  - 这其实就是 Bourne 双手扶拍的**升级版**——从"双手都用力"变成"左主动右被动"
- **失败模式**：
  - 右手提前发力 = 没 wind-up，直接 swing
  - 三角肌前束硬 = State B 复发
- **升级标准**：连续 20 次右大臂前侧全程可被外力按动

### Drill 2.2 · 蜷曲张力测试

- **步骤**：
  1. 完成 2.1 的 wind-up
  2. 在引拍末端**多保持 5 秒**，自检三件事：
     - 胸大肌外侧（靠近腋下）有没有被拉伸感？
     - 右肩胛骨"卡进槽"了吗？（4/30 晚圣经）
     - 右髋能不能再多转 5°？（"再蜷一点"）
  3. 如果三件事都通过 → 释放（前挥）
  4. 任一项失败 → 不释放，重 setup
- **频率**：每天 15 次 × 2 组
- **时长**：6 分钟
- **做对的体感**：像把一根弹簧压到底——**释放是被弹的，不是推的**
- **失败模式**：
  - 胸没有拉伸感 = 蜷曲不够 / 已经主动挥
  - 自检时三角肌发力 = 蜷曲变成了"端"
- **升级标准**：15 次里 ≥ 12 次三件事全过

### Drill 2.3 · 对侧手指引（Glove Hand 网球版）

- **步骤**：
  1. 投手的 glove hand（戴手套那只）在前挥时**主动拉到躯干内侧** → 加速躯干旋转
  2. 网球版：左手在前挥起步时，**主动往左后下方拉**（不是被甩开，是主动拉）
  3. 自检：左手收尾位置应该在**左髋外侧 / 左腰后侧**，不是飘在身前
- **频率**：每天 20 次 × 2 组
- **时长**：5 分钟
- **做对的体感**：
  - 左手"拉"出去的瞬间，能感到躯干被这个反作用加速旋转
  - 这是 FTT "左手拉离" 的物理升级——不是为了平衡，是为了**驱动**
- **失败模式**：
  - 左手飘在身前 = 没拉，只有右臂在动
  - 拉得太早（unit turn 阶段就拉）= 失去蜷曲张力
- **升级标准**：20 次里 ≥ 16 次左手收在左腰后侧

### Phase 2 通过 criteria

- [ ] 2.1 右大臂前侧 20 次全程可按动
- [ ] 2.2 蜷曲三件事 ≥ 12/15
- [ ] 2.3 左手收尾 ≥ 16/20
- [ ] 综合自检：闭眼空挥一次，能描述出"左手托 → 蜷 → 释放"三段，并且右臂全程是"被借走"的

## §3 Phase 3 · 挂球 + 慢喂球（Week 3，场上静态）

**目标**：把投球感放到**真实击球**里。这一周不练对拉，只练"静态/极慢"条件下的投球式击球。

### Drill 3.1 · 挂球 + 投球 setup（独立训练）

- **步骤**：
  1. 球用绳挂在合适高度（接触点 = 大约腰高）
  2. **每球前必走**：左手托拍到引拍位 → 蜷曲三件事自检 → 释放
  3. 击球后，球应该被"打穿"（绳子大角度甩出去），不是"敲响"
- **剂量**：50 球 × 2 组，组间休 3 分钟
- **频率**：每周 3 次
- **做对的体感**：
  - 击球瞬间右臂**还在被甩中**，不是"挥到了"
  - 球出去的速度感觉"大于自己出的力"——这就是鞭打
- **失败模式**：
  - 球被"敲" = 主动臂复发，立即停 reset
  - 连续 3 球失败 = 这组作废，回到 2.1 重做 5 次空挥再继续
- **失败 reset 流程**：
  ```
  1. 放下球拍 30 秒
  2. 闭眼回想 P1 毛巾的"鞭响"
  3. 双手扶拍空做 3 次 2.1
  4. 再回挂球
  ```
- **升级标准**：50 球里 ≥ 35 球（70%）大臂前侧软

### Drill 3.2 · 极慢喂球（5-7 秒/球）

- **步骤**：
  1. 喂球者每球间隔 5-7 秒（数 3-2-1）
  2. 用户用全部时间走完投球 setup：
     - 数 3：双手扶拍 + Bounce Reset
     - 数 2：左手开始托 + 右脚压
     - 数 1：蜷曲完成 + 三件事自检（出声念"胸 / 槽 / 髋"）
     - 喂球：释放
  3. 击球后立刻自检："右臂是被借走的吗？"
- **剂量**：30 球 × 2 组
- **频率**：每周 2 次
- **做对的体感**：每球都有充分时间感受 setup 的**完整张力建立**
- **失败模式**：
  - 等不及喂球先做完 setup 然后散掉 = 蜷曲泄力，要重新蜷
  - 喂球到了 setup 还没好 = 节奏没对齐，让喂球者再慢一点
- **升级标准**：30 球三件事全过 ≥ 22 次

### Drill 3.3 · 节拍器投球节奏（60 BPM）

- **步骤**：
  1. 手机开节拍器 60 BPM
  2. **第 1 拍**：双手扶拍 + 启动 setup
  3. **第 2 拍**：蜷曲到末端（左手托拍到位 + 三件事完成）
  4. **第 3 拍**：释放（击球）
  5. **第 4 拍**：随挥到位 + reset
- **剂量**：30 球
- **频率**：每周 1 次
- **做对的体感**：身体被节拍**强行拉慢**，主动臂没有时间抢跑
- **失败模式**：
  - 第 3 拍前球已经被打了 = 主动加速，重新对拍
  - 第 3 拍到了还在蜷 = setup 慢了，下一球缩短第 1 拍
- **升级标准**：30 球节奏全部对齐 + 三件事 ≥ 22/30

### Phase 3 通过 criteria

- [ ] 3.1 挂球 ≥ 35/50 大臂软
- [ ] 3.2 慢喂球三件事 ≥ 22/30
- [ ] 3.3 节拍器节奏全对齐
- [ ] 击球后能在 1 秒内说出"这球是投球感还是挥臂感"

## §4 Phase 4 · 实战压力下保持投球感（Week 4）

**目标**：进对拉 / 训练赛，**保住投球感不丢**。不追求结果，追求"丢了能找回"。

### Drill 4.1 · Pre-Point Routine（投球感激活版）

每球前 4 秒固定流程：

```
1 秒：Bounce Reset（清残留）
1 秒：双手扶拍——左手摸右手手腕（强化"左主动右被动"）
1 秒：右脚压（4/27 圣经下肢轴）
1 秒：心里念"托"（4/30 晚圣经上身轴 + 投球 wind-up 入口）
```

**4 个字 = 下肢轴 + 上身轴 + 投球感 三合一**。

- **剂量**：每球前必走，包括对拉、训练赛
- **失败信号**：连续 3 球没走 routine = 默认值已接管，**强制停 1 分钟**走 §3 的失败 reset

### Drill 4.2 · 实战丢失 reset 协议

实战必然丢，关键是丢了怎么找回——不是怎么不丢。

- **触发条件**（任一即触发）：
  - 自己感觉"上一球右臂主动了"
  - 球软 / 没穿透
  - 肩前侧开始酸
- **Reset 流程**：
  ```
  1. 立刻走到底线后方（脱离对打节奏）
  2. 空做 3 次 §1 Drill 1.1 毛巾动作（即使没毛巾，做空抛）
  3. 闭眼念一遍"托 → 蜷 → 释"
  4. 回场，下一球必走完整 routine
  ```
- **频率指标**：每周记录 reset 次数。第 1 周可能 10+ 次，到第 4 周末应该 ≤ 3 次

### Drill 4.3 · 录像投手自检

- **步骤**：
  1. 训练赛或对拉，从右后侧 45° 角架手机
  2. 录连续 10 个正手
  3. **不看技术，看像不像投手**——暂停在引拍末端，问自己：
     - [ ] 蜷曲度看得见吗？（胸闭合、左肩朝前）
     - [ ] 左手是不是托的姿势？
     - [ ] 右大臂是不是贴着身体？
     - [ ] 释放时左手有没有拉到左后？
  4. 4 项里 ≥ 3 项 = 投手感在
- **频率**：每周 1 次
- **升级标准**：10 球里 ≥ 7 球四项 ≥ 3

### Phase 4 通过 criteria（4 周末验收）

- [ ] 4.1 routine 执行率 ≥ 85%（对拉中）
- [ ] 4.2 reset 触发 ≤ 3 次/周
- [ ] 4.3 录像投手感 ≥ 7/10
- [ ] 主观：能在击球时**同时**感觉到右脚压 + 肩胛槽 + 投球感（三件事并行）

## §5 每周升级标准与退回信号

### 升级（进入下一 Phase）

| 当前 | 进入下一阶段需要 |
|---|---|
| P1 → P2 | 三个 drill 全部 criteria 满足 + 闭眼能调出"右臂被借走"感 |
| P2 → P3 | 球拍 setup 三个 drill 满足 + 不上球能稳定演示完整 wind-up |
| P3 → P4 | 挂球 + 慢喂 + 节拍器三个 drill 满足 + 能在 1 秒识别投球感/挥臂感 |
| P4 → 固化 | routine 85%、reset ≤ 3、录像 7/10 |

**严格执行**：criteria 是硬约束，时间是参考。

### 退回（这些信号必须退回上一阶段）

| 信号 | 退回到 | 原因 |
|---|---|---|
| 任何阶段：肩前侧持续酸 ≥ 2 天 | P1 + 完全停拍 1 周 | 三角肌抢跑过度，神经通路在强化错误 |
| P3：连续 2 次训练挂球 < 50% 大臂软 | P2 + 加做 Drill 2.1 双倍 | setup 没固化，前进无效 |
| P4：routine 执行率 < 50% | P3 + 重做节拍器 drill | 实战压力把节奏冲散，回去夯实 |
| P4：录像看不到蜷曲 | P2 Drill 2.2 + P3 Drill 3.2 | 蜷曲是全协议的核心张力来源，丢了一切都丢 |

### 红线（出现立即停训找原因）

- 肩关节后侧 / 内侧疼（不是酸）→ 可能是 wind-up 角度过大压肩袖
- 肘关节内侧痛 → 可能是 release 时主动用了小臂
- 击球后右大拇指麻 → 可能是 pronation 过度

**不要硬撑，硬撑会让错误模式被神经固化。**

## §6 与已有 cue 的整合

### 投球感是 11 字系统的什么？

**结论**：投球感是**触发器**（trigger），不是新口令。它的作用是用一个全身已会的模板，**一次性激活** 11 字系统里 5-6 个字的协同状态。

### 关系图

```
"压"（右脚） ──┐
"托"（肩胛槽）─┤
"撑"（左臂） ─┼─ 投球感 = 这些字的"和弦"，一个动作激活全部
"推"（胸→肘）─┤
"流"（小臂） ─┘
```

- 投球感**包含**了：压（右脚为轴）、托（肩胛槽）、撑（左臂主动拉）、推（胸推肘）、流（小臂被动）
- 投球感**不替代**任何一个字——它是把这些字打包成一个**生物学已会的 chunk**
- 当用户走 11 字逐字执行时容易"想多丢一"，走投球感 chunk 时容易**全部就位**

### 推荐"投球字"候选：**"投"** 或 **"甩"**

| 候选字 | 优势 | 劣势 |
|---|---|---|
| **"投"** | 直接激活投球模板 / 全身已会 / 隐含"右臂被动" | 字面像"扔出去"，可能误导成"主动扔" |
| **"甩"** | 强调"被动鞭打" / 与"小臂被甩"一致 | 已被部分体系借用，可能歧义 |

**建议**：先用 **"投"** 字做训练辅助 cue（同"抱/弹/点/跟"），4 周协议结束后回看：
- 如果"投"字能稳定激活全套和弦 → **升级进 11 字系统**，与"压/托"并列
- 如果只能在场下激活，实战丢失 → **保留为辅助 cue**，不进 11 字

### 使用时机

| 场景 | 推荐用法 |
|---|---|
| 场下空挥 | 走完整 11 字（精确诊断） |
| 慢喂球 | 走 5 字（压/托/撑/推/流） |
| 对拉 | 走 routine 4 字（弹/抱/压/托）+ 出手前心里"投" |
| 比赛 | 只用"投"字 chunk（注意力顶不住分字） |

**核心原则**：压力越高，字越少。投球感是为高压场景准备的"压缩包"。

### 与 6 周协议的并行

- 6 周协议（早晨）= 肌肉激活，从下往上建通路
- 4 周投球协议（傍晚）= 模板触发，从上往下借通路
- 两套**指向同一终点**（State A），互补不冲突
- 4 周完成后，投球感成为日常自检 trigger，6 周协议的肌肉激活套件继续维持（不停）
