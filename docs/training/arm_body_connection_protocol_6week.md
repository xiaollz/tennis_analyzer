# 大臂-躯干一体化 6 周训练协议

> **诊断**：用户已建立认知层面的 State 1（大臂跟躯干一体），但默认运动模式仍是 State 2（大臂独立飘动）。空挥时能执行 State 1，喂球时部分丢失，实战时几乎全部回退。
>
> **根因**：State 1 不是单一动作，是**前锯肌 + 下斜方肌 + 胸大肌 + 肩胛下肌**的协同张力网络。神经通路没建立 → 大脑在压力下走最熟悉的路（三角肌前束 + 二头肌主导的"举起手臂"模式）。
>
> **协议目标**：6 周内把"大臂卡进肩窝、被胸推出去"从意识动作 → 默认动作。
>
> **不是教技术，是激活肌群 + 重写默认值。**

## Phase 1（Week 1-2）：肌肉激活 + 神经唤醒（场下）

**目标**：让用户能**主动单独激活**前锯肌、下斜方肌；学会**主动放松**三角肌前束。
不上场，不碰拍，每天 5-10 分钟。

**为什么先做这个**：State 2 的根因是大脑找不到前锯肌/下斜方肌——它们在日常生活中几乎不被孤立调用。激活前你想"用胸推"会自动变成"用三角肌前推"，因为三角肌是默认值。

### 1.1 前锯肌激活套件（每天 1 套）

| Drill | 步骤 | 时长/组数 | 做对的体感 | 做错的失败模式 |
|-------|------|----------|-----------|--------------|
| **墙面 push-up plus** | 面墙站立，双手与肩同宽撑墙。手肘**保持锁直**，只用肩胛骨前推（胸离墙更近）→ 后缩（胸贴近墙）。前推到末端时刻意"再往前 1 cm"——这 1 cm 就是前锯肌 | 12 次 × 2 组 | 腋下下方（肋骨外侧）有酸胀感 | 弯肘 = 用三头肌代偿；耸肩 = 用上斜方代偿 |
| **熊式爬行 hold（Bear hold）** | 四足跪姿，膝盖离地 2 cm，肘锁直，肩胛骨主动前推（背呈微圆而不是塌腰） | 30 秒 × 2 组 | 肩胛骨外侧 + 核心同时点燃 | 塌腰 = 没前推，靠骨架撑着 |
| **Serratus punch（站姿）** | 站立，单手前伸至肩高，肘锁直。**只用肩胛骨**把整条手臂再往前推 2-3 cm，再回收。慢——每次 3 秒推 3 秒回 | 每侧 10 次 × 2 组 | 拳头能感到向前"延展"，腋下下方点燃 | 整个躯干往前晃 = 没分离出肩胛骨 |
| **Wall slide** | 背贴墙，前臂贴墙呈 W 型，缓慢上推到 Y 型。前臂**全程不离墙**——做不到说明肩胛骨被锁死 | 8 次 × 2 组 | 肩胛骨在背上"滑"——能感到它在动 | 前臂离墙 = 肩胛骨没动靠胸推 |

**完成验收**：Week 2 末，能**意识指挥下**单独感受到肋骨外侧（前锯肌位置）的发力。做不到 → Phase 1 延长 1 周，不进 Phase 2。

### 1.2 下斜方肌激活套件（每天 1 套）

下斜方肌位置：肩胛骨下角 → 脊柱中段。这是把肩胛骨"按住"不让它上飘的关键肌——上飘就是耸肩，耸肩就是 State 2。

| Drill | 步骤 | 时长/组数 | 做对的体感 | 做错的失败模式 |
|-------|------|----------|-----------|--------------|
| **Prone Y-raise（俯卧 Y 抬手）** | 俯卧，双臂前伸呈 Y 型（拇指朝上）。**只把双臂抬到与肩平行**（不是高过头），停 2 秒 | 10 次 × 2 组 | 肩胛骨下角往脊柱靠 + 往腰部沉 | 耸肩 = 上斜方在干活，下斜方没激活 |
| **Prone T-raise** | 同上但双臂呈 T 型，掌心朝下，拇指朝上。抬到肩平 | 10 次 × 2 组 | 两块肩胛骨之间夹紧 | 头抬起来 = 颈椎代偿 |
| **Scapular pull-up（无器械版）** | 站立，双手举过头顶贴墙。**不弯肘**，仅靠肩胛骨下沉把整个躯干"拉低" 1-2 cm | 8 次 × 2 组 | 腋下后方下沉 | 弯肘 = 引体向上的代偿 |
| **耸肩对偶 drill** | 故意耸肩 5 秒（感受上斜方紧张）→ 主动**把肩胛骨往腰部沉** 5 秒。重复 8 次 | 4 分钟 | 学会区分"耸"和"沉" | 这就是 drill 本身——不会区分就要继续做 |

**完成验收**：Week 2 末，**站立闭眼**能感受到肩胛骨"沉"或"浮"两种状态，并能在 1 秒内切换。

### 1.3 三角肌静默 drill（学会主动放松）

State 2 的核心错误是三角肌前束抢跑。Phase 1 必须建立"三角肌静默"的体感。

| Drill | 步骤 | 时长/组数 | 做对的体感 | 做错的失败模式 |
|-------|------|----------|-----------|--------------|
| **手臂悬挂诊断** | 直立，让对手（或自己另一只手）抓住你的手腕**慢慢往前抬到肩高**。你的任务是**完全不参与**——让手臂被动被抬起来 | 每天 5 次 | 三角肌前束**没发力**，手臂像挂着一样 | 手臂"轻"了 = 你在帮忙抬 = 三角肌还在活 |
| **大臂卡肩窝静态保持** | 侧身预备站姿，引拍到 Bourne 抱球位（45° 肩转，双手扶拍）。**只用胸 + 背锁住大臂**，三角肌前束放松。保持 30 秒 | 30 秒 × 4 组 | 胸前外侧 + 腋下后侧 持续张力，大臂前侧（三角肌）软 | 大臂前侧硬 = 三角肌锁死 = 整个 protocol 失效 |
| **拍头悬挂自检** | 拿拍，预备站姿。让拍头**自然下垂**——不靠手腕固定，仅靠握拍最小张力。3 秒 | 5 次 | 拍头会轻微晃动（说明手臂松） | 拍头一动不动 = 手臂全程紧绷 |

**完成验收**：Week 2 末，"大臂卡肩窝静态保持"能稳定做 60 秒，且大臂前侧三角肌**全程可被外力按动**（同伴用手指能轻易压下去）。

### 1.4 Phase 1 每日训练表

```
晨起 5 分钟：
  - 墙面 push-up plus  12×2
  - Wall slide  8×2
  - 耸肩对偶 drill  4 分钟

睡前 5 分钟：
  - Prone Y + T  10×2 each
  - 大臂卡肩窝静态保持  30s × 4
```

**14 天总投入**：约 2-3 小时。不上场。

### 1.5 升级到 Phase 2 的 criteria（不是时间）

全部满足才进 Phase 2。任一不满足 → Phase 1 延长 1 周。

- [ ] 前锯肌能被意识激活（"想一下就能感觉到"）
- [ ] 肩胛骨能在沉/浮之间 1 秒切换
- [ ] 大臂卡肩窝静态保持 ≥ 60 秒，三角肌前束可被外力按动
- [ ] Wall slide 能完整做完 8 次而前臂不离墙

## Phase 2（Week 3-4）：场上空挥 + 慢喂球

**目标**：把 Phase 1 激活的肌群接到挥拍动作上。建立"空挥-喂球"的桥梁——这正是用户最大的痛点。

**核心策略**：**镜子 → 空挥 → 慢喂球**三档切换。每次训练**只能用一档**，不要混。

### 2.1 镜子前空挥协议（每次训练前 5 分钟）

镜子放在身体右侧（右手持拍者）。可以看到肩、大臂、肘的相对位置。

**Drill：双手扶拍 Unit Turn + 肩胛骨自检**

```
1. 预备站姿，双手扶拍（Bourne 抱球意象）
2. 慢动作做 unit turn 到 45°——3 秒走完
3. 在 45° 位置冻结 5 秒，做以下自检（出声念）：
   □ 大臂是不是"卡进"肩窝？（看镜子：大臂内侧贴胸）
   □ 肩胛骨有没有沉？（不应该耸起来）
   □ 三角肌前束软不软？（用左手摸右大臂前侧确认）
   □ 左手扶拍位置对不对？（拍头还在身体前方，没甩到背后）
4. 任一项失败 → 这次作废，重做
5. 通过 8/10 次才进下一项
```

**做对的体感**：肩胛骨像被"按"在背上的两块石板，大臂像挂在肩窝里的肉。

**做错的失败模式**：
- 大臂离开胸 = 三角肌抬起来了 = State 2
- 耸肩 = 上斜方代偿 = State 2
- 拍头甩到背后 = 手臂独立 = State 2

### 2.2 "腋下夹纸巾不掉" drill（lock 不 clamp）

> 注意：是**锁住**不是**夹紧**。腋下应有篮球间距 + 张力连接。这条体感来自 feedback_armpit_lock_not_clamp 内化项。

```
1. 把一张纸巾轻夹在右腋下（不是用力夹，是用悬挂的肌肉张力托住）
2. 做完整空挥（unit turn → 引拍 → 前挥 → 随挥）
3. 验收：纸巾不能在击球前掉下来
4. 失败模式：
   - 纸巾在 unit turn 阶段掉 = 大臂没卡肩窝
   - 纸巾在击球瞬间掉 = 三角肌抢跑把大臂抬起来了
   - 纸巾全程死死夹住但击球后才掉 = clamp 而不是 lock，过紧
5. 目标：30 球里 25 球纸巾保持到击球后
```

### 2.3 极慢喂球协议（Week 3-4 主菜）

**为什么要慢**：用户已经发现"空挥能做实战做不到"——根因是注意力被来球抢走。慢喂球（5-7 秒一球）让注意力**有余力分一半给身体**。

**喂球节奏**：5-7 秒一球。喂球者每球前数"3-2-1"，让用户有完整 reset 时间。

**每球流程（每球必走）**：

```
喂球者数 "3"：
  → 用户做 Bounce Reset（双脚原地小跳一次）
  → 双手扶拍回到抱球位
喂球者数 "2"：
  → 用户做 unit turn 到 45°
  → 出声念："肩窝"（确认大臂卡进去了）
喂球者数 "1"：
  → 用户继续 coil 到 65-90°
  → 出声念："胸"（确认胸推肘的入口张力）
喂球者抛球：
  → 击球
  → 击球后立刻自检："肘有没有过身体？三角肌前束有没有抢跑？"
```

**剂量**：每组 10 球，做 3 组。每组之间休息 2 分钟，回顾上一组的失败模式。

**验收标准（Week 3 末）**：
- 30 球里 ≥ 18 球（60%）能完整执行 "肩窝 → 胸" 双口令
- "肘过身体"的成功率 ≥ 70%（侧面录像验证）

**Week 4 末升级标准**：
- "肩窝 → 胸" 双口令成功率 ≥ 80%
- 喂球节奏可以加速到 4 秒一球，仍保持 75%+

### 2.4 镜子 vs 球 drill 对比（Week 4 必做）

每次训练结尾做这个对比，量化"空挥 vs 喂球"的差距。

```
1. 镜子前空挥 10 次，自检通过率 X%
2. 立刻转向球场，慢喂球 10 次，通过率 Y%
3. 计算差距：X - Y
4. 差距 > 30% = 桥梁没搭上，下次训练继续 Phase 2
5. 差距 < 15% = 桥梁建立，可以考虑进 Phase 3
```

### 2.5 升级到 Phase 3 的 criteria

- [ ] 慢喂球（5 秒/球）成功率 ≥ 80%
- [ ] 中速喂球（4 秒/球）成功率 ≥ 70%
- [ ] 镜子 vs 球差距 < 15%
- [ ] 腋下纸巾 drill 能稳定做到 25/30
- [ ] 击球后自检"肘过身体" ≥ 75%

任一不满足 → Phase 2 延长 1 周。

## Phase 3（Week 5-6）：实战压力下保持 State 1

**目标**：把 State 1 从"喂球能做"推进到"对拉能做"和"得分球能做"。

**核心认知**：实战变形是**正常的**。Phase 3 不追求 100% 成功率，追求**变形后能 reset 回 State 1**。这就是 pre-point routine 的作用。

### 3.1 Pre-Point Routine（每球前必走）

这是 Phase 3 的核心工具。把已有 cue 编成一套 4 秒固定流程，让身体在每球前都被强制 reset 到 State 1。

```
Step 1（1 秒）：Bounce Reset
  - 双脚原地小跳一次
  - 目的：清空上一球的肌肉张力残留

Step 2（1 秒）：双手抱球
  - 双手扶拍到 Bourne 抱球位
  - 目的：强制大臂回到肩窝（抱球意象的几何必然）

Step 3（1 秒）：胸前感受
  - 闭嘴呼气，主动感受胸前外侧肌群的张力（前锯肌 + 胸大肌）
  - 目的：激活胸推肘的入口

Step 4（1 秒）：大臂锁感
  - 心里念"肩窝"
  - 目的：最后一道大臂位置确认
```

**剂量**：每球前必走，**包括对拉、训练赛、正式比赛**。
不走 routine 就直接打 = 默认 State 2。

**Week 5 任务**：在所有击球场景植入这套 routine，宁可慢、宁可被对手 rush，也要走完。

### 3.2 对拉训练协议（Week 5）

```
- 配合一个能控制速度的对手或教练
- 第 1 阶段：低速对拉（球速降到平时 60%），重点是 routine + State 1
- 每打 5 球，自评 1 次："这 5 球里有几球走了完整 routine？"
- 不走 routine 的球 = 作废 = 不计数
- 目标：连续 20 球，routine 执行率 ≥ 90%
```

**变形 reset 协议**：
- 当出现一球明显 State 2（自己能感觉到大臂飘了）→ **暂停 5 秒**
- 做 1 次墙面 push-up plus（重新激活前锯肌）
- 走完整 routine 再继续
- **不要硬撑**，硬撑会让 State 2 模式被强化

### 3.3 模拟得分球（Week 6）

```
- 设计一个低压场景：5 球一组，第 5 球是"决胜球"
- 前 4 球正常对拉，第 5 球宣布"这是赛点"，然后击球
- 验收：第 5 球能不能保持 State 1？
- 评分（每组 1 分）：
  - 走完 routine + State 1 = 1 分
  - 走 routine 但 State 2 = 0.5 分
  - 没走 routine = 0 分
- 10 组 = 满分 10 分
- Week 6 末目标：≥ 7 分
```

### 3.4 Week 6 末验收（最终标准）

**硬指标 1：实战 8/8 检验**
- 找一个实战场景（训练赛或对拉中），录像
- 连续录 8 个正手击球
- 视频指标：
  - [ ] 8 球里 ≥ 6 球大臂内侧贴胸（侧面视角）
  - [ ] 8 球里 ≥ 6 球击球瞬间肘已过身体（肘部位置在身体前方）
  - [ ] 8 球里没有任何一球出现明显耸肩
- 全部通过 = State 1 已固化

**硬指标 2：体感反馈**
- 击球后回忆每球，能说出"这球是 State 1 还是 State 2"
- 准确率 ≥ 80%（可以通过录像验证）

## 警告与边界

### 这些事会让你倒退到 State 2

| 触发事件 | 为什么会倒退 | 应对 |
|---------|-------------|------|
| **跳过 Phase 1 直接上场** | 前锯肌没激活，"胸推"会变"三角肌前推" | 严格按顺序，不跳 |
| **训练时同时改 2 个变量** | 注意力分散，旧默认值接管 | 一周只练 1 件事 |
| **打到累了继续硬撑** | 疲劳时大脑选最熟悉路径 = State 2 | 累了就停，宁少勿错 |
| **跟比自己强 30% 的对手对拉** | 球速逼迫你"省思考"= 走老路 | Phase 3 前不打高强度 |
| **比赛压力下追求结果** | 注意力 100% 给目标 = 0% 给身体 | Phase 3 末再考虑比赛 |
| **连续 3 天没做 Phase 1 套件** | 神经通路退化（需要每日刺激维持） | Phase 1 套件做满 6 周不停 |

### 什么情况应该退回上一阶段

| 当前阶段 | 退回信号 | 退回到 |
|---------|---------|-------|
| Phase 2 | 慢喂球成功率连续 2 次训练 < 50% | Phase 1 + 重新激活前锯肌 |
| Phase 3 | 对拉中 routine 执行率 < 60% | Phase 2 + 加强镜子 vs 球对比 |
| Phase 3 | 出现腋下/肘部酸痛 | 立刻停训，检查是否 clamp（夹紧）而非 lock（锁住） |
| 任何阶段 | 击球后大臂前侧（三角肌）酸 | Phase 1 + 三角肌静默 drill 加倍 |

### 时间线的真实预期

- **乐观情况**：6 周完成 3 个 Phase。
- **正常情况**：8-10 周完成。Phase 1 通常需要 3 周（不是 2 周），因为前锯肌激活对没有专项训练背景的人需要更久。
- **悲观情况**：12 周。如果 Phase 3 反复退回 Phase 2，说明 Phase 1 的肌肉激活没扎实——回去补，不要在 Phase 3 硬磕。

**criteria 是硬约束，时间是参考**。永远先满足 criteria。
