# facts_v2 — 中立事实抽取（看「球员」的视频：用户视频 + 盲测片段）

> 模型固定：`gemini-3.8-flash`，本地 mp4 **去掉音轨**（`ffmpeg -an`）后 inline 发送；同一片段跑 **3 次**，选项顺序每次随机打乱。
> `{QUESTIONS}` 由执行者从 `tree.json` 的 `observables` 渲染：每个观测项一题，选项 = 该项 `values` + `unclear`，顺序随机。
> **渲染后**的完整提示词必须先通过 `check_neutrality.py`（文件名以 `facts_` 开头），再发送；渲染稿存进 `raw/` 以便复现。
> 输出由执行者整理成 `schema/facts.schema.json`（`agree` = 3 次中给出多数答案的次数；`strokes` = 多少拍表现出该答案）。
