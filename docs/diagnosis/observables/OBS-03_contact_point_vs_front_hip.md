# OBS-03 触球点相对前髋的前后位置

- **定义**：触球帧，球（或拍弦中心）相对前髋的前后位置：「在前髋之前 / 在身体侧面（与髋齐平）/ 在身后 / 看不清」；有 Pose 时记前后距离（按肩宽归一化）。
- **看哪一帧**：触球帧。
- **哪个机位**：S 必须（前后距离在画面平面内）；R/B 看不准深度（R8、R9 模型自己标「中」把握）。
- **谁来测**：B 层：Pose + 人工抽帧；模型只作参考。
- **可靠度**：**不稳定**。直接问到（R6–R9）：「前髋之前」3/4，R7 说「身体侧面」；R10 说「不够靠前、很近」；R3 明确说判断不了。

挂接故障：在身体侧面或身后 → 支持 FLT-07；在前方但偏近 → 结合 OBS-02 看 FLT-01。原书依据：p.24–25、p.116。
