# OBS-13 触球时重心落脚 + 触球后重心/躯干方向

- **定义**：(a) 触球帧重心主要在前脚 / 后脚 / 两脚之间；(b) 触球后 0.5 秒内身体继续朝球网方向 / 向后或向上 / 看不清。
- **看哪一帧**：触球帧 + 触球后约 0.5 秒。
- **哪个机位**：S 最准；R/B 只能粗看。
- **谁来测**：B 层：Pose（髋中心相对双脚的前后位置）+ 人工抽帧；模型只作参考。
- **可靠度**：**不稳定**。(b)：「向后/向上」3 份（R3、R4、R10），「继续向前」1 份（R5）。(a)：「后脚」2 份（R6、R7），「前脚」2 份（R8、R9），「两腿之间」1 份（R2）。(b) 里同为 argon 的 R3/R10 与 R5 相反；R8/R9 答的是 (a)，不能和 (b) 直接对比。R2 的「两腿之间」是整体描述，不是触球帧，从宽计入。

挂接故障：FLT-10（推断）、FLT-05。
