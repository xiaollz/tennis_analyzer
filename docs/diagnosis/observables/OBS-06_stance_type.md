# OBS-06 站位类型

- **定义**：触球前双脚相对出球方向的关系：「开放 / 半开放 / 中性 / 封闭 / 看不清」。
- **看哪一帧**：前挥启动帧（双脚定位后）。
- **哪个机位**：B 最清楚；S 次之。
- **谁来测**：A 层模型；人工抽帧复核。
- **可靠度**：**大类不稳定**：R8、R9「半开放」；R7「半开放/中性」；R3「半开放/中性」；R2、R10「开放/半开放」；R6「封闭/中性」。7 份里 6 份含「半开放」，但具体类别不一致。

挂接故障：站位本身是风格（书 p.77–78）；只有「封闭」需要留意，作为 FLT-05 的线索（书 p.78–79）。
