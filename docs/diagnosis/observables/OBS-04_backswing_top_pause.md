# OBS-04 引拍顶点停顿（有无 + 时长）

- **定义**：引拍到最高点后，拍子是否静止超过约 0.3 秒再启动前挥；有则记静止时长（秒）。
- **看哪一帧**：时间序列：引拍最高点 → 前挥启动（手腕速度重新上升）之间的帧段。
- **哪个机位**：任何机位都能看有无；时长需 ≥60 fps 和手腕速度曲线。
- **谁来测**：「有/无」A 层模型；时长由 Pose 手腕速度时间序列（B 层）。
- **可靠度**：「有停顿」：直接问到的 R4、R5 **2/2 份、10/10 拍一致**；R3 未被问也主动提到（约 0.5 秒），但同一份输出另一处又说「一气呵成，没有中途停顿」，自相矛盾，不计入。R2、R10 没提到。时长：R4 说 0.3 秒到约 1 秒，R3 说约 0.5 秒 → **时长未测准**。

挂接故障：FLT-03（待定卡）。注意原书 p.75：准备后的等待是正常的最后一步，慢球等待可以很长，所以**有停顿本身不支持任何故障**，只有与 OBS-03 偏晚同时出现时才作线索。
