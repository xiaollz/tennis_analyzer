# OBS-01 触球时肘角

- **定义**：触球帧右肘是「明显弯曲（约 90–120°）/ 接近伸直 / 看不清」。
- **看哪一帧**：触球帧（音频峰值或拍球接触帧），前后各 1 帧确认。
- **哪个机位**：S 最准（肘角在画面平面内）；R/B 能粗分「明显弯 vs 接近直」，具体角度不准。
- **谁来测**：A 层模型可答粗分类；角度值由 Pose + 人工抽帧（B 层）。
- **可靠度**：粗分类「明显弯曲」**7/8 份一致**（R2、R4–R9 明确；R10 只描述「肘掉在腰腹侧」未直接答，按 00_runs 规则不计入分母；R3 说「接近直臂或微曲臂」，但描述的是整体挥拍结构、不是触球帧，算作相反答案是从严处理）。直接问到的 R4–R9：6/6 份、30/30 拍一致。角度值：未测。

挂接故障：单独出现**不定罪**（风格项，书 p.66、p.69–70，见 00 P6）。只有与 OBS-02/03 同时异常时，才作为 FLT-01 的辅证。
