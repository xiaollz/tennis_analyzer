# OBS-11 前挥启动到触球之间，手的路径

- **定义**：持拍手从前挥启动到触球的路径：「大致水平向前 / 先向下再向前上方 / 先向上抬 / 看不清」。
- **看哪一帧**：前挥启动帧 → 触球帧的时间序列。
- **哪个机位**：S 最准（高低和前后都在画面平面内）；R 机位会把前后和左右混在一起。
- **谁来测**：B 层：Pose 手腕轨迹；模型只作参考。
- **可靠度**：**按模型分裂**：3.8-flash 两次都答「水平向前」（R6、R7）；argon 两次都答「先下再前上」（R8、R9）；R10 说「很陡地由下往上」。同模型内一致，跨模型相反 → 不可靠。

挂接故障：FLT-08（拍路）、FLT-09（推断：小臂上提）、FLT-10。
