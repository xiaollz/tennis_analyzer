# OBS-15 随挥：终点位置 + 触球后有没有向前延伸

- **定义**：(a) 收拍终点「过左肩 / 左肩以下 / 停在身前 / 看不清」；(b) 触球后手有没有一段朝目标方向的延伸，还是马上绕回身体；(c) 随挥结束时持拍肘是否在胸前。
- **看哪一帧**：触球帧 → 随挥结束帧。
- **哪个机位**：B 看 (b)(c) 最好；S 看 (a)(b)。
- **谁来测**：A 层模型粗答；人工抽帧复核。
- **可靠度**：(a)「过左肩」**3/3 份整体分析一致**（R2、R3、R10）。(b) 只有 R2 说「几乎没有向前推送、马上绕回」，单份 → 未测准。(c)：未测。

挂接故障：随挥只是诊断工具（书 p.107）。(b) 马上绕回 → FLT-08 的强行随挥线索（书 p.107）；(c) 肘在胸前结束 = 旋转成功转成平移的标志（书 p.109）。终点高低本身是风格（书 p.93：Thiem 终点在非持拍肩以下）。
