# OBS-12 触球时前臂朝向与拍杆角度

- **定义**：触球帧前臂相对水平面「大致水平（<20°）/ 斜朝上 / 斜朝下 / 看不清」；拍杆「接近水平 / 倾斜 / 接近竖直」。
- **看哪一帧**：触球帧。
- **哪个机位**：S 必须；R 机位下角度受透视影响。
- **谁来测**：B 层：Pose（肘—腕连线角度）+ 人工抽帧。
- **可靠度**：前臂「大致水平」**4/5 份**（R6–R9 问卷）；R10 整体分析说「斜朝上」——而 R10 的问题里本身写了「小臂朝上」，问法影响明显。拍杆：「接近水平」3/5（R7 说偏竖直 60–75°；R10 说「略微偏斜向上」；R8 有 1 拍说倾斜 20–30°）。

挂接故障：只作线索，挂 FLT-09（推断部分）。原书没有把前臂朝向本身当作标准；书 p.44 注释只说前臂—拍子夹角在触球区会被动张开约 10–30°。
