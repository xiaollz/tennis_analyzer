# OBS-05 分步 / 调整步

- **定义**：每拍从发球机出球到触球之间，是否有分步（split step）和调整碎步：「有 / 很少 / 没有 / 看不清」。
- **看哪一帧**：出球 → 触球的整个帧段，看双脚。
- **哪个机位**：S 或 B 均可，需双脚完整入画。
- **谁来测**：A 层模型。
- **可靠度**：「几乎没有分步、站在原地」**3/3 份整体分析一致**（R2、R3、R10）；问卷类输出没问这一项。R1 说看不清脚。

挂接故障：FLT-01 的上游候选（站位/步法，单源：q6LrQYDvxmY【未核对】）。原书只说训练中要先有「身体相对球的位置」目标再移动（p.134），不讨论分步本身。
