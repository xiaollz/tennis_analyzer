# OBS-02 触球时手/肘与躯干的横向间距

- **定义**：触球帧，持拍手（腕关节）到躯干侧面的水平距离；粗分类「上臂贴肋 / 有明显空隙 / 看不清」。
- **看哪一帧**：触球帧。
- **哪个机位**：B 最准（距离在画面平面内）；R 机位深度被压缩，看不准；S 机位看不到横向距离。
- **谁来测**：B 层：Pose（腕—髋水平距离，按肩宽归一化）+ 人工抽帧。模型只作参考。
- **可靠度**：**不一致**。说法「贴近」5 份（R2、R4、R7、R8、R10；其中 R7、R8 只在第 1 拍明确说）；「有空隙」1 份（R5）。R3 的「没有把胳膊夹死在肋骨旁边」说的是引拍、不是触球，不计入。同为 argon，R5 说有空隙、R8/R10 说贴近。直接问到的 R4/R5：1:1 相反。R 机位下判为不可靠。

挂接故障：支持 FLT-01（偏近）；也是 FLT-02、FLT-10 的下游线索。
