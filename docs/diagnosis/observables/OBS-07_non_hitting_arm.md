# OBS-07 非持拍手：转身时是否横过身体、何时离开球拍、何时落下

- **定义**：三个子项：(a) Unit Turn 完成时非持拍手是否伸过身体前方；(b) 非持拍手在转身完成前还是之后离开球拍；(c) 前挥开始时它是否已经垂到身侧（「已落下 / 随胸一起回转 / 看不清」）。
- **看哪一帧**：(a)(b) Unit Turn 完成帧；(c) 前挥启动帧到触球帧。
- **哪个机位**：B 最清楚；S 能看 (c)。
- **谁来测**：A 层模型粗答；人工抽帧复核。
- **可靠度**：(c)「触球前已落下」**弱，1/2 份中立整体分析**：R2 说「引拍刚到位就迅速垂在胸腹前」；R3 说伸展后「在挥拍过程中收拢到左胸前」。R1 也说早落，但受污染不计。(a)(b)：未测（没有输出被直接问到；R3 顺带说「左手扶着拍喉，配合转肩」「引拍到位后…左手松开拍喉」，只作参考）。

挂接故障：FLT-04（书 p.62：转身完成前双手都在拍上、非持拍手横过身体）；(c) 关联「上半身整体回转」（书 p.91、p.111）。
