# OBS-08 Unit Turn 幅度（肩线、髋线转离目标的角度）

- **定义**：Unit Turn 完成时，肩线和髋线相对底线转离目标的角度（度）；粗分类「明显侧身 / 少量 / 几乎正对 / 看不清」。
- **看哪一帧**：Unit Turn 完成帧（手开始降到球下之前）。
- **哪个机位**：B（略高于头）最准；S 可粗看胸是否转向侧面。
- **谁来测**：B 层：Pose 2D 肩/髋连线只能粗估；人工抽帧。
- **可靠度**：**未测**（没有输出被直接问到）。R2 顺带说「躯干有转但幅度有限，骨盆旋转角度较小」，只作参考。

挂接故障：FLT-04；同时用来判断 FLT-05 时有没有「转离」可以转回。
