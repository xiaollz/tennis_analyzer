# OBS-10 后脚：触球时脚跟是否离地、触球后是否随挥绕到身前或踢到身后

- **定义**：右脚（后脚）在触球帧是否脚跟离地；触球后 0.5 秒内是否绕到身前 / 踢到身后 / 原地不动 / 看不清。
- **看哪一帧**：触球帧 + 触球后约 0.5 秒。
- **哪个机位**：B 或 S，双脚需完整入画。
- **谁来测**：A 层模型；人工抽帧复核。
- **可靠度**：**不一致**。R8、R9：右脚跟提起、重心到左脚；R6、R7：重心仍留在右脚；R5：右脚跟抬起、右脚向前迈步；R10：右脚跟轻轻踮起；R2：右脚极少向前跟进；R3：反而左脚向后撤。

挂接故障：FLT-05（书 p.79：后脚随挥是判断髋转是否到位的指标；p.84：双脚钉地无法完整转髋）。
