# OBS-18 前挥启动顺序（髋 / 躯干 / 手臂谁先动）

- **定义**：前挥启动时谁先开始朝目标方向动：「髋先、躯干和手臂随后 / 几乎同时 / 手臂先动 / 看不清」。
- **看哪一帧**：引拍最深帧 → 触球前约 0.2 秒的时间序列。
- **哪个机位**：B（看髋、肩连线转动）；需 ≥60 fps，最好 120 fps。
- **谁来测**：B 层：Pose 髋线、肩线角速度和手腕速度的峰值先后（2D 只能粗估）；模型只作参考。
- **可靠度**：**按模型分裂**：3.8-flash 两次都答「手臂先动」（R6、R7）；argon 两次都答「几乎同时」（R8、R9）。不可靠。

挂接故障：FLT-02、FLT-05。原书提醒：先后时序不能拿来当场上口令（p.90，00 P7），这一项只供诊断。
