# OBS-17 引拍最深时拍头指向

- **定义**：引拍到最深（前挥启动前）时拍头指向：「正后方（背后围网）/ 斜后方 / 正右侧 / 朝上 / 看不清」。
- **看哪一帧**：引拍最深帧。
- **哪个机位**：B（略高于头）最准；R 机位前后深度被压缩。
- **谁来测**：B 层：人工抽帧；模型只作参考。
- **可靠度**：**不稳定**：4 次直接问（R6–R9）得到 3 种答案——A 正后方（R6）、B 斜后方（R7、R8）、C 正右侧（R9）；R10 说引拍最深时「拍头是高高竖起朝向天空的」（D 朝上；它说的「后方偏下」是下落到最低点时，不是本帧）。5 份 4 种答案，同模型两次也不同。

挂接故障：只作线索。拍头/拍底指向属于被动位置（书 p.64–65：拍底指网是 dynamic position，不应主动进入），**不能直接变成处方**（00 P5）。
