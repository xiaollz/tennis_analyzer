### 教练明确给出的因果链

1. **后背稳定收紧 → 骨骼关节获承托反弹 → 高速甩臂并不失力、不受伤**
   - 01:44 - 02:04、02:40 - 02:55：后摆变向处背阔肌收紧并把肩胛骨下沉锁紧（Pack） → 支撑住肱骨与肩关节，形成坚实的反弹基底（防止前侧脆弱软组织被过度后扯牵拉） → 变向动能被安全转化为前冲动能，手臂快速爆发向前射出，既避免力量流失又防止受伤。

2. **引球过高且未等待下落 → 击球脱离胸肌水平杠杆范围（肩关节孤立代偿） → 无法高效发力抽球**
   - 04:30 - 04:55：来球过高且击球前未多等待半秒下落 → 击球高度过高，无法使用胸肌完成水平转体抽击（只能变成单靠肩膀受力挥击） → 难以驱动球并失去力量杠杆（"hard to drive the ball"）。

3. **水平半圆轨迹全力挥击 + 暂未施加控球上旋 → 击球深且快但出界（属于达标练习）**
   - 03:25 - 03:45：专注于胸肌带动与水平半圆加速释放最高拍速 → 暂未加入由低到高的上旋调整机制 → 击球高速飞出底线落入绿区（Miss long and fast，符合当前解除力量限制的训练目标）。
