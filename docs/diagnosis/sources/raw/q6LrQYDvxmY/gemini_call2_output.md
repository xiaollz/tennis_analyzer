### 教练明确指出的因果链

1. **01:35 - 02:18**：引拍时不推开非持拍手（左手垂挂在身侧） → 破坏定距感知并丢失左侧躯干稳定杠杆 → 击球容易被挤压、球速下降且躯干转动发力脱节。
2. **02:19 - 02:35**：非持拍手推展开并维持平衡 → 锁定身体右侧击球窗口并协助核心激活 → 整个躯干作为一个完整单元加速带动手臂穿透击球。
3. **05:47 - 06:06**：击球侧向定距过近（留于双脚后跟之间） → 击球时右腿无法向前发力驱动，只能通过脚后跟向左后方蹬转 → 击球挥拍失去稳定支撑向左侧倾倒。
4. **06:12 - 06:57**：建立足够远的右侧定距 → 躯干旋转时为手臂向前延展留出物理通道 → 右肘能够顺着面朝方向向前直线推进（Pressing Vector），避免内折横拽手肘。
5. **10:25 - 10:40**：面对低球时转动平面过于水平且强行在球下起拍 → 挥拍路径无法提供平缓对角斜面 → 击球容错裕量（margin）极低，极易下网或失误。
6. **12:47 - 12:58**：高球击球时若错误地将球拍降到球下方过深的位置起拍向上刷 → 拍面与挥拍向上矢量叠加过多 → 打成无法控场的高吊球（lob）或直接出界。
7. **14:05 - 14:21**：击球深度定距不足（球过分靠近身体躯干） → 转体时缺乏手臂前向释放的纵深空间 → 手臂蜷缩成“鸡翅膀”状或卡在躯干侧后方。
8. **15:00 - 15:21**：计划身体前倾迎击，但仅按照静止不动的击球点来定距 → 身体向前倾入击球空间 → 躯干前移吃掉手臂击球纵深，导致击球点再次被挤压。
9. **16:41 - 17:02**：过度强调击球点在身前而过度向前够球 → 身体重心脱节形成“屁股后坐、球拍前伸”的失衡姿态 → 失去自然的躯干转体挥拍动力。
