### 教练明确给出的因果链

1. **00:39 - 00:47**
   引拍时髋部/骨盆跟随上半身一起向后转动 → 上下半身之间无法形成相对转角扭力（无张力） → 挥拍击球时无扭矩弹性势能可释放（击球软绵无力）。
   *(髋部同向后转 → 躯干无扭转张力 → 击球缺乏爆发力与弹性)*

2. **02:30 - 02:42**
   骨盆与肩膀同步向后转、同步向前转（无对向反扭制动） → 挥拍失去核心肌群旋转力量 → 被迫大幅向上捞拍来补偿球速与过网。
   *(躯干与骨盆同步同向转动 → 核心发力不足 → 被迫向上捞球以进行代偿)*

3. **02:51 - 03:26**
   骨盆向前锚定/反扭 + 上半身充分转体蓄力 → 核心释放出巨大的旋转力量 → 若继续采用原本向上捞球的挥拍轨迹 → 击球严重飞出底线（必须压低挥拍轨迹转为向前下方打）。
   *(对向反扭蓄力爆发大能量 + 沿用向上捞拍轨迹 → 回球深远出界)*

4. **04:38 - 05:05**
   单脚悬空站立击球 + 沿用错误的同向转体习惯 → 旋转时身体完全丧失平衡支撑点 → 身体东倒西歪、被迫落地（迫使中枢神经纠正动作，自发寻找对向平衡）。
   *(单脚站立挥拍 + 躯干同向旋转 → 身体失衡摔倒/落脚 → 迫使身体激活对向反扭平衡机制)*
