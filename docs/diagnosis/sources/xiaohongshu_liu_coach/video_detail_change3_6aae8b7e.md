## B. 学员现象 / 症状

- 白背心、浅蓝裙、白帽，室内场（地面有 Rabbit venue）。开场横扫式挥拍，拍收到身前，球贴在拍面上。
- 教练指出：拍在这个位置会自己把拍头掉下去，拍被拉到后边，挥出去像杀球。0:12 画面是人站直，拍横在腰腹前，拍头指向侧后方。
- 左手已经在指，右手却不回到左手指的地方。绿字点明错法：「指的地方和打的地方都不一样」。她左手指上面，拍却打到上面。
- 球还没落地，手和上身已经动。

## C. 动力链成因

1. 右手在这段里被说成「打球里边的一个傀儡」，「他只是负责挥拍」。找位是左手的事。拍面要去左手指定的地方，不能自己跑过去找球。口播补了一句：不是用右手去找球。
2. 拍头自己掉下去、拍被拉到后边，是他要停掉的现象。字幕原词是「降拍头」「不降拍头」。只记原话，**不写成我方口令**。
3. 错的时候，指的高度和打的高度不是一处。他问「你左手是指上面吗」「你为什么把球拍放到上面去打球」。
4. 上身要等球落地才动。球落到左手指的方向，这个时候才瞄准去打。球不落地就不要动。

作者在评论里把「拉拍」改口成「侧身引拍」，越早越好。那是评论文，片中口播没有展开这一句。

## D. 改进 / 口令 / 练习

- 左手找位、左手指定方向；拍面跟过去。反复问「球拍的拍面去哪里」，然后自己答「去你左手指定的地方去」。
- 右手不要乱动，只负责挥。球不落地，手不要乱动。
- 眼和上身先别动。字幕「眼动上身别乱动」；口播是「眼睛、上身别乱动」。落地之后才动上身，再瞄准。
- 片尾口令串：别动 → 落地了 → 左手的方向 → 这个时候才会瞄准去打球。球不落地你不要动。
- 「降拍头 / 不降拍头 / 拉到后边 / 杀拍」只留教练字幕和口播，**禁止写成降拍、推肘或伸肘**。评论里的「侧身引拍」也只记原话。
