- 全程远景。女孩在底线右侧一带打正手多球，不是手把手改动作。
- 顶上绿字两行从头到尾几乎都在（抽到的 0:00–2:54 都在；约 2:56 她走回场中时，这两行不再明显）：「这组训练目的是蹲腿」「高球也需要提前蹲腿打」。

## C. 动力链成因

1. 文案：这组是 bani 教练给小朋友的，目的就是蹲腿。蹲腿被他接上力量、速度、0 失误。0 失误是结果句，片中没有解释为什么不会失误。

3. 粉字「蹲」打在若干击球瞬间，不是打在准备站好的空档。能核对的是：字和挥拍叠在同一帧。不把这个字再解释成某一块肌肉。
4. 约 2:14 粉字：「只要蹲腿0失误」。和标题、文案同一句结果。没有第二句条件。
5. 约 2:38 两行：「蹲腿在继续中」「偶尔一个失误不可怕」。这句把文案的 0 失误松了一档：继续蹲的过程里，偶尔一次失误不算问题。两句都保留，不合成「所以其实允许失误」。
