## B. 学员现象 / 症状

- 同一室内侧墙、绿场地。学员马尾、海军蓝连衣裙、黄拍，自己喂自己打，旁边散着球。没有教练入画。
- 准备时双手扶拍，拍在身前，人站在边线里侧，重心在两脚之间。
- 挥的时候拍会绕到头侧、甚至举过头顶，拍头在脑后上方。这是大字说的「绕头」。
- 打完有一帧右臂甩到身体侧后方，左手摊开在身前，球还在脚边。击球点如果停在那儿，就是晚了。
- 她打着打着会笑。大字把这个笑当成松弛，不是慵懒。

## C. 动力链成因

1. 开场大字把顺序说死：永远的击球点都在前方，拍头速度自然起来。速度是结果，点在前是条件。文案同一句：抢时间把击球点放在身体前面。
2. 松弛和慵懒被写成「一线之差」。底字：「打到笑应该是松弛了」。笑是松的证据，不是收着劲不去找点。
3. 绕头被降级。大字：「绕头说不需要学。目的就是赶击球点。」另一条：「super好的意识。绕头也要把击球点推前。」绕头可以发生，但不准把点留在身后。这里的「推前」是把击球点放到身前，**不是推肘**。
4. 画面里的绕头就是拍从身前收到头侧再打出去。大字不要求把这个圈练成固定动作。
5. 片中没有说到髋、肘、拍面朝下。不把「拍头速度」改写成任何加力口令。

## D. 改进 / 口令 / 练习

- 先抢击球点，点在身体前面。拍头速度让它自己起来。
- 要松，不要懒。打到自己会笑，算松弛。
- 绕头不用单独学。真绕了，也要把点赶到前面。
- 文案说这个点能抬 0.5。片中没有给次数、组数。
- 大字「绕头」按字形记。有一版画面描述写成「饶头」，不采用。
