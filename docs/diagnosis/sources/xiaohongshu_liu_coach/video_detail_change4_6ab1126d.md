## A. 元信息 / 标题文案

- 标题：网球🎾每个细节点改变都会让你涨球(四)
- 文案原样：一个练习满足3个要点。a降拍头。b转髋打球。c非持拍手找球。每天100次，一周保证涨球。
- 文案和片中不是一回事。抽帧字幕和口播里**没有**出现「降拍头」「转髋」这几个字。片中在做的是：左手找球、两手先合再分开一点点、右手跟同一方向、打开只有这么多、不要力气、两手抓圈。文案三点只记文案，**不把 a/b 写成片中口令，更不写成降拍或送髋**。

## B. 学员现象 / 症状

- 同一学员（白背心、浅蓝裙、白帽），室内。开场还在打上一支的节奏：人在动，球在脚边。
- 两只手贴在一起找球、击球，教练说这个阶段两手是「貌合神离」：看着在一起，其实要分开。
- 分开如果太大，他立刻喊停，只要「分很少 / 只打开这么多」。
- 她会使劲把球打出去。教练要的是找到球、碰一下，不要力气。

## C. 动力链成因

1. 先重申（三）：球落地才奔到左手的方向，这时才瞄准。球不落地不要动。作者评论把这句收成：上身不要乱晃，稳住核心。【评论原话，不是送髋】
2. 这一段练习里，左手找球的位置和右手击球的位置要「合二为一」。顶字写「这个练习非常有用」。
3. 合在一起之后，马上改成只分开一点点。形容词是他自己说的：「貌合神离」。分开的方向，他比成「垂直于我的肩」：拍在右手里竖着，左手掌打开在肩侧。
4. 球过来的时候，右手永远跟左手同一个方向一起打。字幕写「发球过来的时候」，口播更像「球过来」。教练握着她的拍柄把方向送出去。这里的「跟」是两手方向，**不是推肘**。
5. 打开的量被卡死：就这么多，再大他就喊。口播 2:02 有一截听成「这样一点拍头」，烧录字幕写的是「打开这么多 / 就打开一点点」。画面是拍头抬起来、两手仍只分开一点，不是把拍头降向地面。
6. 片尾用一只黄圈：两只手抓着圈。口播还有「在圈圈外边」「把他转过来」。这个「转」是把圈/手转过来，**片中没有说转髋**。

## D. 改进 / 口令 / 练习

- 不用使劲。口播：「不用把球打过来」「你只是找到球」「把球碰一下都可以」。字幕：「再来不用使劲」「你只是找到球」。
- 左手找，右手一起。先合二为一，再「分开一点点 / 分很少 / 仅仅分开」。
- 球过来，右手跟同一方向一起打。打开只到他比的那个宽度。不要力气，打准。
- 每天怎么练，只在文案里：100 次、一周。片中没有数到 100。
- 「海拉」「塞塞卡」是口播里的喊声，像称呼或垫词，不当技术口令。2:24 底字有一帧被读成「顾夕再来一个」，口播只是「再来一个」，「顾夕」不采用。
- 文案「a降拍头」「b转髋打球」加【文案原话·片中未听到·非我方口令】。
