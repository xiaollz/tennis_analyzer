## B. 学员现象 / 症状

- 白背心蓝裙学员，开放站位。引拍、移动、挥拍糊在一起：人还在走，拍已经挥出去（屏显「早了」「no」）。
- 击球位没有停。拍一到身前就接着抡，教练说这被误当成「二次拉拍」。
- 距离太近时更明显：一启动上身就动手，没有「走两步到三步拍还留在这儿」。
- 后段数拍时，走步阶段上身已经动了，屏显红叉「上身不动不对」。

## C. 动力链成因

教练把「往后/往下那一下」从「二次拉拍」里拆出来：

1. 需要停的地方是身前的击球位（粉字「就是这里」），不是再往后拉一次。
2. 拍头先到一个高点再往下落，他用山车比喻：爬到顶上蓄一下再下滑。下落和前面是**同一条轨迹**，所以不叫二次拉拍。先说「这个轨迹是不一样的」（若在击球位再往后拉），马上改口「这个轨迹是一样的 / 所以这个不叫二次拉拍」。
3. 人不能「一走起来就已经开始动」。停留可以长到两步、三步；步子在走，拍还停在击球位。职业插入画面字幕 always forward，人在跑，拍仍留在身前。
4. 初学距离太近，才会直接抡出去，没有这段停留。

「往下拉拍 / 往后拉」只记教练原话，**不译成我方口令**（尤其不写成降拍）。

## D. 改进 / 口令 / 练习

- 找到身前击球位再停，不要把停顿理解成第二次向后拉拍。
- 停留时长：两步到三步。口播用「吧吧吧」数拍，强调「三步我还停留在这 / 或者两步我还停留在这」。
- 刻意把这个时间停长一点，停下来再挥。
- 片尾数拍口令（辅助节奏，非 trunk 处方）：**预备 → 撤 → 走 → 挥**。走的时候上身不要先动手。他后来说「我都懒得看你，就听我说就好了」，然后连数三组，反馈 good shot / perfect / this is good。
- 顶栏绿字点题：初学者把引拍、移动、挥拍混为一谈。
