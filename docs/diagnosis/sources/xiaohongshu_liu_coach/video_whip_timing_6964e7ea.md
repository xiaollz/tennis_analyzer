## B. 学员现象 / 症状

- 大字把成因标题写成：「早击球的成因了解一下」。早的是击球。
- 粉字和白字把早出去写成三行：「站稳了」「球拍还在老位置」「不要急于出去击球」。
- 看她打的时候，大字：「留意看 / 突然短路了」。短路是他的结果词，大字没有画断在哪一节。
- 柴犬大字：「完全没见过这样侧身的」。否定的是这一种侧身。
- 片中大字没有「轻轻降下去」「送拍柄」「送拍头」「送肩」「转髋送球拍」「拉胯」「转胯」「等地转髋」「转体」。口播说的是「掉下来」，评论说的是「掉拍头」「转体」，都只引用，不改写。

## C. 动力链成因

大字单列。口播能对上的写在后面，并标听写。

1. 大字：「早击球的成因了解一下」。口播（听写，约 0:07–0:18）：早打球；球拍怼到这里；在这个地方没有忍住，直接就掉下来；一掉下来，自然就会出去。「掉下来」是口播，大字没有这四个字。不改写成降拍。
2. 大字：「timing的重要性这是体现出来了」。口播（听写）：这个动作是连贯的；要让球拍晚一点到达这个地方；这个位置要保持；不能很早放下来。
3. 粉字：「keep住」。口播反复是「忍住」。keep 和忍住对得上。忍住的是他还没让拍离开的那个位置，大字没有再命名那个位置。
4. 「站稳了 / 球拍还在老位置 / 不要急于出去击球」。作者评论把站稳和早出拍拆开：站稳是一个条件，站稳了仍会早出拍，不是同一个意思。评论不并进这三行大字。
5. 口播（听写，约 0:37–1:00）：等球往上走才开始动手；球落地之后往上走，才能够挥拍；全靠这个地方忍住。等的是球往上走，不是大字上的另一句。
6. 「留意看 / 突然短路了」。口播在这之前有「这个球不对」「站稳了再动手，老是急于动手」「脚都没踏稳」（听写，约 2:32–2:49）。短路和大字绑在一起；脚没踏稳只算口播。
7. 「完全没见过这样侧身的」。之后口播在问怎么侧身、左手呢、右手应该在哪里。有一句听不清，不收录。他没有在这几秒给出一个替换的侧身形状，只留下这句否定和这几个问。
