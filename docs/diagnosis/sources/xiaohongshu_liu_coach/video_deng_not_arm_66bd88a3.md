## B. 学员现象

- 学员：女，粉背心、粉短裤、黑白鞋，右手持拍。室外硬地，低机位盯脚。
- 教练（绿格纹上衣、绿短裤）先自己做给她看：一只脚的脚尖底下垫着一个小黑物件（像手机/楔子），脚尖被抬起、脚跟还在地上；另一只脚在身后、旁边有一颗黑黄药球。
- 她接着做的是开放步：后脚靠近边线，前脚伸向场内，脚掌抵住药球。教练蹲下去把那个小黑物件塞到她前脚脚尖下面，让脚尖提前离开地面。
- 看得见的问题（用教练的对比说，不另造故障名）：脚如果整只贴地，只能用脚尖拧，蹬不出去；力如果从手臂往回带，腿的链就没接上。片中没有单独拍她「用手臂拖身体」的错误挥拍，这个现象写在标题和片尾字幕里，口播落到「压，不拉」。

## C. 教练归因（动力链 / 技术）

1. 蹬和转是两个动作，不要混成一个。字幕：「不要误会 / 蹬转其实是两个动作」。
2. 第一拍是整只脚的侧面发力，不是脚尖点地拧。字幕：「把脚整个侧面抬起 / 会有一股力穿到前腿」。口播：「这个时候发力是整只脚。整只脚。发力转。整只脚去转。」
3. 拿掉脚尖下的垫物之后，剩下的只是转，而且是脚尖在转，力出不来。字幕：「现在只是转」。口播：「如果没有了这个东西，你看。在这里。你是脚尖在转。」
4. 转完还要压着这只脚蹬出去。口播：「力度很。压着脚。蹬出去……明白了吧？」后半「蹬出去」之后两个字听不清。
5. 到学员身上：这一刻身体重心先移到前腿的一部分（不是整个人扑出去）。然后「轻松双腿发力」。顺序是「先压再转」，压完才转，他写成「巨有力」。
6. 前脚抵住药球：来到这个位置、脚尖一抬，把球顶开/踢开。口播「踢开它」「压之后踢」「压完之后，顶开你的脚」。药球是让前脚有东西可蹬，脚离开地面时鞋底会亮出来（口播听成「鞋底量直」，见 D，不当口令）。
7. 腿的链接上之后，上肢不用再带身体。片尾字幕：「腿部动力链完整了 / 上肢轻松拿捏」。文案括号是「力由腿发」。口播末段是「压，打 / 压不拉」——压（脚）而不是拉（手臂把人带过去）。片中烧录字幕没有逐字写出标题那句「不要用手臂带身体」。

## D. 教练见解与改法（口令、练法、步骤）

口令按字幕优先，口播附在后面。

- 「不要误会。」「蹬转其实是两个动作。」
- 「把脚整个侧面抬起。」「会有一股力穿到前腿。」口播同段：「发力是整只脚」「整只脚去转」。
- 错误对照：「现在只是转。」口播：「你是脚尖在转。」脚尖点地拧 ≠ 蹬。
- 「压着脚。」「蹬出去。」
- 「这一刻身体重心前移到前腿一部分。」评论里学员自己的理解：「重心要压到前脚」「脚贴地时蹬不动，原来要提前抬点脚」。
- 「轻松双腿发力。」
- 「先压再转。」「巨有力。」
- 站位 / 脚的方向（画面 + 口播，不是另外一套口令）：
  - 开放步。后脚留在边线侧，前脚朝场内、朝来球方向，脚掌抵药球。
  - 前脚脚尖底下垫高一点点，让「整个侧面」抬起来，脚跟先还在地上。不要整脚贴死。
  - 垫物拿掉或脚离开垫物之后，那一拍才是转；转的时候脚尖方向变了，但这一拍单独做只是转。
  - 蹬出去时这只脚的鞋底会朝外/朝镜头亮一下。口播约 58–65s 听成「鞋底，鞋底，鞋底量直」「量直出去」【口播不稳】。画面是鞋底对着镜头蹬离地面，更像「鞋底亮着」或「蹬直出去」，**不采用「量直」当口令**。
- 药球练法（口播 + 画面）：「你来了这里之后，一抬之后，踢开它。」「压之后，踢。」「你这脚压完之后，顶开你的脚。」约 82s 口播听成「要缝，放到这里之后」【口播不稳】；画面是教练把黑黄药球放到她前脚前，按画面记为药球，**「要缝」不采用**。「你自觉把这里打开，然后你就可以发力了。」
- 「你自觉。」「做得非常好。」「没错，再来一次。」约 68s 另一次听写是「没穿没穿，再来一次」【口播不稳】，同片评论写的是「无错无错再来一次」，采用「没错，再来一次」。
- 上肢：「压，打。」「压不拉。」片尾字幕「上肢轻松拿捏」。意思是腿蹬完，手只是拿着，不要用手臂把身体拉/带过去。标题「戒掉用手臂带身体，你要蹬」是标题，片中字幕没把这句再打一遍。
- 约 53s「你的脚不能够打的时候」【口播不稳】，像在说脚还没到能打的条件；不改写成别的口令。
- 文案「力由腿发」「不用很大劲」只记文案。片中没有数次数、没有「每天几次」。
