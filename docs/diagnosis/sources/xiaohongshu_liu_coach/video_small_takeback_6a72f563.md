## B. 学员现象 / 症状

- 室内，一侧是深灰墙，地面是硬地，没有球网入画。学员绿上衣、蓝短裤。教练黑背心、黑帽，多数时间站在学员身后或身旁。
- 开场学员面对墙，引拍把拍送到墙边。教练从身后握住他的拍，把拍留在身前，不让拍碰到墙。大字粉条：「please don't touch」。
- 碰到了就罚。0:36 粉字：「罚钱，罚钱 / 立刻做好」。1:06 红字开玩笑：「定点打会轻松动起来打 / 这钱有机会收了」。1:50 粉字：「忙活半天一块钱没赚到」。罚的是引拍太大、碰到墙，不是击球出界。
- 教练自己打的时候，拍停在身前不远的地方就向前送，球打在身前侧，不绕到墙上去。绿衣学员后来站到旁边看。2:16 前后学员把右臂直直伸到侧后方，拍头远离身体，这是大引的样子；教练的拍留在身前。
- 片尾教练又做了一次拍收到头侧后方的空挥。那时大字已经没了，不把这一下写成新动作。

## C. 动力链成因

1. 大引和二次引被文案写成两件坏事：击球晚，击球不准。练习的目的是把幅度自动改小，不是多讲一个要领。
2. 墙是限制，不是目标。拍一碰到墙，就是引得太远。大字用英文写「please don't touch」，用罚钱当反馈。人靠墙站，大引拍自然没处去，小引拍才放得下。
3. 力量被大引拍花掉。后段 small 能对上的是：「你把你的有限的力量，全部都用在往后扯。往后扯，上面扯。你不要用在往后扯。你放在这里，往下扯。」medium 后半同一句：「有限的力量，全部都用在往后扯，往上扯」。往上扯那两个字两套都有。再往下 small 还有「走过去 / 放下去 / 手放下去」，medium 没有，只作 small 单侧，标【小模型单侧】。「挺」「撑撑」「慢力 / 蛮力」两套对不齐，【听不清】，不进成因。这里的「往后扯、上面扯」是把有限的劲用去把拍拉到身后和上方。**「往下扯」「手放下去」只记原话，不写成降拍。**
4. 改完框架才谈发力。2:42 粉字：「框架修改好了 / 准备发蛮力打球」。2:36 先有一句「很好啊，一学就会」。发力被他放在框架之后。大字「发蛮力」是口语，不当技术口令。
5. 片中没有髋、没有拍面朝地。不补。

## D. 改进 / 口令 / 练习

- 靠墙做。引拍不许碰到墙。碰到就停，重来。他用「罚钱」「please don't touch」当即时反馈。
- 教练可以站在身后，用手把拍留在身前，不让学员把拍送到墙上。
- 劲不要先花在往后拉、往上拉。拍放在身前这一带再打。原话「往下扯」「手放下去」只作引用。
- 框架小了之后他才说可以发力。不把「发蛮力」写成加速口令。
- 没有次数、组数。automatic 是文案里的词：靠墙的限制让小引拍自己发生，不是再背一个动作名。
