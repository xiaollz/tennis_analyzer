## B. 学员现象 / 症状

- 室内蓝场地。学员黑上衣、白短裤、遮阳帽，持绿拍。教练白上衣、黑短裤（LACOSTE）。一瓶可乐绑在拍上，红盖露在拍头一侧，瓶身在拍面旁边。
- 开场两人并排，学员把拍从身前送向身侧，红盖跟着出去。教练在他右侧，用手比、用嘴讲。
- 大字说的错：红盖（拍头）一直带头走得太远；手腕如果为了追这个远路而改掉，轨迹就乱。他要的是红盖先不在前面，追上来，再在回来的路上带头。
- 后段学员自己打。拍会收到身侧、举过腰。片尾收拍拍面朝天，被评论点出，作者认这个错。

## C. 动力链成因

1. 拍头乱窜被写成两件结果：球满天飞，力量去不到地方。他不先加力，先给拍头一条能看住的轨迹。红盖就是那条轨迹的指针。大字：「边喝边练，只管红色轨迹。」
2. 交换，不是一直带头。大字按出现顺序：把红色的换成前面 → 红色的换换出去 → 你不能够让他继续 / 不能够带头走这么远 → 他不是带头的 → 换过来红色带头 → 红色虽然他不是在前方 / 但是他现在已经追上来 → 然后他带头往回走 → 不要一直让他带头 → 这个交换尤其重要。口播同一套，用词是「带红色」，和大字「带头」指的是同一件：红盖。不把「带头」理解成身体部位。
3. 交换的时候手腕不动。大字：「所以你的手腕没有改变。」紧接着：「小臂要悬 / 选择这个姿势哦。」「悬」字口播和大字一致，不改成「松」。意思是小臂停在这个样子里，不是再转一次腕。
4. 抓拍的方向。大字：「我们不是这样去抓球拍，也不要斜着抓球拍。」「永远让可乐对自己。」然后：「放下来转体」「可乐朝上」。放下来的是瓶（拍头）的朝向配合转体，**「放下来」只记原话，不写成降拍**。「转体」是身体转，不是手去推。
5. 口诀是红盖的四个朝向，大字黄字写全了：「红色盖子口诀来了 / 对自己～对天上～对后面～对自己。」粉字重复：「可乐是对自己朝上」「边朝上边朝后边追」。末字口播是「追」。有一版画面把末字读成「嘴」，不采用，不当技术词。四个朝向是看瓶盖的顺序，**不改写成旋后**。「对后面」是瓶盖在轨迹上的一个朝向，不是前臂旋转口令。
6. 回家只看瓶。大字：「好了现在你拍的视频里边 / 回去就只是看这个 / 其他的不管他 / 回家挥拍练习 / 可乐在怎么去运作就」。口播同一句。别的部位先不看。
7. 片尾大字「好好看的挥拍轨迹」，学员在打。评论指出收拍拍面朝天，作者同意那是错的。朝天发生了，但不是口诀的终点。口诀的终点仍是「对自己」，不是朝天。

## D. 改进 / 口令 / 练习

- 拍上固定一瓶可乐，红盖当拍头指针。边做边只看红盖。
- 红盖不要一路带头走很远。先让它不在前面，等它追上来，回来的路上再让它带头。这个交换时手腕不要改。小臂保持他选的那个姿势，原话「小臂要悬」。
- 不要正着硬抓，也不要斜着抓。让可乐对自己。然后放下来、转体，可乐朝上。原话照记，不改成降拍。
- 口诀四拍：对自己，对天上，对后面，对自己。回来接着看这四个朝向。
- 自己录像时只看可乐怎么走，其他先不管。
- 片尾如果收拍拍面朝天，按作者自己的回复，那是要改的，不是示范。
- 没有次数、组数。握拍他在评论里答「半西」，只记这一句，不进处方。
