## B. 学员现象 / 症状

- 大字先写禁令：「初学者脚步 / X的位置都不能是最后一步」。X 是地上那种红色叉标所在的位置，不是一个动作名。
- 白字把初学者不该做的收成一句，连说三次不要：「初学者不要不要不要后撤步」。
- 蓝字把另一种错法写成：「不是直接挥拍」。同一张上面还有「前脚踩稳」。
- 片中大字没有「轻轻降下去」「送拍柄」「送拍头」「送肩」「转髋送球拍」「拉胯」「转胯」「等地转髋」。出现的是「转髋挥拍」，只引用这四个字，不改写成送髋。

## C. 动力链成因

只写大字。口播若和大字不是同一句，不拿来改大字。

1. 「X的位置都不能是最后一步」。最后一步不许落在 X 上。
2. 「点地方是允许我们最后一步（开放式或者关闭式）」。大字就是「点地方」。允许当最后一步的，括号里写的是开放式或者关闭式。不把「点地方」改成垫步或占位。
3. 「击球后follow」。follow 用的是这四个英文字母，大字没有中文随挥。
4. 四行叠在一起：「这里要很留意的另一个点」「前脚踩稳」「接着是转髋挥拍」「不是直接挥拍」。顺序就是这四行的顺序。转髋只出现在「转髋挥拍」里，不改写成送髋。直接挥拍是他否定的那一种。
5. 「初学者不要不要不要后撤步」。三次「不要」都在大字上。作者评论把后撤步留给「比赛中球压底线」，并把后场后退另写成「正手，左脚后交叉。反手，右脚后交叉」。那是评论，不是这一段大字。两处都保留，不并成一句。
6. 结尾红字：「脚步对了才能马上成功」。马上，不是「马的」。

口播听写里有「踩上去」「一二三四」「往斜的走两步」「这边是差的，这边是对的」，和地上的标、数步能对上，只作听写。听写里的「车撑」和大字「后撤步」对不上，不采用「车撑」。

## D. 改进 / 口令 / 练习

- 文案：初学脚步要严格认真掌握。没有组数。
- 看得到的练法：地上放红标、蓝标和后来的橙叉。他弯腰去挪这些标。她踩上标再挥，他在旁边看、拍手，或用手比划。后段两个人站着看他指叉。
- 大字口令：X 不能是最后一步；点地方可以是最后一步（开放式或者关闭式）；击球后 follow；前脚踩稳，接着是转髋挥拍，不是直接挥拍；初学者不要后撤步（大字连写三次不要）；脚步对了才能马上成功。
- 粉字「漂亮」、粉字 `prefect`（画面拼法）是对一次踩标或挥完的反应，不是另一套步法。
- 评论里的「正手，左脚后交叉。反手，右脚后交叉」只挂在后场往后退那一条，不写进初学者这一式。
