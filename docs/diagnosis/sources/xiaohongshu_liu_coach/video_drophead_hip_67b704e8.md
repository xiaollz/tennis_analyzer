## C. 教练归因（动力链 / 技术）

字幕优先。口播只在和字幕同向、或字幕没写时补上，并标明。

1. 拍头下来不是手腕的事。粉字：「第一重要 / 手腕不能动 / 打死都记住」。蓝字后段：「整个动作期间 / 都不可以动手腕」。口播 3.9–7.2s：「这个手腕是不可以动」。
2. 放下来靠小臂转。粉字：「通过小臂旋转 / 球拍放下来」。口播 8.6–12.0s：「其实是我们的小臂放下来的。来到这里做。」文案另有一句「小臂内旋送球」（只在文案，烧录字幕没打出「内旋」「送球」这四个字连在这一句上）。不得把「内旋」写成旋后，不得把「送球」写成送髋。
3. 放下来的这个姿势本身打不了球，但要守住，先不跟球走。粉字 14.5–24.5s：「这时是无法击球的 / 无论如何都保持这个姿势」。口播 15.8–18.2s：「这个时候跟球没有关系」。
4. 然后才「转肩顶胯」，拍面自己对准球。粉字原文：「随后转肩顶胯 / 拍面自动对准球」。这里的「顶胯」是字幕原词，只引用。
5. 收腹是他点名的细节。粉字：「里面有个超级细节 / 需要收腹」。反面：「挺肚子挺胸 / 都会导致肩膀后倾」。
6. 他称为完整的掉拍头（粉字用「掉」，不是标题那个「降」）连着的是「转髋收腹送球」。粉字原文整句：「看看完整的掉拍头 / 转髋收腹送球」。送的对象字幕写的是球。
7. 压拍面。粉字：「这时拍面尽量压平」。作者评论里的对应句是「转髋前拍面侧外，转髋后拍面向球」（评论，不是这一秒的字幕）。
8. 片尾三条粉字：「三大重点 / 立手腕转髋收腹」。口播同一段反复是「顶」和「收腹」：102.4s「一顶的时候收腹」，106.0–107.9s「顶的时候不可以这样顶」，112.3s 与 116.4s「收腹顶」。Whisper 把「腹」听成「拂」，以字幕「收腹」为准。「顶」保留口播用字，不改写成别的髋部口令。119.5s「出发」【口播不稳】，不采用。

## D. 教练见解与改法（口令、练法、步骤）

口令按烧录字幕。口播附后。没有数次数。

- 「尽早给学生打好 / 掉拍头的基础。」（粉字；标题和文案用的是「降拍头」，见 A，两处不要并成一个词）
- 「第一重要。」「手腕不能动。」「打死都记住。」口播：「这个手腕是不可以动。」
- 「通过小臂旋转。」「球拍放下来。」口播：「其实是我们的小臂放下来的。」「来到这里做。」「像我一样。」
- 「这时是无法击球的。」「无论如何都保持这个姿势。」口播：「这个时候跟球没有关系。」
- 蓝字：「整个动作期间 / 都不可以动手腕。」和上面的「手腕不能动」是同一条，蓝字把时间拉长到整个动作。
- 「随后转肩顶胯。」「拍面自动对准球。」【「顶胯」仅字幕原文】
- 「里面有个超级细节。」「需要收腹。」
- 不要：「挺肚子挺胸。」后果字幕写「都会导致肩膀后倾」。
- 「看看完整的掉拍头。」「转髋收腹送球。」【「送球」仅字幕原文】
- 「这时拍面尽量压平。」
- 「丑的自己都无法接受。」（对着错误那一下，没有再解释丑在哪一个关节；口播接着说的是「不可以这样顶」）
- 「三大重点。」「立手腕转髋收腹。」第一字是「立」，不是「锁」。口播同段：「一顶的时候收腹。」「顶的时候不可以这样顶。」「收腹顶。」
- 约 30.1–47.5s 口播只稳定听到「刚刚我说了什么?」，中间被 VAD 拉得很长，【口播不稳】。48.2–51.2s「不可以干嘛」【口播不稳】，不改写成别的口令。紧挨着的字幕仍是「挺肚子挺胸」。
- 文案四句只记文案（见 A）。「肌肉记忆」「越早固定框架」片中字幕没有再打。
- 评论里作者另说的、片中字幕没有的：曲臂可以，曲更要弹性；松要看阶段，3.5 以前别拿鞭打当要求；转髋前拍面侧外，转髋后拍面向球。这些记评论，不升成片中口令。
