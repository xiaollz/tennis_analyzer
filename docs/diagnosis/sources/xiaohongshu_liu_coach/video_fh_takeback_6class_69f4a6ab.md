## C. 动力链成因

只写大字、文案和对得上的评论原话。

1. 文案：6 届正式课后，大场正手和小场反手「相当合理和标准」，因为「对网球动力链底层逻辑已经理解」。理解本身没有在文案里拆成步骤。
2. 大引拍的代价，绿字原句：幅度大，击球时间长；经常出现晚击球；动作自然变形。
3. 他按人分开。黄字：「10岁前的很多孩子都会做大引拍」。下一张：「先天条件的限制」加上「用大引拍的无可非议」。粉字：「孩子的引拍就相对大」。孩子这一档，他不否定大引拍。
4. 另一档，粉字：「成年人一旦依赖手臂大挥拍」。绿字另给「男生」打叉。约 2:26 粉字上半被角标挡住，露出的是「生是完美不该 / 靠手臂发力打球」。首字没有单独露出来，不补。
5. 力量从哪来，结尾粉字原句：「确实不用太大引拍 / 通过转体也是很有力量的」。下一张：「转体的力量足够」。「转体」只引用，不改写成送髋。
6. 尺度还在。粉字：「同时也要必须把握好尺度」。评论里作者另写：没有不让大引拍；小变大以后很简单，大变小你得花很多钱。拉到七八点钟、一想发力就拉过，是观众的句子。作者回复原话：「发力要通过转髋，重心后向前，克制你的手去使劲。」这句里的「转髋」只引用。

## D. 改进 / 口令 / 练习

- 问句原样留着：「到底要不要大引拍（尤其」后面两个脸的表情「和」再一个脸「）」。他没有在这张上回答要或不要。
- 孩子、以及他写成先天条件受限的人：大引拍「无可非议」。成年人：不要依赖手臂大挥拍。男生那张是一个叉，没有替换动作。
- 要避开的是绿字那三样：幅度大所以击球时间长、晚击球、动作自然变形。
- 力量用他的原句：不用太大引拍；通过转体也是很有力量的；转体的力量足够。不改写成送髋。
- 同屏还有：「同时也要必须把握好尺度」。
- 粉字：「一个特殊训练方式（小秘密」后面三个「秘」，各套一个红圈）。画面上他隔着网去握她的拍和手。秘密的内容大字没有写开。
- 结论粉字：「结论，真是可靠 / 看看自己到位时间」。到位时间是他给的自查，没有秒数。
- 结尾：「哈哈，1000个多球 / 肌肉记忆就」加一个绿勾。1000 是这张大字上的数，没有组数、没有每天几次。
- 评论口令只记原话，不当本片烧录口令：发力要通过转髋，重心后向前，克制你的手去使劲。
