## A. 元信息 / 标题文案

- 标题：网球20分钟4小练习魔改正手动力链
- 文案要点：侧身转髋是初学者典型问题，辅助手也要重视；借鉴塞尔维亚教练方法，约 20 分钟调框架。

## B. 学员现象 / 症状

- 开式站位偏开放；
- 引拍偏晚；
- 非持拍手未引导；
- unit turn / 侧身浅；
- 触球偏晚、偏手臂，球飘；
- 随挥后背未转到对镜头（转不够）。

## C. 动力链成因

三个「剩下来」的缺口：

1. **引拍晚于移动**；
2. **辅助手引导失败**；
3. **侧身 / 转髋不足**。

目标链条：启动时一次完成侧身 + 引拍 + 辅助手；触球前肚脐约 90°；触球后继续转到后背对镜头。

## D. 改进 / 四个长训练棒练习

1. **空挥 + 训练棒**：双手上举 → 左手放开 → 右手送出 → 重心到前脚。
2. **儿童拍 + 真球**：右手儿童拍，左手持棒作辅助手；字幕强调重心转移。
3. **标准拍 + 辅助棒**：启动完成侧身 + 引拍；转髋做满。
4. **无棒正常击球**：触球前侧身够（肚脐约 90°）；触球后转到后背对镜头；击球后向前跑两步巩固重心前移；多球建立肌肉记忆。屏显写约 **15 分钟**可见变化（标题写 20）。
