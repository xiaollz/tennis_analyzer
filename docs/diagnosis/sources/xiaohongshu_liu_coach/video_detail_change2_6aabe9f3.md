## A. 元信息 / 标题文案

- 标题：网球🎾每个细节的改变都会让你涨球(二)
- 文案：初学者 95% 都没有重视这个细节，到了 2.5/3.0 瓶颈期上不去。调整这里让击球更重，脚步更快更合理。
- 评论（非口令）：多人说自己也后仰、不稳定、听不清。观众「明天就退休」猜是留头；教练本人没有用「留头」。作者回复里把原因说成后仰。另一条评论说国外教练嘴边就是 forward，和片中口播一致。

## B. 学员现象 / 症状

- 开场红字「错 no」：同一学员开放步挥拍，球往上走、不到向下的线路。
- 球还没打完人已经往后退，肩膀跟着往后、往上，打完就想回位。
- 教练点名：**后仰**就是这个原因。后仰时两只手才会在身前接上；人往前时手自然接得上。
- 出界以后立刻退回去看球，下一个球没有意义。

## C. 动力链成因

1. 手往前的时候，肩膀应该跟着身体往前，人就不该同时往后走。字幕/口播「不应该是跟着你的肩膀往前推吗」【教练原话，含「推」；**不是**我方「推肘」】。
2. 整个动作是往前的。最后肩膀留在身体最前方，而不是打完就结束。
3. 回位要晚：听到球落地的声音、球下来了，再往后走。
4. 脑子里的错误顺序是「等球结束我才走」；球还没结束就回去，没有意义。即便这球出界了也一样。
5. 潜意识里还有 forward，手才接得上（口播 bang / 接了）。

## D. 改进 / 口令 / 练习

- 一句反复出现的原话：**always forward**。他说外国好教练、他们俱乐部所有教练嘴边都是这句。
- 在击球这个地方把动作做完，看一眼，再退回来。不要肩膀先往后。
- forward 的同时手接上；不 forward 就会后仰。
- 片尾他边看边说 forward、good shot、forward、nice。约 2:24 后切红土职业脚步（向前、上步），没有新口播。
- 「肩膀往前推」「后仰」只记原话，不写成推肘或送髋。
