## C. 动力链成因

只写大字和文案对得上的。

1. 文案：转髋送肩留头一键三连，会很自然。分开练会感到有顿挫感。「送肩」只引用，不改写成送髋。
2. 错误 1 的位置：右手球拍在身体外侧；左手和髋同高。两句是位置，不是力度。
3. 「这个姿势是改变发力坏习惯 / 最重要点。」姿势被他接上改坏习惯。最重要的是这个姿势，不是另一条口令。
4. 「做上一个留头动作 / 确保上身平衡。」留头被他接上上身平衡。上一个，指的是刚摆过的那个动作，大字没有再编号。
5. 「非常重要 / 只要人的中轴线不改变。」中轴线不改变，被他写成条件。轴是哪一条线，画面没有画出来。
6. 粉字一行：「转髋+送肩+留头」。下一行：「正手框架」。三个词用加号连着，对应文案的一键三连。「送肩」只引用。
7. 「初学者请牢记动作的目标只有两个 / “击准球+身体平衡”」。目标被他收成这两样，引号是画面上的。
8. 结尾：「没错吧 / 打准球平衡身体后一切都会automatic。」打准、平衡在前，automatic 是他的结果词。

## D. 改进 / 口令 / 练习

- 文案要试的是一键三连，不要分开练。分开的结果他写成顿挫感。
- 先改的位置：右手球拍不要留在身体外侧；左手和髋同高。后一句只引用，不当送髋。
- 这个姿势，他写：改变发力坏习惯，最重要点。
- 留头：做上一个留头动作，确保上身平衡。只要人的中轴线不改变。非常重要。
- 框架大字原句：转髋+送肩+留头。正手框架。送肩只引用原文，不改写成送髋，也不当我方 cue。
- 初学者的目标只有两个，原句：击准球+身体平衡。然后：打准球平衡身体后一切都会automatic。
- 没有次数、组数。看得到的练法是空挥：绿外套的人扳她的手和拍，人站到她身后，她把拍举在身前再挥上去。
