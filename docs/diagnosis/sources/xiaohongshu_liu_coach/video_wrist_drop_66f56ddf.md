## B. 学员现象

- 这一条没有学员出镜。教练自己站在网前，蓝绿 polo、白短裤，右手持拍，左手比划。场地是室外硬地，绿色挡网印着奥易。
- 文案说的现象：球友击球轨迹非常不稳定。片中把它指成正手的「掉腕」，并和发球的「翻腕」放在一起。
- 看得见的对照（用字幕的名字，不另造故障名）：
  - 正确示范：拍在体前，手腕被字幕写成「此刻立起来」，拍头朝上，拍柄底部冲着镜头。
  - 错误示范：手腕一折，拍头掉下来、拍面摊开。粉字：「这是掉手腕不是掉拍头」。白字：「掉手腕后我们会用胳膊去扇球」。
  - 他用发球来类比：手腕在一个地方突然翻下来。文案叫「翻腕」。

## C. 教练归因（动力链 / 技术）

1. 正手和发球是同一类错。文案：「发球有个很错误的动作翻腕，正手也有一个错误的掉腕。」口播 1:14.4–1:21.4 把正手掉腕说成和发球翻腕一样，手腕在那个地方突然翻下来。
2. 引拍可以是一次成形，也可以分体拉过来，手腕都要立着。口播 0:07.7–0:23.4：「不管我们平时球拍是一次成形拉过来，还是分体的拉过来……我们这个手腕都是尽量是立起来的。看这个位置是立起来的。」粉字 0:22–0:24 只有「手腕此刻立起来」。
3. 很多球友一打就变成折腕。口播 0:25.7–0:31.4：「很多球友在打球的时候，一打就变成了这样。」粉字 0:30–0:32：「这个动作很容易出现在挥拍之前」。
4. 这不叫放松手腕，也不叫掉拍头。口播 0:31.4–0:35.9：「这是不是叫做放松了手腕。掉手腕。」（Whisper 写成「吊」，字幕是「掉」，采用「掉」。）粉字 0:35–0:41：「注意哦 / 这是掉手腕不是掉拍头」。蓝字：「这是不一样的」。口播 0:39.8–0:46.4：「大家觉得这个是掉拍头吗？不是，这是掉手腕。不是掉拍头。我们的手腕其实是不要掉。」
5. 一掉，拍的角度从「往下打」变成「平拍过去」。口播 0:46.8–1:02.0：「我们一掉，就变成了球拍本来这个角度，我们的球拍是应该是往下打的。……专业运动员都是这样往下打的。如果我们的拍头，手腕一掉就变成了平拍过去。」粉字 0:51–0:54 写的是另一句：「没有掉手腕 / 就能蹬地转髋打球」。两句同时存在：口播讲拍头方向要往下，字幕讲没有掉手腕才能蹬地转髋。都不改写。
6. 掉手腕之后是用胳膊扇。白字 0:60–0:65：「掉手腕后 / 我们会用胳膊去扇球」。口播同段被听成「三人家的动作」「三」【口播不稳】，以白字「扇球」为准。评论里球友自己也说「翻手腕，然后扇球」。
7. 转髋击球之后手臂可以松。粉字 1:07–1:09：「转髋击球手臂 / 可以自然放松」。口播 1:06.6–1:10.4 有「抚摸一下」「这个就是包…有旋转」【「包盒」口播不稳，不收成口令】。口播 1:10.9–1:14.1 是清楚的：「所以我们的手腕在我们打球之前不要松。」
8. 片尾粉字：「今天重点 / 击球前切勿翻（掉）手腕」。括号里的「掉」是字幕自己加的，和「翻」并列。

## D. 教练见解与改法（口令、练法、步骤）

口令按字幕。口播里和字幕一致的附在后面。没有数次数。

- 文案只记文案：「翻腕」「掉腕」「轨迹非常不稳定」。
- 口播（无字幕，听得清）：「一次成形拉过来」或者「分体的拉过来」，「手腕都是尽量是立起来的」。
- 粉字：「手腕此刻立起来。」画面是拍头在上、拍柄底部朝镜头，手腕没有折下去。
- 粉字：「这个动作很容易出现在挥拍之前。」指的是还没挥就已经掉腕。
- 粉字：「注意哦。」「这是掉手腕不是掉拍头。」蓝字：「这是不一样的。」口播：「不是，这是掉手腕。不是掉拍头。」「我们的手腕其实是不要掉。」
- 口播：「球拍是应该是往下打的。」「专业运动员都是这样往下打的。」「手腕一掉就变成了平拍过去。」
- 粉字：「没有掉手腕。」「就能蹬地转髋打球。」【「蹬地转髋」仅字幕原文】
- 白字：「掉手腕后。」「我们会用胳膊去扇球。」口播同段的「三人家 / 三」不采用，采用「扇球」。
- 粉字：「转髋击球手臂。」「可以自然放松。」时序在字幕里是击球（转髋那一下）之后手臂可以松。口播把「不要松」放在「打球之前」：「手腕在我们打球之前不要松。」两句都保留：之前不松，字幕说的放松是转髋击球那一拍的手臂。
- 口播把正手和发球并在一起：「跟我们发球是不是一样。」「翻手腕。」「在这个地方突然翻下来了。」「翻手腕。」其中 1:17.2「老子说翻手腕」【口播不稳，更像「老是说翻手腕」】，不把「老子」当口令。
- 粉字片尾：「今天重点。」「击球前切勿翻（掉）手腕。」
- 评论里作者另说、片中字幕没有打出来的：练不出来就用扫把；放小臂是关键；掉拍头不是靠手腕，是靠髋部转动；先转髋，锁死手腕；顶宽在小臂下放后；时机去看置顶另一条。这些记评论，不升成这一条的片中口令。「锁死」和片中粉字「立起来」用字不同，不互相替换。
