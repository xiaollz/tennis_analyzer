## B. 学员现象 / 症状

- 标题和文案把问题写成：击球会晚了。晚的是击球。
- 粉字把晚写成一句结果：「你还在移动就证明你已经晚了」。前面用引号限定范围：「当球落在场地里」。
- 英文字幕同一句：「if you still moving / you late」。语法按画面原样，不改。
- 粉字把不规则弹跳摘出去：「不规则弹跳除外哈 / 自认倒霉吧」。除外的是不规则弹跳，不是所有晚击球。
- 片中大字没有「降拍」「送髋」「推肘」「旋后」「伸肘」。不补这些词。

## C. 动力链成因

大字单列。口播未听写，不另补一句口播机制。

1. 粉字：「很好的问题 / 当球boom落地 / 身体状态应该如何呢」。问的是球 boom 落地时身体在什么状态。boom 是大字里的英文，不翻译成另一套口令。
2. 粉字：「正常情况（好的情况） / 当球落地我们必须同时具备击球姿势」。好的情况被括号标成「正常情况」。同时具备的是击球姿势，时点是球落地。
3. 粉字：「谨记「当球落在场地里」 / 你还在移动就证明你已经晚了」。晚的证据是：球已经落在场地里，人还在移动。
4. 黄字英文字幕：「if you still moving / you late」。和上一句对得上。still moving 是他还在移动。
5. 粉字：「节奏重点当对方击球同时 / 你要马上做好击球姿势」。文案里的「对方击球时你该做啥」对上这一句。马上做好的是击球姿势，时点是对方击球的同时，不是球落地之后再准备。
6. 黄字：「就是这个 / 球落地击球姿势已经完成」。示范里，球在地上的时候，蓝衣的人已经低重心、分开脚。大字把这一下叫击球姿势已经完成。
7. 黄字：「停止移动 / 击球姿势完成」。停止的是移动。完成的是击球姿势。没有在这句里再命名髋或拍头。

## D. 改进 / 口令 / 练习

- 文案：对方击球时做一件事，球落地时做一件事。没有次数。
- 看得到的练法：前半两个人站着讲，用拍和手比划。后半蓝衣的人在场上移动、停住、挥拍，地上有球。约 1:42 起黄字标明「慢动作看看这个击球节奏」，画面放慢他的移动和挥拍。没有别的道具被大字说成教具。
- 大字口令：当球落地必须同时具备击球姿势；对方击球同时马上做好击球姿势；停止移动；击球姿势完成。
- 不规则弹跳被大字排除，不并进这几句口令。
