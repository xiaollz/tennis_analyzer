## C. 动力链成因

只写大字和评论里对得上的原话。

1. 上课前他看见的是脚：没站定就击球；一边退一边打；脚不到位还捞着球打。三句都是脚和球的关系，不是力度。
2. 他要在一小时里看的三样，黄字原样：挥拍轨迹、击球重心、能不能改好。
3. 粉字把第一处叫做「核心细节 / 持拍手的摆放位置」。持拍手，不是另一只手。位置，不是力度。
4. 下一处粉字：「击球核心2 / 挥拍要慢」。「2」是这张上的数字。慢的是挥拍，大字没有写慢在哪一段。
5. 再换一法，粉字：「陈教练换了一个小方法 / 左手轻轻握着右手腕击球」。左手握的是右手腕。这句只引用，不改写成推肘或伸肘。
6. 结果他写成：「前所未有的松弛感出来了」。松弛感是他的结果词。
7. 她后来对着镜头，黄字：「其实」加一个拍和球的小图「有一个逻辑 / 大家务必搞懂」。下一张：「没人可以100%站对每一个来球」。逻辑被他接到「站不对也要打」这一侧，大字没有把逻辑再写开。
8. 评论原话：手放后面「不利于等地转髋，同时延长了挥拍准备时间」。转髋只引用。

## D. 改进 / 口令 / 练习

- 开场大字先给陈教练一个任务：「fizzcoco俱乐部陈教练 / 给他一个机会换来一个暴力正手」。暴力正手是这张的结果词，没有次数。
- 先看的位置：持拍手的摆放位置。粉字叫它核心细节。画面上他握着她的拍和手，球车在旁边。
- 挥拍要慢。粉字编号是「击球核心2」。多慢，大字没有写。
- 小方法原句：左手轻轻握着右手腕击球。只引用，不改写成推肘、伸肘。
- 慢动作之前粉字：「美丽小裙子摆起来」。裙子是这张的说法，不是另一条口令。接着：「高清慢动作来了」。看得到的是她把拍从身侧挥出去，他在旁边。
- 粉字替观众问：「教练说拍头出去 / 到底怎么样做到」。下一行：「这可能是很多球友心声*^_^*」。问句留着，这张没有回答拍头怎么出去。

- 结尾粉字：「一小时飞快框架里关键的细节一点点修正」。然后：「效果挺好的 / 越打越流畅」。最后一张：「下课」，旁边有花。没有组数。
