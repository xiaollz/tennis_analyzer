## B. 学员现象 / 症状

- 大字把要避开的位置写成：「打好正手 / 球拍远离后背」。远离的是后背，不是某一个关节名。
- 口播同一段（听写）：「你的球拍从来不会跑到后面去了吗」「是在你身体的外侧去挥动」。和大字是一件事。听写把「外侧」听成身体外侧，大字没有「外侧」两个字，外侧只算口播。
- 评论里别人说的「拍子拉后打」是观众的话，不是片中大字。
- 片中没有「轻轻降下去」「送拍柄」「送拍头」「送肩」「转髋送球拍」「拉胯」「转胯」「等地转髋」「转体」。

## C. 动力链成因

只写大字，以及能和大字对上的口播。听写句标明。

1. 大字：「球拍侧方贴网」，下面一个勾。口播：「软网最好」「看，就这里」「你看着前面」。贴的是软网的侧方，看的是前面。
2. 大字两行：「挥拍还是保持 / 拍子侧方贴着软网向前」。旁边粉字拼成 `prefect`（画面就是这个拼法，不是 perfect）。口播：「贴着这里挥」。向前是这一行的方向，保持的是贴着软网。
3. 大字：「打好正手 / 球拍远离后背」。口播把同一件事说成球拍不跑到后面、在身体外侧挥。后背、后面，都只引用，不改写成别的口令。
4. 粉字一个字：「刮」，后面一串点。口播邻近句听成「挖着这里出去」「贴着往出去」。大字是「刮」，听写的「挖」不覆盖这个字。
5. 口播还说到女孩子会做、莱巴也会、现代的不会、距离大约一个球拍。这些没有对应大字，只作听写，不写进成因链。

## D. 改进 / 口令 / 练习

- 文案：家居都可以练的挥拍；1000 个之后「无论侧身，击球都会很规格角度」。口播次数是一百颗、100 下。两边都保留。
- 看得到的练法：人对着左侧软网，把拍贴在网的侧方，再向前挥。口播：「贴着这里挥」「看着前面」。没有喂球，没有次数以外的组数。
- 大字口令按出现顺序：球拍侧方贴网；挥拍还是保持，拍子侧方贴着软网向前；打好正手，球拍远离后背；刮。
- `prefect` 只是画面上的对勾字，不改成正确拼写后再当口令。
