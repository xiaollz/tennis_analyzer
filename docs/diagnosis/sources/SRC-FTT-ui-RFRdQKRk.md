## 1. 解决的症状（主诉）
- 「转成侧身」不等于「coil」：髋跟着肩一起转 → 没有张力可释放 → 靠往上捞球补偿（→ FLT-04、FLT-05；与 tree.md 的 FLT-04/05 同层）。
- 次：进攻球/前倾球时无法在前脚上做反向旋转，失去平衡。

## 2. 它认为的上游成因（教练自己的因果链，A → B → 症状；均为 Gemini 抽取，**未核对**）
1. 引拍时髋/骨盆跟着上半身一起向后转 → 上下半身之间没有扭转张力 → 前挥时没有可释放的张力（00:39–00:47）。
2. 骨盆与肩同去同回（不反向）→ 躯干转力不足 → 被迫向上捞球补偿（02:30–02:42）。
3. 反向旋转做对、力量变大 → 若沿用原来向上的轨迹 → 球飞出底线；须改成更 overhand（02:51–03:26）。
4. 单脚站立时仍同向转 → 失去平衡、必须落脚 → 逼大脑自己找到反向旋转（04:38–05:05）。
- 与 tree.md：链 1、2 与 FLT-04（Unit Turn）/ FLT-05（髋）同方向；「unit 不包含髋」是否与 FLT-04 一致、与书 p.57–62 是否一致，**未核对**。链 2 的「向上捞球」与 FLT-08（up 过多）有关联，属推断。

## 3. 默认前提（Gemini，未核对）
- 进攻球、前倾球最容易暴露问题；底线对拉「可以蒙混过去」（06:15，旧笔记无对应）。
