## 2. 它认为的上游成因（教练自己的因果链，A → B → 症状）
1. 引拍到前挥的转向处背部不稳（没有「夹住」背阔肌/肩胛）→ 前侧较弱的软组织被向后拉伸、没有东西可以弹回 → 力量流失，也是伤病多发处（01:29–01:50、02:36–02:58）。字幕：「that's where a lot of injuries happen and it's where a lot of power gets lost」。
