## 1. 解决的症状（主诉）
- **主诉**：正手机制做对之后，仍然回到旧的「被挤住」击球点，一切崩掉（→ FLT-01）。
- **次**：被挤住的两端失败——球太近（手臂缩成鸡翅、肘被拽过身体）与够过头（屁股后撤、拍子前伸）。
- 视频的做法是把「击球槽位」拆成三个轴——横向（离右侧多远）、纵向（转动平面起点高低）、纵深（身前余量 + 前倾余量）——逐轴给练习。

## 2. 它认为的上游成因（教练自己的因果链，A → B → 症状）
均为本期转写能对上的说法；括号里是时间。
1. 旧习惯的击球通道近 → 即使机制做对也会无意识退回旧的被挤点 → 动作崩掉（00:50–00:59）。**与 tree.md 一致**（FLT-01 的「站位/间距」上游，但这里强调的是习惯回吸）。
2. 球放得离身体近（横向）→ 只能「underhand yank」把肘拽过身体 / 用肘去顶球（转写此句含糊）→ 被挤住（06:12–06:57）。FLT-01 已有「肘撞球」的描述，**视频给出机理**。
3. 重心停在两脚跟之间（不是整只脚）→ 挥拍向左掉：整条右腿没有带你穿过球场，而是从脚跟蹬、被带回左边（05:44–06:05）。**tree.md 里没有对应节点**（见 §5 待定区）。
4. 深度（前后）间距错 → 肩膀和自然击球动作被「麻痹」；球太近 → 持拍臂缩成「鸡翅」或卡在躯干后面（13:28、14:05）→ FLT-01。
5. 打算前倾却按「不前倾」的槽位准备 → 前倾吃掉手臂空间 → 又回到被挤住（14:36–15:19）→ FLT-01 / FLT-10（与 FLT-10 现有的「+6 英寸【单源】」是同一出处，**不是第二来源**）。
6. 想进攻，直接跑向球 → 把自己挤住（16:02）。出发点是对的（脚积极），问题是没有和「动态找深度间距」挂钩。
7. 为了「留足空间」而够得太多 → 屁股后撤、拍子前伸（butt back, racket forward）→「丢了动作」；修正是更耐心，回到绝对在身前、但不夸张的深度槽位（16:40–17:14）。FLT-01 已有「易混淆：够过头」。
8. 低球时转动平面太水平 → 容错很小，要完美接住（10:30–10:56）；高度靠调转动平面（髋铰链）而不是手臂独立抬（09:49–10:20）。与 FLT-10 的「用手臂/手腕够低球」方向一致。
9. 加速起点远高于球 → 很难造出高度与旋转（08:39–08:48）；要的是手在球下方、被躯干和肩甩出去、沿缓和向上斜线滚过球（09:14–09:28）。
10. 非持拍手收在身前 → 更难找间距、速度更低、整体不协调（01:34–02:12）；教练同时说「不是物理必须，但更容易、更平衡」（01:45–01:52）。

## 3. 默认前提
- 水平：已经能做到「胸下压、髋稳定、肩膀连着转、缓和的半圆」的球员（00:13–00:27）；这是整期处方的前提，**不适用于机制还没建立的阶段**。
- 示范对象：Alexa，教练**亲手喂球**，位置和高度由教练刻意调远/调近/调低（失误是**被诱发的示范**，不是自然发生）。
- 来球：喂球、慢速；纵向部分涉及腰高、膝高、胸高；深度部分涉及上网前倾球、中性球、防守球。
- 教练自己说明：他个人更偏「把拍子放在球后面再挥」的风格（09:31–09:36），转动平面可以因人而异。
