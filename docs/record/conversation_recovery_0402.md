### 3/17 训练：识别核心问题

- 产出 `docs/正手常见误解清单.md`：17 个概念纠正

### 3/18 训练：改动作阵痛期
- VLM 评分下降到 45-55（改动作期正常）
- 同步性暴跌到 0.09 = 同时改太多东西导致大脑过载
- **结论**：一次只改一件事。明天只做蹬地转髋
- Sinner 式低位引拍：手腕高度从 Unit Turn 到击球保持水平线，消除 scooping
- 发球机角度从 32° 降到 20-25°，避免高弹球诱发向上刷
- **Drop Feed = FTT 金标准训练法**

### 3/27 训练：关键对比分析日

**数据发现（vs 教练）：**
| 指标 | 教练 | 用户 | 差距 |
|------|------|------|------|
| 手腕位于肘上方 | +12.4px | -2.9px | 15px |
| 肩线角度 | 122.5° | 107.7° | -15° |
| 击球时肘角 | 135°(展开) | 64°(收缩) | 方向相反 |
| 手腕轨迹 | 流畅大弧线 | 挤在一起 | 搬运vs鞭打 |

**核心发现：**

1. **"荡"vs"提"** — 教练手臂被身体带动（钟摆），用户手臂自己在抬（搬运）
   - 根因：手臂和身体没有连接（背阔肌=胶水松了）
   - 检验：打完球手臂累吗？累=提，不累=荡

2. **轨迹层级压缩** — 教练三条线（肩肘腕）层次分明，用户三条线挤在一起
   - 教练：肩不动→肘延迟→手腕最后加速 = 鞭打时序
   - 用户：三点同时动 = 搬运（没有时序差）
   - 口令：`肩是钉子，肘是绳子，手腕是绳头`

3. **双臂不同步（Unit Swing 缺失）** — 左臂先收完，右臂才出发
   - 正确：身体旋转时左右臂同时往相反方向走（旋转门）
   - 口令：`左手松的瞬间就是右手出发的瞬间`

4. **击球太急是根因** — 站太前→没时间让身体先动→手臂抢跑
   - `弹...落...打` 三拍节奏
   - 站位退后半步

5. **Separation 是被动结果** — 不需要主动做
   - FTT 不讲 separation 不是因为它不存在，是因为它不需要你主动做
   - 只做蹬地转髋，separation 自然发生

6. **右肩下沉 = 蓄力感** — 用户自然发现了 FTT 的 Shoulder Tilt
   - Tilt 是主动的（FTT 7步第5步），但时机要和蹬地同步

7. **击球点偏后** — 不是位置问题，是身体没转到位，手臂在"够"
   - `球来找我，不是我去找球`

**产出文档：** `docs/research/19_forearm_compensation_analysis.md`（小臂代偿完整调研，900行）

## 第四阶段：握拍与胸肌突破（3/28-3/29）

### 3/28 空挥突破

**三个体感发现：**
1. ✅ 同步 = Unit Swing
2. ✅ 胸部推压带动小臂 = FTT Press Slot（核心正确感觉）
3. ⚠️ 食指主动内旋 → 纠正：内旋是被动结果，不需要主动做

**FTT 新视频："The Pros Grip Differently From You"**
- 旋转轴在手掌上部"V型区"（食指+拇指），不是 butt cap
- 两指练习法：只用食指中指握拍打球，强制建立触觉参考点
- **可能直接解决小臂代偿**：旋转轴在上部→前臂解锁→内旋自然发生

### 3/29 整合：两指 vs 肘部往前

**用户困惑**：两指握拍感觉和肘部往前荡的感觉难以兼顾

**解答**：这是同一个动作的两个视角，属于不同训练阶段
- 两指 = 握拍前的校准（1秒设置）
- 往前荡 = 挥拍时的执行意识（全程）
- 分三步练：①纯两指校准 → ②全手握检查触感 → ③正常打球只想荡

**重大认知修正："肘部往前推" → "胸部 press"**
- ❌ "肘部往前推/荡" = 增加手臂发力感
- ✅ "胸部 press" = FTT Chest Engagement，胸肌焊接手臂随躯干同步
- 更新了所有文档和 VLM 分析

**肩胛骨滑动（Scapular Glide）理解**
- 后缩（Unit Turn时背部夹紧）→ 前伸（Press时胸部推开）
- 和"背→胸"是**同一个动作的三个视角**
- 30秒体验法：双手合十→双肘往后夹→双手往前推
- 比喻：Sliding Door（滑动门），沿轨道水平滑

**FTT 正手三层架构：**
```
地基层：背阔肌连接 = 肩胛骨后缩（背部夹紧）
传动层：胸肌 press = 肩胛骨前伸（胸部推开）
接口层：V型区握拍 = 力量传到拍头
```

## 第七阶段：动力链完整串通（4/1）

### 4/1 上午 — 重大突破日

**发现1：腋下夹住 = 手臂焊在胸上**
- 大臂内侧和胸部侧面保持接触压力
- 蹬转时胸转手臂自动跟上，不需要主动送肘

**发现2：核心旋转（腹斜肌）= 动力链中转站**
- 肚脐左方一指处有扭转力 = FTT"腹部展开"
- 之前力在腰部断掉就是这里没连上

**发现3：发力心理模型修正 — Trunk Sequencing**
- ❌ 从脚开始四步阶梯（太机械）
- ✅ 躯干发令，腿部放大（一个旋转意图）
- 口令从 `蹬→肚子→胸→出去` → **`转！`**
- 旋转是脉冲不是长旋转，终点=击球瞬间

**完整动力链：**
```
蹬地（腿）→ 转髋（髋）→ 腹斜肌扭转（核心）→ 胸部转动（胸肌）→ 手臂被带走（腋下夹着）
```

### 4/1 下午 — 球场训练突破
- **第一次完全感受不到胳膊在发力** = 动力链正确的终极标志
- 力量传到了拍头，不需要刻意发力
- 新问题：**Through 向量不足**，击球后没有往前穿透
- 口令：`打穿球，不是打到球`

### 4/1 晚 — 钢架模型
- 教练 = 肩-肘-腕焊成一根钢架，焊在躯干上
- 用户 = 三段松散链条，各自调整角度
- 钢架三段保持靠：腋下贴住（肩）+ 背部托着（肘）+ V型区搭上（腕）
- **整个正手"做"的事 = 维持钢架 + 一个旋转脉冲**
- 设置好了，执行只需一个字：`转！`

**终极口令：**
```
设置：V型区搭上+中指环住 / 腋下贴住 / 背部托着 → 钢架成型
执行：转！
节奏：弹...落...打
```

## 第八阶段：肘在前机制 + 训练计划（4/2）

### 两指挥拍深化
- "Pros Grip Differently"（旋转轴）vs "Hit Hard Without Missing Long"（摆锤时机）
- 两个视频解决不同问题，不是一回事

### 《网球运动系统训练》书籍（211页）
- 3 个并行 agent 提取解剖学层
- 产出 24 份生物力学文件（胸大肌、背阔肌、腹斜肌等，含肌肉→概念映射）

### ⭐ 核心发现：肘在前面 ≠ 主动做，= 三个条件的结果

**教练从未说"把肘往前"。肘在前面是物理必然结果：**
1. **摆锤下落**（两指练习强制做到）— 球拍先自然落到最低位
2. **肩膀倾斜**（非持拍肩抬高）— 持拍侧肘自然下沉到低位
3. **然后才旋转** — 此时肘不得不先行往前

缺任何一个都不行。之前做不到是因为在试图直接制造结果。

### 4/3 训练计划

**口令：**
```
1. 落...斜...转！（摆锤→倾斜→旋转）
2. 等它落下来（不对抗球拍重力）
3. 关闭式站位
```

**5 个 Drill：**
1. 两指摆锤感知 × 15球（等球拍自然落到最低点）
2. 抛接球延迟加速 × 15次（训练晚加速）
3. 落...斜...转！完整练习 × 30球
4. 肩膀倾斜 + 髋部折叠 × 20球
5. 全场容错击球 × 10分钟
