# 训练录像协议（v4.2）

> 给累瘫的你看的录像 SOP。照做就行，不用想为什么。
> （想知道为什么的话，看最后一节。）

---

## TL;DR（一分钟版）

- **主机位放球员斜后 45°（右手球员→相机在球员后方偏右），三脚架腰高 1.1 m，距球员 5–6 m**
- **手机设 1080p @ 60 fps**（iPhone 能开 120 fps 就开 120 fps，用"慢动作"模式）
- **画面里必须同时看到：完整全身 + 来球落地点 + 头顶留白 0.5 m**

就这三条。其它都是细节。

## 主机位（每次训练必须）

| 项目 | 设置 |
|---|---|
| 位置 | 球员**斜后方 45°**（右手球员→相机在球员后侧偏右） |
| 距离 | 距球员 **5–6 m** |
| 高度 | 三脚架**腰高 1.1 m**（量一下三脚架伸到 110 cm） |
| 角度 | **水平**，不要俯仰；镜头水平指向球员胸口 |
| 帧率 | **1080p @ 60 fps**（手机能 120 就 120） |
| 构图 | 球员居画面中线偏一侧，**来球弹跳点必须在画面内** |
| 上下留白 | 头顶 0.5 m，脚下 0.3 m，**禁止半身画幅** |
| 衣服 | **纯色上衣**，与裤子和背景对比明显 |
| 光线 | **顺光**，避免逆光剪影；阴天最佳 |
| 背景 | 球场围网或单色挡布，背景**不要有其他移动球员** |
| 录制方式 | 三脚架，**禁止手持** |
| 单组时长 | 每组连续录 **6–10 拍**，开始前空打一拍让相机对焦 |

**为什么是这个角度**：斜后 45° 是单机位的最佳折衷。它能同时看到 unit turn 完成度（肩转角度、非持拍手指向）、引拍轨迹的环形 loop、以及来球落地点和击球点的相对时序。正侧面虽然能精确测量接触点位置，但会丢失肩-髋分离信息。

> **v4.2 注**：实地观看 Tom Allsopp / FTT / Feel Tennis 共 18 个视频后发现，
> **职业教练并不普遍使用「斜后 45°」**。Tom 大多数视频用「正前方 + 分屏正侧面」，
> Johnny FTT 用「正前方近景 + 侧面学生击球」。
> 「斜后 45°」只在专门诊断「肩髋分离角」时是必须的——它是单机位里唯一能同时看清两条线的角度。
> 所以：**斜后 45° 仍然是最高信息密度的单机位选择**，但如果你做不到，
> 「正前方 + 副机位侧面」组合也是合法的；缺的只是肩髋分离角的精确测量。

## 副机位（每周至少一次）

主机位拍不清楚的细节，靠副机位补。每周训练里安排一次专门走副机位。

| 项目 | 设置 |
|---|---|
| 位置 | **正侧面**（持拍手对侧——右手球员相机在球员**左侧**） |
| 距离 | 距球员 **7 m** |
| 高度 | 腰高 1.1 m |
| 帧率 | 60 fps 起步，120 fps 优先 |
| 构图 | 球员居画面右 1/3，左侧留 3 m 纳入来球弹跳点 |
| 用途 | 诊断**接触点前后位置**、**引拍开始时机相对来球**、**重心前后平衡** |

副机位拍 2–3 组就够了，主要用来交叉验证主机位看到的问题。

## 可选机位：握拍特写（pivot point 分析）

**何时录**：当你怀疑自己的 lag 出不来、或者明明动作看起来对但拍头总是「拖泥带水」时，
说明问题可能在握拍的旋转支点（pivot point）——这是 FTT Johnny 反复强调的结构性原因。

| 项目 | 设置 |
|---|---|
| 位置 | 持拍手特写，**低角度（拍柄侧面）** |
| 距离 | 距持拍手 **30–50 cm**（手机自动微距） |
| 时机 | 准备阶段静止 2 秒 + 几次 shadow swing |
| 帧率 | 60 fps |
| 必须看到 | 拇指 / 食指虎口的 V 字位置、底部 3 根手指（中无小）的握紧程度、shadow swing 时拍头是绕虎口还是绕底盖摆动 |
| 用途 | 诊断 `v2_pivot_at_butt_cap` —— lag 物理上不可能产生的结构性原因 |

录 10 秒就够了。这一段不上球场也能录（在家拿拍子做 shadow 即可）。

## 为什么是这个角度（一段解释）

VLM 看视频和人眼不一样。它需要**关键信息出现在画面正中、不被遮挡、有足够帧数**才能稳定判断。

正面拍：unit turn 是肩往后转，正面看就是肩膀"消失"在身体后面，VLM 看不见 → 误判为"没转肩"。
正侧面拍：能看到接触点和引拍弧线，但**髋肩分离的角度差被压扁**（两条线在同一深度），VLM 量不出 X-factor。
**斜后 45° 拍**：肩线、髋线、引拍 loop、来球轨迹**都能同时入画**，是单机位信息密度最高的角度。

帧率同理。30 fps 下 split step 落地只占 2–3 帧，VLM 经常错过；60 fps 是底线，120 fps 能精确到 ±8 ms。

## 常见错误（不要这样录）

- **正面录**（隔网对面）：看不到 unit turn 和肩-髋分离，VLM 给不出有效诊断
- **距离太远（>10 m）**：动作细节糊，关键点检测精度掉一半
- **距离太近（<4 m）**：脚步出画，下肢动力链信息丢失
- **30 fps**：split step 时机和拍头滞后窗口被采样丢失
- **手持拍摄**：抖动会让 VLM 把镜头位移误判为身体位移
- **半身画幅**：业余拍摄最常见错误，丢掉下肢=丢掉一半诊断维度
- **逆光**：球员变剪影，姿态检测直接失效
- **背景有其他移动球员**：VLM 会被干扰，误把别人的动作算到你身上
- **鱼眼/超广角**：边缘畸变让角度测量全部失真
- **录到一半暂停换角度**：同一文件里多个机位 VLM 会蒙圈，**一组录完再换**

## 极简检查清单（出门前看一眼）

- [ ] 三脚架带了
- [ ] 手机充满电（或带充电宝）
- [ ] 手机存储 ≥ 5 GB 空闲
- [ ] 相机 app 设到 **1080p @ 60 fps**（或 120 fps）
- [ ] 三脚架高度调到 **110 cm**
- [ ] 穿了**纯色上衣**
- [ ] 知道今天主机位放哪（斜后 45°，距球员 5–6 m）
- [ ] 如果是副机位日：记得带"侧面 7 m 腰高"

## 到场后检查（架好相机之后）

- [ ] 试录 5 秒，回放确认：
  - [ ] 全身入画，头顶有留白
  - [ ] 来球弹跳点在画面里
  - [ ] 不抖
  - [ ] 不逆光
- [ ] 确认背景没有其他移动球员
- [ ] 开始正式录制前空打 1 拍让自动对焦稳定
