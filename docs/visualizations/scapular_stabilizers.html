State 2 · 大臂自由飘动（默认状态）
肩胛骨没锚定 → 三角肌 + 上斜方肌主导 → 大臂被肩胛骨拽走 → 胸推肘失败
体感：肩头紧、脖子绷、胸软、大臂"飘"。胸推肘"找不到点"。
力学：肩胛骨上抬 + 前移，胸大肌起点 - 止点之间没有刚性桥，发力被"漏走"去拉肩胛骨。
State 1 → 4/30 突破态
前锯肌 + 下斜方 + 菱形肌钉住肩胛骨 → 胸大肌有 fixed point → 胸推肘清晰 → 大臂被被动甩出
体感：肩头松、脖子松、肩胛"贴在肋骨上滑"、胸有挤压感、大臂跟身体"焊死"。
力学：肩胛骨锁定 → R_scap 高 → 胸大肌的力 100% 拉肱骨 → 肘被推出去 → 小臂被甩。

关键力学方程（agent 给的精确表达）

F_pull_humerus / F_pull_scap = R_scap / R_humerus
胸大肌发力时，力会按"刚性"分配。肩胛骨松（R_scap 低）→ 力被分散到肩胛 → 拉不动手臂。肩胛骨锁（R_scap 高）→ 力全部用于拉肱骨 → 胸推肘清晰可感。

这就是为什么"想着大臂不动"反而做不到：意识把"大臂不动"翻译成"三角肌夹紧"，三角肌一夹就把肩胛骨往上抬，更飘了。 正确的指令不是给大臂，是给前锯肌——"把肩胛骨贴肋骨上"。
前锯肌激活 · Serratus Anterior
Drill 1 · Wall Push-up Plus（墙面推拉）
1. 双手撑墙，距离一臂
2. 手肘伸直不动，用肩胛骨"推墙"再"收回"
3. 推出去时肩胛远离脊柱（外展），收回时贴回脊柱
4. 每组 12 次，3 组

做对的体感：肋侧（腋下偏前）有酸/紧的发力感
做错：肩头耸起、感觉只有手臂在推
下斜方肌激活 · Lower Trapezius
Drill 2 · Y Raise（俯身 Y 字举）
1. 俯身 45°（或趴在斜板上）
2. 双臂伸直向斜上 45° 举起，呈 Y 字
3. 感觉肩胛骨"下沉 + 内收"（不是耸肩）
4. 顶峰停 2 秒，每组 10 次，3 组

做对的体感：肩胛骨下角附近有发力
做错：上斜方耸起（脖子两侧紧）
菱形肌激活 · Rhomboids
Drill 3 · Scapular Pull（肩胛收缩）
1. 直立，双手向前伸直
2. 仅用肩胛骨向脊柱方向收缩（手臂保持位置）
3. 感觉两块肩胛骨"互相靠近"
4. 收紧 2 秒，每组 15 次，3 组

做对的体感：两肩胛骨之间（脊柱上段）有挤压感
做错：胸前挺出、含胸不变
三角肌静默 · Deltoid Silence
Drill 4 · Hand-on-Shoulder Test（自检）
1. 左手摸右肩头（三角肌）
2. 慢动作做 unit turn + 引拍
3. 感觉三角肌应该是"软"的，不应有发力收缩
4. 如果三角肌一直紧 → 失败
5. 重做，意念放到前锯肌（肋侧）而不是肩头

做对的体感：三角肌一直松，肋侧前锯肌主动出力
做错：三角肌一直绷紧

训练顺序（按这个走）

  1. Week 1-2（场下）：每天 5-10 分钟做 Drill 1-3，让大脑认识这 3 块肌肉的位置和发力感
  2. Week 3-4（场上空挥）：做 unit turn 之前先做 1 次 Drill 1（墙面 push-up plus），把前锯肌"打开"，再去打球
  3. Week 5+（实战）：每球之间 3 秒 reset：左手摸右肩胛骨（确认没飘）+ 一次浅呼吸（让上斜方放松）
